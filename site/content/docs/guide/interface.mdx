## 首页两种形态

应用有**经典形态**和**玻璃坞**两种形态，在「设置 → 首页与导航 → 应用形态」切换。

| 形态 | 特点 |
| --- | --- |
| **经典形态** | 保持原有的页面与导航方式 |
| **玻璃坞** | 悬浮玻璃底栏，可切「周课表 / 日课表」，中间有独立圆钮 |

玻璃坞还有两个布局选项：

- **满屏悬浮**：课表满屏显示，底栏浮动在课表之上
- **内容避让**：课表底部预留空间，底栏悬浮在下方（可调节避让高度）

玻璃坞的圆钮功能、圆钮图标、底栏按钮列表都可以自定义。详见[个性化设置](/docs/guide/customize)。

## 周视图

网格展示整周课程。

| 操作 | 手势 |
| --- | --- |
| 切换周次 | 左右滑动 |
| 回到当前周 | 点「回本周」按钮（内嵌在时间栏，或右下角悬浮，样式可在设置里改） |
| 精确选周 | 点顶部信息栏的周次，打开周次选择器 |
| 打开课程 | 点课程卡片 |

<Callout type="info">
  **空白网格区域不响应点击**。需要添加内容时，点右上角菜单或圆钮，
  明确选择是加课程、加日程还是加考试。
</Callout>

## 日视图

聚焦当天安排，按时间顺序排列，适合赶时间时快速看。

- 玻璃坞形态下点底部「日课表」切换；经典形态下在右上角菜单或视图切换入口进入
- 左右滑动切换日期，点「回到今天」快速跳回；点右上角的 ✕ 回到周视图
- 顶部摘要卡显示当天门数、起止时间，以及当前状态标签：
  「正在上课 · 剩余 N 分钟」「快下课了 · 剩余 N 分钟」
- 有冲突时显示红色「冲突 N 节」标签；看其他周时会显示「非本周 N 门课」
- 临近的考试也会以标签出现，显示「考试名 · 今天」或「N 天后」
- 绑定了情侣课表时，底部还会显示「今日共同空闲」时段
- 独立日程（自习、会议等）也会插入日视图时间线，不会改动课程本身
- 日视图里点**「返回周视图」**回到网格

<Callout type="info">
  日视图选中的日期会带进添加流程——在日视图里点添加，
  新课程/日程的日期会自动填上你正在看的那天。
</Callout>

## 多课表管理

应用支持多张课表**独立保存、快速切换**。通知与超级岛会跟随当前课表。

适合这些场景：

- 区分不同学期
- 区分不同身份（例如本科课表与旁听课程）
- 同一学期的多套课程方案

### 常用操作

| 操作 | 路径 |
| --- | --- |
| 快速切换 | 点首页左上角课表名 → 在弹出面板里选 |
| 新建课表 | 右上角菜单 → 课表管理 → 右上角新建图标 |
| 重命名 / 复制 / 清空课程 / 删除 | 课表管理页 → 每张课表的「更多操作」 |
| 切换到此课表 | 课表管理页直接点这张课表 |

课表管理页每张课表下面会显示「N 门课程 · 第 M 周」。

<Callout type="info">
  **「复制」**会整张复制一份（连课程带设置），适合新学期在旧课表基础上改。
  切换课表也可以在八宫格菜单里加一个「切换课表」按钮，一点就弹出面板。
</Callout>

<Callout type="warn">
  **清空课程**只清课程，课表设置会保留（确认框原文：「确定清空 XX 的全部课程吗？
  课表设置会保留」）；**删除课表**会整张删掉。
  应用至少保留一个课表，删到最后一个时会提示「至少保留一个课表」。
</Callout>

## 学期与周次

进入「课表设置」，点**顶部的摘要卡**（显示「当前第 N 周 / 共 M 周」）进入学期设置：

| 项目 | 说明 |
| --- | --- |
| **开学日期** | 决定周次计算的基准。没设置会导致导出日历、闹钟、统计等多项功能受限。可选范围 2020–2035 年 |
| **选择学期周数** | 按本校实际教学周数调整（不同学校不一样） |
| **同步当前周** | 显示的周次和实际不符时，一键对齐。需要先设置开学日期，否则这一项是灰的 |

<Callout type="info">
  **周次是拿开学日期推的，不是手机日历周。**换学校、换学期、补过课之后
  都建议回来核一次。寒暑假不算学期周，别拿放假前的日期当开学日期。
</Callout>

<Callout type="warn">
  开学日期与实际作息不符时，课前提醒会整体偏移，超级岛显示的课程阶段也会不准。
  **换学校或换学期后建议核对一次。**
</Callout>

## 时间模板

时间模板决定每节课的起止时间，是课表行高和提醒时刻的计算依据。
入口：**设置 → 时间模板**（设置首页一级位；「课表页面」里也有同名入口，指向同一页）。

### 模板列表

列表里每套模板显示「N 节」和引用情况，当前使用的模板会标注「当前」。
每套模板的**更多操作**里有：

- **编辑节次**：逐节调整起止时间
- **复制**：先复制再改，避免影响正在使用的课表
- **重命名 / 删除**：正在使用中的模板不能删除
- **分享**：系统分享文件，或生成二维码分享给同学
- **查看使用情况**：看清楚影响范围再动
- **应用到当前课表**：把这套模板切给当前课表

列表底部还有两个入口：**地点作息匹配**和**日期作息规则**（见下方两节）。

<Callout type="info">
  模板列表顶部可以**新建**模板。想让某节课用它，在课程编辑页的
  「上课时间方案」里选——那就是「副时间表」。
</Callout>

### 改模板前先看影响范围

点**「查看使用情况」**会分三类列出：

| 分类 | 含义 |
| --- | --- |
| 直接绑定这套模板的课表 | 切到这套模板后，默认按这套节次时间显示 |
| 跟随课表主时间表的课程 | 没单独设副时间表，跟着课表走 |
| 把它作为副时间表的课程 | 即使课表换了主模板，这些课程仍单独用这套时间 |

底部还会显示「N 节课程」的引用数量。改模板前先看一遍，能避免误伤。

<Callout type="info">
  **副时间表（课程级时间模板）**：某节课的上下课时间和课表主模板不一致时
  （比如实验课在另一个校区、作息不同），在课程编辑页的「上课时间方案」里单独指定。
  指定后这门课不再跟随课表主模板。
</Callout>

### 编辑节次

<Steps>
<Step>
进入模板后点**「编辑节次」**，逐节改起止时间。
</Step>
<Step>
用**「新增一节」/「删除末节」**调整节数。节数不能小于已使用的最大节次。
</Step>
<Step>
想快速建一套，点**「快捷生成」**：填上午/下午/晚上各几节、各段第一节时间、
单节课时长、小课间时长，就能自动生成。
</Step>
<Step>
有特殊大课间（比如第 2 节后休息 30 分钟），在**「大课间规则」**里新增规则：
指定「第几节后」和「休息多久」。
</Step>
<Step>
保存。如果当前课表正在使用这套模板，会提示保存后同步更新所有相关课表与课程。
</Step>
</Steps>

### 按上课地点自动匹配时间模板

不同教学楼作息不同（比如主楼 45 分钟一节、实验楼连上 3 节），
可以用**地点作息匹配**自动套用不同模板。

入口：右上角菜单 → 地点作息匹配（或设置里的相关入口）。

<Steps>
<Step>
先创建至少两套时间模板（系统会提示「请先创建至少一套时间模板」）。
</Step>
<Step>
点**「新建地点组」**，填地点组名称（如「主教学楼 / 其他教学楼」），
绑定一个时间模板。
</Step>
<Step>
添加**地点关键词**，如 `A主`、`A1`、`A6`。可以点「从课表地点选择」，
系统会先识别课表里出现过的楼栋。匹配模式建议用**「前缀」**，更长的关键词优先。
</Step>
<Step>
用**「试匹配地点」**输入一个地点（如 `A1062`）验证命中哪个模板。
</Step>
<Step>
点**「重新匹配当前课表」**批量套用。命中课程的钟点会更新，未命中的保持不变。
</Step>
</Steps>

<Callout type="warn">
  重新匹配会**清除此前手动指定的模板**（针对命中的课程），未命中的课程不受影响。
  如果有课程的节次超出目标模板的节数，会拒绝套用并提示未套用的课程名。
  首页左侧时间列仍显示课表默认模板，卡片/详情/实况上的钟点以匹配结果为准。
</Callout>

## 课表显示设置

页面上半部分是**实时预览**，下半部分是设置列表。改任何一项预览立刻变，
不用退出去看效果。

### 课表页面（设置 → 课表页面）

**密度**（管格子本身多大）

| 项目 | 说明 |
| --- | --- |
| 自动充满屏幕高度 | 打开后行高自动撑满一屏，不需要手动调 |
| 隐藏周六周日 | 周末没课时可以让网格更宽 |
| 显示非本周课程 | 非本周的课以半透明灰色显示，方便对照 |
| 首页时间列显示 | 左侧节次时间列 |
| 时间栏宽度 | 时间列占多宽 |
| 课表行高 | 单行高度（开了「自动充满」时这项不生效） |
| 课程卡片间距 | 卡片之间的缝 |

**回到当前周**

| 项目 | 说明 |
| --- | --- |
| 按钮样式 | 时间栏内嵌 / 右下角悬浮 |
| 悬浮按钮不透明度 | 悬浮样式下按钮的透明度 |

**背景**

| 项目 | 说明 |
| --- | --- |
| 课表背景色 | 6 种预设底色 |
| 背景图片 | 全屏铺底的壁纸。选完后可以在壁纸选择页**拖动调整显示位置**，也能「重置居中」 |
| 背景随周次滑动 | 切周时壁纸跟着横向位移 |
| 背景显示区域 | 状态栏 / 顶栏 / 信息栏 / 课表区域，逐块控制 |
| 顶栏玻璃 / 信息栏玻璃 | 对应区域的磨砂玻璃开关 |
| 文字颜色 | 课程卡片标题、课程卡片详情、星期栏字体、星期栏强调色、时间轴字体；可勾「独立设置详情颜色」 |

<Callout type="info">
  设了壁纸后，可以在壁纸选择页**拖动调整显示位置**，也能「重置居中」。
  如果信息栏文字颜色和壁纸对比度不足，应用会自动切换成自动白/黑并给出提示，
  可在「课表页面 → 文字颜色」里换色或恢复默认。
</Callout>

### 课程卡片（设置 → 课程卡片）

同样是上预览下设置的布局。

**显示字段**

| 开关 | 说明 |
| --- | --- |
| 课程名 | 卡片主标题 |
| 老师 | 授课教师 |
| 教室 | 上课地点 |
| 时间 | 起止钟点 |
| 上下课字样 | 「上课 / 下课」这类标记 |
| 周数 | 例如「1-16 周」 |
| 课程简介 | 默认关闭，空间不足时最先被压缩 |

**布局**

| 项目 | 说明 |
| --- | --- |
| 卡片外观 | 实体 / 高斯模糊 |
| 垂直排版 / 水平排版 | 文字的对齐方向 |
| 课程卡片字号 | 主字号 |
| 紧凑字号 | 空间不够时自动降到的字号 |

**颜色**

| 项目 | 说明 |
| --- | --- |
| 统一课程卡片颜色 | 打开后所有卡片用同一个颜色，关掉各自用课程色 |
| 课表重新配色 | 进入重新配色弹层 |
| 冲突小胶囊 | 冲突课程上显示「冲突」标记 |
| 冲突课程透明度 | 冲突课程层叠显示时的透明度，调低能同时看到多节 |

<Callout type="info">
  冲突课程会自动层叠显示，调低透明度后能同时看到多节课。
</Callout>

### 按日期切换作息（日期作息规则）

有的学校分夏令时和冬令时。用**日期作息规则**可以让某段日期自动套用另一套模板。

入口：右上角菜单 → 日期作息规则。

<Steps>
<Step>
点**「添加日期规则」**，填规则名称（如「夏令时 / 冬令时」）。
</Step>
<Step>
设置**开始日期**与**结束日期**。
</Step>
<Step>
选择到期后要套用的**时间模板**。
</Step>
<Step>
保存。到达开始日时，系统会自动把所选模板套用为全部课表的默认作息。
</Step>
</Steps>

<Callout type="info">
  最多 2 条规则，且区间不能重叠。四种作息来源的生效顺序见
  [名词与数据说明 → 时间相关](/docs/guide/glossary#时间相关)——
  某门课命中了地点组时，会优先用地点组的模板。
</Callout>

## 节假日标记

设置 → 节假日标记（首页「课表」组里也直接显示了开关状态）。

- **启用节假日标记**：打开后会在课表上标记法定节假日和调休补班日
- **节假日数据更新**：显示「N 年法定节假日」和条数，可点**「检查更新」**拉取最新数据
- **近期节假日**：列出即将到来的假期，显示「N 月 N 日」区间
- **补班**：调休上班日会单独标出
- **自定义假期**：填名称、起止日期，类型选「假期」或「调休上班」，可编辑可删除

<Callout type="warn">
  **超级岛在假期期间不显示**，课程提醒与小组件也会隐藏课程。
  如果你在假期里测试超级岛发现不弹，先检查这里有没有覆盖今天的假期。
</Callout>
