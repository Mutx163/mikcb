应用里有些词是它自己的说法，弄清了能少踩很多坑。

## 三个层次：课程 / 排课 / 单节课

| 概念 | 是什么 | 改了影响什么 |
| --- | --- | --- |
| **课程** | 以**课程名称**为唯一标识的一门课 | 简称、颜色、性质、简介是**共享字段**，改了会同步给所有同名排课 |
| **排课记录** | 一门课的一个上课时间。高数周一 1-2 节、周三 3-4 节，就是同一门课的两条排课 | 只影响这一条 |
| **单节课** | 落在**某一个具体周次**上的一次课 | 调课、停课、本节课备注都作用在这一层 |

<Callout type="warn">
  **课程名称就是身份证。**改了名字等于新建一门课——历史备注、统计、
  任务关联都会留在新名字下。想改显示效果请改**课程简称**，别改课程名。
</Callout>

## 时间相关

| 词 | 含义 |
| --- | --- |
| **开学日期** | 周次计算的基准。校历第 1 周的起点，**不是手机日历周** |
| **学期周数** | 一学期总共几周（影响周次上限与统计） |
| **当前周** | 由开学日期推算。和学校对不上就用「同步当前周」一键对齐 |
| **时间模板** | 一套「第几节几点上、几点下」的作息表 |
| **主时间表** | 课表绑定的那套模板。没单独指定的课都跟它走 |
| **副时间表** | 单门课单独指定的模板（课程编辑页的「上课时间方案」）。指定了就不再跟主时间表 |
| **地点作息匹配** | 按教室楼栋关键词自动套用不同模板。优先级高于日期作息规则 |
| **日期作息规则** | 某段日期自动套用另一套模板（夏令时/冬令时）。最多 2 条，不能重叠 |

<Callout type="info">
  优先级从高到低：**地点作息匹配 > 副时间表 > 日期作息规则 > 课表主时间表**。
  课表左侧时间列始终显示课表默认模板，卡片和详情上的钟点以最终匹配结果为准。
</Callout>

## 单双周

「单周 / 双周」是按**周次的奇偶**过滤，不是按日期，**第 1 周是单周**。
怎么设见[课程与排课 → 周次设置](/docs/guide/courses#周次设置)；
导入时怎么对齐校历见[导入与迁移 → 教务系统导入](/docs/guide/import#教务系统导入推荐)。

## 课表（Profile）

「课表」是应用里的一套完整数据，包含：课程、任务、日程、考试、课表设置、
当前周。**多张课表互相独立**，切课表时通知和超级岛也跟着切。

| 操作 | 效果 |
| --- | --- |
| 切换 | 只改当前查看的，数据都在 |
| 复制 | 整张复制（连课程带设置），适合新学期改 |
| 清空课程 | 只清课程，**课表设置保留** |
| 删除 | 整张删掉。至少保留一张 |

导入对方课表后会出现一张标着**「对方课表（只读）」**的课表，
不能编辑，也不能当「当前课表」切换。

## 数据存在哪

| 数据 | 位置 |
| --- | --- |
| 课表、课程、时间模板、设置、任务、日程、考试 | **本机**（SharedPreferences） |
| 教务系统记住的账号 | 本机 |
| WebDAV 凭据 | 本机，断开连接即清除 |
| 云同步快照 | 你自己的坚果云（应用不托管任何服务器） |
| 应用日志 | 本机，可导出、可清空 |

应用**没有账号体系**，也不上传课表。检查更新、下载、导入导出这些才会联网。

## 备份文件是什么

后缀 `.mikcb` 的**明文**数据文件（可以直接打开看，但格式会随版本调整，
**不建议手改**）。分「当前课表」和「全部数据」两种导出范围，
换机、误删时靠它恢复。导出与导入的完整流程见
[同步与备份 → 数据备份与迁移](/docs/guide/sync-backup#数据备份与迁移)。

## 快捷导入的「录制」记了什么

录的是**操作步骤**（点了哪些按钮、访问了哪些页面），**不含账号密码**。
保存后下次点「⚡ 快捷导入」直接重放。教务网站改版后会失效，重录一次即可。
操作步骤见[导入与迁移 → 快捷导入](/docs/guide/import#快捷导入录制一次之后一键)。

## 超级岛相关

| 词 | 含义 |
| --- | --- |
| **超级岛 / 焦点通知** | 小米 HyperOS 在系统层展示的 promoted ongoing 通知。需 HyperOS 3.0.300+ |
| **重点提醒** | 高优先级通知 + 超级岛。可以由「重点提醒切入时机」控制什么时候切过去 |
| **阶段** | 三个：上课前 / 上课中 / 下课提醒 |
| **铃声时间矫正** | 整体平移提醒时刻（±30 秒），应对学校铃声比课表快/慢 |
| **后台保活服务** | 无障碍服务，只用于后台刷新小组件与重排提醒。**不读屏幕、不代点击** |
