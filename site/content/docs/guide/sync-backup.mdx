课表数据默认保存在本机。需要换机、防丢或多设备使用时，用下面几种方式。

## 数据备份与迁移

入口：**设置 → 数据备份与迁移**。页面顶部「当前可迁移内容」会列出
课程数量、当前课表、全部课表数、时间模板数、当前周、开学日期与文件后缀。

### 完整导出

| 选项 | 导出内容 |
| --- | --- |
| **导出当前课表** | 当前这一张课表，导入后可直接恢复课程和设置 |
| **导出全部数据** | 一次导出全部课表、时间模板和当前选中状态 |
| **导出时间模板** | 只导出时间模板，可分享给同学 |

导出后会走系统分享面板，建议存到网盘或电脑。

<Callout type="warn">
  备份文件是误删或换机后**唯一的恢复依据**。建议每学期至少导出一次。
</Callout>

### 完整导入

<Steps>
<Step>
点**「选择文件并导入」**，通过系统文件选择器选中 `.mikcb` 备份文件。
</Step>
<Step>
在弹出的「**选择导入方式**」里选择：

- **覆盖当前课表**：替换现有内容
- **合并更改**：保留两边，合并差异

对话框会同时列出两种方式的变更摘要
（`+新增 / ~更新 / -移除`），方便你先看清影响再决定。
</Step>
<Step>
确认后完成，提示「导入成功，备份数据已恢复」。
导入后 Toast 上会出现**撤销**按钮，点一下即可撤销本次导入。
</Step>
</Steps>

<Callout type="info">
  换机时最省事的做法：旧机「导出全部数据」→ 文件传到新机 →
  新机「选择文件并导入」。别只导「当前课表」，那样会丢掉其他课表和时间模板。
</Callout>

<Callout type="warn">
  选择覆盖时，当前课表未备份的修改会丢失。导入前建议先导出自己的备份。
</Callout>

<Callout type="info">
  另一种入口：从**外部分享一个备份文件**给本应用打开时，会直接问你
  「覆盖当前课表」还是「导入为新课表」。选后者会保留现有课表、另存一张，
  提示「已创建新的课表」。
</Callout>

## 云同步（坚果云 WebDAV）

需要多设备使用时配置。入口：**设置 → 云同步**。

<Steps>
<Step>
点**「连接坚果云」**。服务提供商默认坚果云，也可选**自定义 WebDAV**。
</Step>
<Step>
填写**邮箱 / 用户名**与**应用专用密码**。

应用专用密码在**坚果云网页或客户端 → 账户信息 → 安全选项 → 添加应用密码**里生成，
**不要用登录密码**。
</Step>
<Step>
点**「测试连接」**验证。显示「WebDAV 连接成功」后再确认连接。
</Step>
<Step>
在**同步设置**里选择同步方式：**自动同步**或**手动同步**。
</Step>
<Step>
手动同步时点**「立即同步」**：先拉取云端更新，再上传本机修改。
</Step>
</Steps>

<Callout type="warn">
  快照会包含仓库记住的学校账号，请务必使用应用专用密码。
  建议在高级设置里确认 WebDAV 地址使用 **HTTPS**（默认 `https://dav.jianguoyun.com/dav/`）。
</Callout>

### 同步冲突

本机和云端都有新修改时，会弹出「检测到同步冲突」，让你二选一：

- **使用云端**：下载云端数据替换本机
- **保留本机**：上传本机数据覆盖云端

首次同步时如果云端已有不一致数据，会提示「本机与云端数据不一致」，
并提供**「以本机为准备份」**的选项，避免直接覆盖。

### 可恢复版本

每次同步都会自动保留一个可恢复版本。在「**可恢复版本**」区：

- 点**「立即备份」**手动创建一个版本
- 点**「查看全部可恢复版本」**浏览列表，显示设备名、来源（自动/手动）、
  「N 个课表 · M 门课程」摘要。当前生效的那份标着「当前」
- 对某个版本点**「恢复到此备份」**：本地未同步的修改会丢失，需二次确认。
  恢复时会问你要不要**「设为当前云端版本」**——建议选「设为当前版本」，
  这样其他设备同步时不会冲突；选「仅恢复本地」则只改本机
- 也可以删除不需要的版本（不可撤销）

### 备份保留策略

「**备份保留策略**」里两档，用来防止云端版本无限堆积：

| 项目 | 说明 |
| --- | --- |
| **最长保留天数** | 超过后自动删除过期备份 |
| **最多保留份数** | 超过后自动删除最旧的备份 |
| **手动备份永不过期** | 打开后，你手动点的「立即备份」不会被自动清理 |

### 高级设置

| 项目 | 说明 |
| --- | --- |
| **WebDAV 地址** | 坚果云默认 `https://dav.jianguoyun.com/dav/`。建议用 HTTPS |
| **远程目录** | 云端存放快照的目录 |
| **启用云同步** | 关掉后不会上传也不会下载云端快照（凭据保留） |

<Callout type="info">
  「设备名称」可以自定义（如「我的手机」），方便在备份列表里区分来源。
</Callout>

### 同步状态

「**同步状态**」区显示**上次同步**时间，以及**最近错误**（失败时把原因写在这里，
排查比翻日志快）。同步结果有四种提示：

| 提示 | 含义 |
| --- | --- |
| 已上传到云端 | 本机较新，已推上去 |
| 已从云端恢复 | 云端较新，已拉下来 |
| 本地与云端已一致 | 没有变化 |
| 同步失败：xxx | 看「最近错误」，常见原因见[故障排查](/docs/guide/troubleshooting#webdav-同步失败) |

### 断开连接

「云账号 → 断开连接」会清除本机保存的 WebDAV 凭据，**课表数据仍保留在本机**。

## 局域网编辑

同一局域网下，可以在电脑上通过浏览器编辑手机上的课表。适合大量录入或批量调整课程。

<Steps>
<Step>
进入**设置 → 局域网编辑**，点**「开启局域网编辑」**。
</Step>
<Step>
页面显示**访问地址**、**PIN** 与**端口**。点「复制地址」，
或让电脑扫描页面上的二维码（链接已含 PIN）。
</Step>
<Step>
在电脑浏览器打开该地址，输入 PIN 后即可编辑。页面会显示「已连接 N 台」与最近活动。
</Step>
<Step>
用完点**「停止」**。默认离开本页即停止；打开**「离开后保持开启」**可保持运行。
</Step>
</Steps>

页面还会显示**已连接 N 台**与**最近活动**，方便确认是不是只有你自己在用。

<Callout type="warn">
  数据只在局域网内传输，不会上传云端。但**用完请及时停止**，避免同一网络下的其他人访问。
  未检测到局域网 IP 时会提示确认已连接 WiFi。宿舍 WiFi 无法互相访问时，
  可以**用手机开热点，再让电脑连接该热点**。
</Callout>

## 情侣课表

可以把两个人各自的课表叠加显示，看「共同空闲」和「一起上课」。
入口：**设置 → 情侣课表**。

<Steps>
<Step>
**导出我的课表给对方**：生成分享文件发给 TA。
</Step>
<Step>
对方收到后，在他自己的应用里**「导入对方课表」**。
</Step>
<Step>
绑定成功后首页可进入**叠加视图**，用图例区分「我的课 / TA的课 / 一起上课 / 共同空闲」。
</Step>
<Step>
下方会列出**今日共同空闲**时段（或该日共同空闲），并显示「共 N 段」。
</Step>
</Steps>

### 用坚果云自动同步对方课表

不想每次手动传文件，可以配置**坚果云拉取**——它和「云同步」的账号**互相独立**。

<Steps>
<Step>
点**「连接坚果云」**，填写账号与应用专用密码。
</Step>
<Step>
选择**本机槽位**：**双方必须选不同槽位**（一方选 1，另一方选 2），否则互相读不到课表。
</Step>
<Step>
点**「上传我的课表到坚果云」**把自己的课表传上去。
</Step>
<Step>
对方点**「立即拉取对方课表」**即可更新。可随时「断开连接」。
</Step>
</Steps>

### 周次偏移

两个人的学期进度不一致时，设置**周次偏移**：查看你的第 N 周时，
读取对方课表的第 N+偏移 周（例如 +1 表示对方比你快一周）。设置后会显示实时预览
——「查看你的第 5 周时，显示对方第 6 周的课」。选「无偏移」即同步。

<Callout type="warn">
  两张课表的**开学日期不一样**时，光靠周次偏移对不齐。
  各自先确认自己的「当前周」是对的，再调偏移。
</Callout>

绑定后这张课表在课表管理里会标着**「对方课表（只读）」**。

<Callout type="info">
  对方只能看到你导出文件中包含的内容。对方课表在应用内是**只读**的：
  点开对方的课会提示「这是对方课表中的课程，仅供查看」，只能看备注，
  不能编辑或调课。解除绑定会删除本地保存的对方课表。

  **叠加颜色**里可以改四种图例（我的课 / TA 的课 / 一起上课 / 共同空闲）的配色；
  **对方名称**只是显示名，随便填。
</Callout>

## 二维码迁移

换机场景下，二维码传输比备份文件更快：旧手机生成二维码，新手机扫码导入。
详见[导入与迁移 → 二维码面对面传输](/docs/guide/import#二维码面对面传输)。

## 导出日历（ICS）

右上角菜单 → **导出日历**：把课程、考试、日程导出成 ICS 日历分享给其他日历应用。

<Steps>
<Step>
选择要导出的**课表**。
</Step>
<Step>
设置**日期范围**（开始日期 / 结束日期）。
</Step>
<Step>
在「**日历内容**」里勾选**课程 / 考试 / 日程**（至少选一种）。
</Step>
<Step>
点**「导出并分享」**，会提示「已导出并分享 N 个日历事件」。
</Step>
</Steps>

<Callout type="warn">
  导出课程前**必须先设置学期开始日期**，否则会提示错误。
  结束日期不能早于开始日期；范围内没有事件时会提示
  「所选日期范围内没有日历事件」。
</Callout>

## 从旧版迁移

如果你之前装过旧包名版本，首次启动会看到迁移引导页，按三步走：

<Steps>
<Step>
**打开旧版应用**：进入「数据备份与迁移」后点**「导出全部数据」**，
不要点「导出当前课表」，也**不要先卸载旧版**。
</Step>
<Step>
**保存备份文件**：优先选择「保存到文件」，建议存到 下载 / Download 文件夹。
</Step>
<Step>
**回到新版导入**：通过系统文件选择器选中 `.mikcb` 文件。
确认新版数据正常后，再卸载旧版。
</Step>
</Steps>

<Callout type="info">
  没有「保存到文件」选项时，可以先分享到微信任意一个聊天，在微信里点开并保存，
  通常会出现在 Download / WeiXin 文件夹，再回到新版选择该文件导入。

  桌面上会暂时出现两个应用图标，这是正常现象，旧数据仍在旧版里。
</Callout>
