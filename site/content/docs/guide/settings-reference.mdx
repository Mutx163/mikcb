这一页把所有设置入口收成一张地图。**想改什么直接在这里找路径**，不用翻遍全文。

设置页按「设置首页 → 次级页」两级组织，下表把每一项的入口和用途都列出来。

## 功能设置

以下是在设置首页直接可见、能一步进入的常用设置：

| 设置项 | 入口 | 作用 |
| --- | --- | --- |
| **当前周 / 学期** | 设置顶部摘要卡 | 设开学日期、学期周数、同步当前周 |
| **时间模板** | 设置 → 时间模板 | 每节课的起止时间，行高与提醒依据 |
| **课表页面** | 设置 → 课表页面 | 密度、背景、回到当前周、时间列 |
| **课程卡片** | 设置 → 课程卡片 | 卡片显示字段、布局、颜色 |
| **桌面小组件** | 设置 → 桌面小组件 | 十种卡片、绑定课表、外观 |
| **超级岛与通知** | 设置 → 超级岛与通知 | 提醒时段、显示内容、上课闹钟、自检 |
| **数据备份与迁移** | 设置 → 数据备份与迁移 | 导出/导入备份、二维码传输 |
| **云同步** | 设置 → 云同步 | WebDAV 同步、可恢复版本 |
| **局域网编辑** | 设置 → 局域网编辑 | 在电脑浏览器编辑课表 |
| **情侣课表** | 设置 → 情侣课表 | 叠加对方课表、共同空闲 |
| **节假日标记** | 设置 → 节假日标记 | 法定节假日、自定义假期 |

## 应用设置（设置 → 应用）

| 分组 | 入口 | 覆盖内容 |
| --- | --- | --- |
| **外观与配色** | 设置 → 应用 → 外观与配色 | 主题模式、字体、主题色、磨砂玻璃、高级材质、文字颜色 |
| **课程卡片** | 设置 → 应用 → 课程卡片 | 卡片显示字段、布局、颜色 |
| **课表页面** | 设置 → 应用 → 课表页面 | 密度、背景、回到当前周、文字颜色 |
| **首页与导航** | 设置 → 应用 → 首页与导航 | 经典形态/玻璃坞、底栏、菜单样式、首页标题 |
| **桌面小组件** | 设置 → 应用 → 桌面小组件 | 卡片显示项、外观、精确闹钟 |
| **通用** | 设置 → 应用 → 通用 | 语言、页面转场、震动反馈、下拉快捷导入 |

## 关于类

设置首页「**关于**」分区里：

| 分组 | 入口 | 作用 |
| --- | --- | --- |
| **关于软件** | 设置 → 关于 → 关于软件 | 版本更新、下载渠道、更新日志、开源许可、问题反馈与支持开发者 |
| **使用引导与权限** | 设置 → 关于 → 使用引导与权限 | 重新打开首次启动的引导页（权限 / 个性定制 / 简称建议与导入方式）；隐私说明只读 |
| **诊断** | 设置 → 关于 → 诊断 | 应用日志开关、日志查看与导出、内存状态 |

每一项的详细操作见[更新与支持](/docs/guide/about)，这里只列入口。

## 右上角菜单入口

不少功能不走设置页，而是进右上角菜单。菜单样式（列表 / 八宫格）可自定义。

| 功能 | 入口 |
| --- | --- |
| 课程总览 | 右上角菜单 → 课程总览 |
| 课程统计 | 右上角菜单 → 课程统计 |
| 考试安排 | 右上角菜单 → 考试安排 |
| 日程安排 | 右上角菜单 → 日程安排 |
| 任务清单 | 右上角菜单 → 任务清单 |
| 冲突检测 | 右上角菜单 → 冲突 |
| 地点作息匹配 | 右上角菜单 → 地点作息匹配 |
| 日期作息规则 | 右上角菜单 → 日期作息规则 |
| 课表重新配色 | 右上角菜单 → 课表重新配色 |
| 课表管理 | 右上角菜单 → 课表管理 |
| 导入课程 | 右上角菜单 → 导入课程 |
| 导出日历 | 右上角菜单 → 导出日历 |
| 课表设置 | 右上角菜单 → 课表设置（即「设置」入口） |
| 软件更新 | 右上角菜单 → 软件更新（跳到关于软件） |
| 问题反馈 | 右上角菜单 → 问题反馈 |
| 请喝咖啡 | 右上角菜单 → 请喝咖啡 |

<Callout type="info">
  右上角菜单支持**列表**和**八宫格**两种样式，也可以自定义放哪些入口、
  怎么排序。默认包含的功能不一定会全部显示，想用的入口可从候选项里加回来。
  详见[个性化设置 → 首页与导航](/docs/guide/customize#首页与导航)。
</Callout>

## 设置首页从上到下分 8 段

| 段 | 内容 |
| --- | --- |
| 摘要卡 | 当前第 N 周 / 共 M 周、开学日期（**点它进学期设置**） |
| 课表 | 课表管理、时间模板、节假日标记 |
| 课表显示 | 课程卡片、课表页面 |
| 提醒与桌面 | 超级岛与通知、桌面小组件 |
| 应用 | 外观与配色、首页与导航、通用 |
| 数据与共享 | 数据备份与迁移、云同步、局域网编辑、情侣课表 |
| 关于 | 关于软件、使用引导与权限、诊断 |
| 开发者选项 | 仅调试版 / 性能版可见，正式版不显示 |

<Callout type="info">
  设置首页的**摘要卡**在最顶部，点它能快速进入当前周与学期设置。
</Callout>

## 还有些页面不在设置首页

| 页面 | 入口 |
| --- | --- |
| **课程统计** | 右上角菜单 → 课程统计 |
| **统计设置** | 课程统计页 → 右上角设置（或菜单里加「统计设置」按钮） |
| **课程总览与编辑** | 右上角菜单 → 课程总览 |
| **导入课程** | 右上角菜单 → 导入课程 |
| **导出日历** | 右上角菜单 → 导出日历 |
| **地点作息匹配 / 日期作息规则** | 右上角菜单（时间模板页底部也有入口） |
| **课表重新配色** | 右上角菜单 → 课表重新配色 |
| **切换课表** | 点首页左上角标题，或菜单里的「切换课表」按钮 |
| **高级材质** | 设置 → 应用 → 外观与配色 → 高级材质（**玻璃模式需为「液态玻璃」才显示**）；菜单里也能加按钮 |
| **版本更新 / 问题反馈 / 更新日志 / 开源许可** | 设置 → 关于 → 关于软件（每一项的详细操作见[更新与支持](/docs/guide/about)） |

<Callout type="info">
  觉得某个页面藏太深，就把它加进菜单：**设置 → 应用 → 首页与导航 →
  自定义菜单按钮**（八宫格菜单）或**自定义底栏按钮**（玻璃坞底栏）。
  候选条目分四类：功能入口 / 数据与同步 / 偏好设置 / 关于与支持。
</Callout>

## 开发者选项

设置页最底部「**开发者选项**」分区（实况测试样例、HyperOS 组件展示、
Miuix 组件展示，调试版还有内存状态）。**仅调试版 / 性能版可见**，正式版不显示。
普通使用无需改动。

## 各设置页的「恢复默认」

多数设置页底部都有**「恢复默认设置」**，按范围重置，**不会动课程数据**。
详见[个性化设置 → 恢复默认设置](/docs/guide/customize#恢复默认设置)。
