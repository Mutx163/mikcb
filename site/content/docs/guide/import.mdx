轻屿课表提供多条导入路径，学校有没有被适配都能用。

## 教务系统网页登录导入

适配脚本来自 [qingyu_warehouse](https://github.com/Mutx163/qingyu_warehouse)，已覆盖一部分学校。

<Steps>
<Step>
在应用中进入导入入口，选择**教务系统导入**。
</Step>
<Step>
在内置浏览器中登录你的教务系统。
</Step>
<Step>
按提示选择学期，确认解析出的课程列表。
</Step>
<Step>
导入为当前课表，或保存为一张新课表。
</Step>
</Steps>

教务系统的账号密码只在你本机与学校服务器之间传输，不会上传到应用作者。

<Callout type="info">
  如果你的学校尚未适配，仍然可以使用 ICS 导入或 AI 识图。也欢迎参与适配补充——需要网页调试、抓包或 JavaScript 基础；也可以用 AI 协作完成，见 [AI 协作适配教务](/docs/dev/jiaowu-adapter)。
</Callout>

## ICS 导入与导出

适用于从其他课表应用、学校导出的日历文件迁移。

- **导入**：选择 `.ics` 文件，应用会解析其中的课程事件并生成课表
- **导出**：把当前课表导出为 `.ics`，供其他日历应用使用

导入前建议先确认时间模板与本校作息一致，否则节次可能对不上。

## AI 识图导入

学校未适配、又没有 ICS 文件时，可以截图教务系统的课表页面，用 AI 识图识别课程信息后生成课表。

识别结果可能存在偏差，导入后请逐条核对课程名称、时间、地点与周次。

## 二维码面对面传输

两台设备之间可以直接传课表，无需网络：

- 发送方生成课表二维码（喷泉码多帧）
- 接收方扫码即可导入

适合同学之间互传，或手机换机时快速迁移。

## 手动添加课程

课程不多时直接录入最稳妥。添加一门课需要提供：

| 字段 | 说明 |
| --- | --- |
| 课程名称 | 必填，可另设简称用于通知与小组件 |
| 授课教师 | 选填 |
| 上课地点 | 选填，超级岛会显示 |
| 星期与节次 | 决定课程在周视图中的位置 |
| 周次范围 | 支持单周、双周与自定义周次 |
| 颜色 | 用于区分不同课程 |
| 备注 | 选填，可标记作业等信息 |

## 多课表管理

应用支持多张课表独立保存与快速切换，通知与超级岛会跟随当前课表。

适合区分不同学期、不同身份（如本科课表与旁听课程）或不同课程方案。
