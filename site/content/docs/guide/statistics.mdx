课程统计把一学期的上课记录折算成可读的图表，回答「这学期到底有多忙」。
入口：**右上角菜单 → 课程统计**。

## 学期 / 周双视图

页面顶部两个标签：**学期** 和 **周**。

### 学期标签

- **学期进度**：显示「学期 开始 - 结束」区间、今天日期，
  以及「截至第 N 周，已上 X 节 / 共 Y 节」和剩余节数
- **本周小结**：上周课时、学期周均，以及「较上周 ±N 节」「较周均 ±N 节」的对比
- **成就徽章** 与 **数据故事**（见下）
- 底部有课表对比入口

### 周标签

按周查看：本周概览（课程门数、本周课时）、每周课程、每日课时分布、必修/选修比例、课程列表。

<Callout type="info">
  统计跟随**当前课表**。切换课表后数据会变，用「课表对比」可以查看多张课表之间的差别。
  统计基于课表里的课程与周次设置，刚加的课程请确认已保存、周次范围覆盖当前周。
</Callout>

## 深度分析

点各模块卡片进入详情页：

| 模块 | 内容 |
| --- | --- |
| **每周课时趋势** | 折线图，点任意一周显示「第 N 周 · X 节」 |
| **时间利用** | 时间段的利用分布 |
| **教室分析** | 按上课地点汇总 |
| **教师分析** | 按授课教师汇总 |
| **课程排行** | 按课时排名的课程列表，超出展示数量的会提示「另有 N 门课程未展示」 |
| **课表对比** | 不同课表横向比较，显示「较当前 ±N 节」 |

## 学期热力图

按星期与节次着色，**颜色越深表示该时段课程越多**。用来找「哪天最满」最快。

## 成就徽章

根据课表特征自动解锁，点徽章可以看到具体解锁条件：

一共 12 个，条件按源码里的真实算法写在这里。**未解锁的会显示进度
（如「64/100」）**，点徽章能看到完整说明。

| 徽章 | 解锁条件 |
| --- | --- |
| 早八战士 | 课表中有 08:00 或更早开始的课程 |
| 早起鸟 | 早间（12:00 前开始）课时占总课时的一半以上 |
| 全勤达人 | 至少一门课程在开课周期内每周都有课（无停课、无单双周跳课） |
| 周末战士 | 周末（周六或周日）有课 |
| 课王 | 某一天排课达到 6 节及以上 |
| 满课日之王 | 某一天排课达到 8 节及以上 |
| 学霸 | 学期累计课时达到 100 节 |
| 均衡大师 | 每天课时差距不超过 2 节 |
| 夜猫子 | 有 18:00 以后才结束的课 |
| 教室探索家 | 使用过 5 个及以上不同的教室 |
| 跨楼达人 | 同一天内去过 3 栋及以上不同的教学楼 |
| 时间管理大师 | 每天课间最长空档不超过 2 节 |

<Callout type="info">
  「每天课时差距」是把周一到周日各自的课时数取最大减最小，
  没课的日子算 0。想把「均衡大师」刷出来，就得让每天节数差不多。
</Callout>

## 数据故事

用自然语言总结你的学期，例如：

- **最忙的一天**：截至第 N 周，你最忙的一天是周X，平均 N 节课
- **最轻松的一天**
- **最常去的教室**：共去了 N 次
- **教学楼探险**：课程分布在 N 栋不同的教学楼
- **时间跨度**：最早的课与最晚的课

## 每周周报推送

入口：**课程统计页 → 右上角设置图标**。也可以在八宫格菜单里加一个「统计设置」按钮（偏好设置分类）。

- **本周课程小结**：打开后每周日 21:00 推送一周小结通知
- 关闭时页面会提示当前状态；打开后副标题显示**下次推送的具体日期与时间**

通知内容包含：第 N 周 · 共 X 节 · Y 门课、较上周的增减、最忙的一天。
本周没课时会提醒「本周暂无课程，好好休息吧」。
设置页里会直接显示下次推送的具体日期与时间。

## 导出与分享

点右上角**分享**按钮：

<Steps>
<Step>
在「**包含模块**」里勾选要导出的模块（至少选一个）。
</Step>
<Step>
在「**导出格式**」里选**长图（PNG）**或**PDF 文档**。
</Step>
<Step>
点**「开始导出」**，通过系统分享发给朋友或保存。
</Step>
</Steps>

导出结果会带上品牌信息与官网二维码，适合发社交平台。

## 与小组件配合

统计信息可以直接放到桌面，提供 **统计 2×2**、**统计概览 2×4**、**统计横条 4×1**
三种卡片。详见[桌面小组件](/docs/guide/widget)。

## 常见问题

**统计里没有我刚加的课程**

确认课程已保存、周次范围覆盖了当前周，并确认当前课表选对了。

**切换课表后统计变了**

正常现象。多课表对比视图可以查看它们之间的差别。

**热力图看不懂**

按星期与节次着色，颜色越深表示该时段课程越多。
