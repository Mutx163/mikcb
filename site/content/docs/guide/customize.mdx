这一页覆盖所有「不影响功能、只影响观感和使用习惯」的设置。

## 外观与配色

入口：**设置 → 外观与配色**（在设置页的「应用」分组里）。

### 主题与显示

| 项目 | 选项 |
| --- | --- |
| **主题模式** | 跟随系统 / 浅色模式 / 深色模式 |
| **字体选择** | 应用默认（Inter）、系统无衬线、MiSans、鸿蒙黑体、OPPO Sans、苹方、Noto Sans、衬线体、宋体、等宽体 |

<Callout type="info">
  厂商字体**未内置**，需要系统已预装才生效。小米通常只有 MiSans 效果明显。
  没有变化时会自动回退，一般不必自己安装字体。
</Callout>

### 应用主题色

影响顶部栏、强调色和全局主色调。

- **预设主题**：默认蓝、暗夜紫、森林绿、暖阳橙、护眼模式、高对比度、深色极简，
  以及中性灰 / 锌灰 / 石板灰等中性色系
- 选中后应用会提示「已切换到 XXX」，并提供**撤销**

### 主题管理

点「主题管理」进入：

| 功能 | 说明 |
| --- | --- |
| **保存当前主题** | 把当前配色存成「我的主题」 |
| **导出主题** | 复制到剪贴板，可发给别人 |
| **导入主题** | 从剪贴板导入（格式错误会提示） |
| **重命名 / 复制 / 删除** | 在「我的主题」列表上管理 |
| **重置** | 把修改过的预设主题恢复原样 |

主题名会显示「基于 XXX（已修改）」，方便区分自定义过的预设。

### 磨砂玻璃

调节首页弹出面板的高斯模糊强度与磨砂亮度：

- **玻璃模式**：实体卡片 / 高斯模糊 / 液态玻璃
  （选「实体卡片」等于关闭模糊，弹窗变不透明纯色底，最省电）
- **模糊强度**与**磨砂亮度**两个滑块，滑块越靠右白色磨砂层越明显
- 点**「打开预览面板」**实时预览效果；也可以勾上「在顶部显示磨砂玻璃预览」

### 高级材质

入口：**设置 → 外观与配色 → 高级材质**。
（这一项只在玻璃模式选了「液态玻璃」时才出现在磨砂玻璃组里；
也可以直接在菜单里加「高级材质」按钮，它是偏好设置分类下的独立页面。）

液态玻璃的精细参数：厚度、模糊强度、染色强度、灯光强度、环境光强度、
折射率、饱和度、色差、光照角度、可见性。也提供**清澈 / 轻雾 / 标准 / 浓密**
四个预设——不想逐项调就先选预设。

<Callout type="warn">
  液态玻璃需要高性能设备支持。中低端机上建议用「实体卡片」或「高斯模糊」。
</Callout>

### 液态玻璃作用范围

开了液态玻璃之后，可以逐块决定哪些地方用、哪些地方不用：

| 范围 | 影响 |
| --- | --- |
| 弹窗与对话框 | 底部弹窗、确认对话框与操作菜单 |
| 玻璃坞导航 | 底部悬浮药丸与加课圆钮 |
| 首页玻璃带 | 标题栏与星期栏的玻璃背景带 |
| 下拉选择弹窗 | 玻璃模式等设置行弹出的小气泡菜单 |
| 全屏选择面板 | 预设主题、字体等长列表选择弹窗（默认保持磨砂） |
| 壁纸选点按钮 | 壁纸位置选择页悬浮在壁纸上的玻璃按钮 |

卡顿时把范围关掉几项，比整体降级成实体卡片损失小。

### 文字颜色

自定义课表各区域的文字颜色：课程卡片标题、课程卡片详情、
星期栏字体、星期栏强调色、时间轴字体。可勾选「独立设置详情颜色」。

<Callout type="info">
  颜色对比度太低时会提示「颜色对比度较低，可能影响可读性」。
  信息栏文字与壁纸对比不足时，应用会自动切为自动白/黑并给出提示。
</Callout>

## 首页与导航

入口：**设置 → 首页与导航**（在设置页的「应用」分组里）。

### 应用形态

| 形态 | 说明 |
| --- | --- |
| **经典形态** | 保持现有的页面与导航方式 |
| **玻璃坞** | 悬浮玻璃底栏，切换日/周课表 |

### 底部导航栏（玻璃坞）

- **显示日课表入口 / 显示周课表入口 / 显示圆钮**（圆钮显示在药丸右侧）
- **圆钮功能**：可选择触发哪个入口（如添加课程、切换课表等）
- **圆钮图标**：默认加号，也可以搜索图标名称自定义
- **自定义底栏按钮**：调整底栏放哪些入口

只有玻璃坞形态下这一组才生效。

### 右上角菜单样式

| 样式 | 说明 |
| --- | --- |
| **列表菜单** | 锚定列表，可自定义 |
| **八宫格菜单** | 图标瓷贴，可自定义 |

点**「自定义菜单按钮」**进入编辑器：

- 上方「**已启用**」是你当前菜单里的按钮，下方「**可添加**」是还没放进去的候选项
- 顶部会显示「**已启用 N/上限 个**」，放满后点「添加」会提示「已达上限」
- **按住条目拖动**即可排序；点条目上的**加 / 减**按钮增删
- 「恢复默认排列」一键回到初始布局
- 候选入口分四类：**功能入口 / 数据与同步 / 偏好设置 / 关于与支持**
- 有个别条目是**固定入口**（如用于重新打开本菜单页的），不能移除，会有提示

<Callout type="info">
  菜单入口太多会装不下。想精简就把不常用的删掉，想更顺手就把常用的拖到前面。
</Callout>

### 首页标题

控制首页左上角课表切换入口的样式：

- **经典文字**：只显示文字，点击切换课表
- **大 Logo**：显示大 Logo 和小课表名称

## 通用设置

入口：**设置 → 通用**（在设置页的「应用」分组里）。

| 项目 | 说明 |
| --- | --- |
| **语言选择** | 跟随系统，或手动切换到已适配语言（简体中文、繁体中文台湾/香港、英文、日文、韩文）。切完立即生效 |
| **页面转场速度** | 调节进入/返回子页面的滑动动画快慢，数值越大越快。**会叠加系统的「过渡动画缩放」**——系统开发者选项里把动画关了，这里调再大也没用 |
| **启用应用内震动反馈** | 关闭后页码切换、切周等交互不再震动 |
| **首页下拉快捷导入** | 在首页下拉时自动执行教务快捷导入。没保存过快捷导入记录时下拉没反应 |

## 恢复默认设置

各设置页底部都有「**恢复默认设置**」入口，按范围重置（不会动课程数据）。
确认弹窗会把影响逐条写出来，看清再点：

| 范围 | 影响 |
| --- | --- |
| 课程卡片 | 显示字段、布局与颜色 |
| 课表页面 | 密度、回到当前周按钮与背景（**含清除壁纸**） |
| 外观 | 主题模式、字体、主题色与玻璃质感 |
| 首页与导航 | 底栏、菜单与首页标题 |
| 桌面小组件 | 显示项与外观 |

<Callout type="warn">
  重置课表页面设置会**一并清除壁纸**。重置前如果壁纸很重要，先记住来源。
</Callout>
