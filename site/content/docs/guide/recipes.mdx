前面的页面按功能讲，这一页按**你要办的事**讲。每节给出完整顺序，照着点就行。

## 场景 1：刚装好，15 分钟配到能用

<Steps>
<Step>
**走完引导 5 页**，第 3 页的权限**全部点一遍**。这步省不掉，
超级岛和提醒全靠它。
</Step>
<Step>
**设开学日期**：设置 → 点顶部摘要卡 → 设置开学日期。
不知道具体日期就填校历第一周的周一。
</Step>
<Step>
**设学期周数**：同一页 → 选择学期周数，按本校实际填（一般 16–20）。
</Step>
<Step>
**导入课表**：右上角菜单 → 导入课程。学校已适配走教务导入，
没适配走[表格或 AI 识图](/docs/guide/import)。
</Step>
<Step>
**核时间模板**：设置 → 时间模板，逐节对一下本校作息。
对不上就[快捷生成](/docs/guide/interface#编辑节次)一套。
</Step>
<Step>
**补课程简称**：每门课填 3 字以内的简称，超级岛和小组件才不截断。
嫌一门门填麻烦，先把主要几门填上。
</Step>
<Step>
**发一条测试通知**：设置 → 超级岛与通知 → 自检 → 测试通知，
**按 Home 键回桌面**看效果。
</Step>
<Step>
**加桌面小组件**：设置 → 桌面小组件 → 快速添加到桌面。
</Step>
</Steps>

<Callout type="warn">
  这三件事没做对，后面怎么调都不对：**开学日期、时间模板、通知权限**。
  出问题先回来看这三项。
</Callout>

## 场景 2：我的学校没被适配

别等适配，按这个顺序试：

<Steps>
<Step>
**先试教务导入**。列表里没有就点底部的「学校列表里没有你的学校？」去反馈，
建议一起写学校名称、教务网址、登录后课表页链接或截图。
</Step>
<Step>
**有 Excel/CSV 课表** → [表格导入](/docs/guide/import#表格导入)。
下载模板、按列填、另存 CSV、导入。最稳的一条路。
</Step>
<Step>
**只有截图** → [AI 识图导入](/docs/guide/import#ai-识图导入)。
用豆包专家模式，截图务必带星期表头。
</Step>
<Step>
**别的课表应用里已经有课** → 在那边导出 `.ics`，回来
[ICS 导入](/docs/guide/import#ics-日历导入)。
</Step>
<Step>
**身边有人已经用上了** → 让对方[导出完整备份](/docs/guide/sync-backup#完整导出)
发你，你导入即可直接恢复。
</Step>
<Step>
都不行就[手动录入](/docs/guide/courses)，课程不多其实很快：
填一次完整信息，之后同名的课用「沿用已有课程」带出来。
</Step>
</Steps>

## 场景 3：换手机

<Steps>
<Step>
**旧机**：设置 → 数据备份与迁移 → **导出全部数据**（**不要**只导当前课表），
存到网盘或传到新机。
</Step>
<Step>
**新机**装上应用，走完引导，在同一页点**「选择文件并导入」**。
</Step>
<Step>
导入方式选**覆盖当前课表**（新课表本来就是空的，合并没必要）。
</Step>
<Step>
确认提示「导入成功，备份数据已恢复」。先别急着卸载旧版——
**核一遍课程、课表、时间模板都在**，再处理旧机。
</Step>
<Step>
新机重做一遍[权限](#场景-1刚装好15-分钟配到能用)：通知、焦点通知、自启动、电池无限制。
</Step>
</Steps>

没带旧机、也没备份文件的话，换两条路：
[二维码面对面传输](/docs/guide/import#二维码面对面传输)（两台都在手边）
或者提前配好[云同步](/docs/guide/sync-backup#云同步坚果云-webdav)。

<Callout type="warn">
  备份文件是误删后**唯一的恢复依据**。每学期至少导一次，存到网盘。
</Callout>

## 场景 4：临时调课 / 放假冲课

只影响这一周这一次，用**停课**，不要用删除——删了课表结构就断了。

<Steps>
<Step>
在课表上点这门课，打开操作面板。
</Step>
<Step>
**只是这周不上** → 点「停课」→ **停本周**。
**这门课整个学期都不上了** → 点「停课」→ **全部停**。
</Step>
<Step>
停掉的课在课表上显示**「停」**标记。要恢复就再打开面板点「恢复」。
</Step>
</Steps>

**是挪时间，不是取消** → 用「调课」：操作面板 → 调课 → 选目标周 / 星期 / 节次，
必要时改地点 → 确认调课。调课只改你当前看的这一周这一节，其他周次不动。

<Callout type="info">
  临时加一节课不用重新录：在课程名称栏点**「沿用已有课程」**，
  选已有的课自动带出简称、颜色、老师，只填新的星期和节次。
</Callout>

## 场景 5：两个校区作息不一样

主教学楼 45 分钟一节、实验楼连上 3 节这种情况，用**地点作息匹配**自动套模板。

<Steps>
<Step>
先建好**两套时间模板**（设置 → 时间模板 → 新建）。
</Step>
<Step>
右上角菜单 → **地点作息匹配** → 新建地点组，填名称（如「主教学楼」），
绑定一套模板。
</Step>
<Step>
加**地点关键词**：可以点「从课表地点选择」让应用先识别课表里出现过的楼栋，
也可以手填（如 `A主`、`A1`、`A6`）。匹配模式选**「前缀」**，更长的关键词优先。
</Step>
<Step>
用**「试匹配地点」**输入 `A1062` 验证命中哪套模板。
</Step>
<Step>
点**「重新匹配当前课表」**批量套用。
</Step>
</Steps>

<Callout type="warn">
  重新匹配会**清掉命中课程此前手动指定的模板**，没命中的课不受影响。
  有课节次超出目标模板节数时会拒绝套用，并列出未套用的课程名。
</Callout>

只想让**某一门课**用另一套作息（比如实验课在另一个校区），不用建地点组：
在课程编辑页的**「上课时间方案」**里直接指定——那就是「副时间表」。

## 场景 6：学校分夏令时和冬令时

用**日期作息规则**：右上角菜单 → 日期作息规则 → 添加日期规则，
填名称、起止日期、要套用的时间模板。到开始日那天，系统自动把该模板
设为全部课表的默认作息。

<Callout type="info">
  最多 **2 条**规则，区间不能重叠。某门课命中了地点组时，
  会优先用地点组的模板而不看日期规则——生效顺序见
  [名词与数据说明 → 时间相关](/docs/guide/glossary#时间相关)。
</Callout>

## 场景 7：和对象一起看课表

见[同步与备份 → 情侣课表](/docs/guide/sync-backup#情侣课表)。简短版：

<Steps>
<Step>
两边都装上应用。你点**「导出我的课表给对方」**，把文件发给 TA。
</Step>
<Step>
TA 在他自己的应用里点**「导入对方课表」**。
</Step>
<Step>
绑定成功后，首页右上角切**叠加视图**，下方直接列出**今日共同空闲**时段。
</Step>
<Step>
嫌每次传文件麻烦，两边都配**坚果云拉取**——**槽位必须选不一样的**
（你 1、TA 2），之后点「立即拉取对方课表」就能更新。
</Step>
</Steps>

## 场景 8：考试周

<Steps>
<Step>
**录考试**：右上角菜单 → 考试安排 → 右上角添加。关联课程、名称、日期、
起止时间必填；**考场留空就用上课教室**，也可以单独填，还能填座位号。
</Step>
<Step>
**设提醒**：不提醒 / 考前 30 分钟 / 1 小时 / 1 小时+30 分钟 / 1 天 / 1 天+1 小时；
都不合适就点**「添加提醒」**自定义（天/小时/分钟组合，可加多个）。
</Step>
<Step>
**放个倒计时在桌面**：加一个**考试倒计时 2×2** 小组件。
</Step>
<Step>
考试期间课表上会显示**「考试」**标记；考完的自动归到「已结束」。
</Step>
<Step>
考完试记得把**上课闹钟**关掉——它在系统时钟里，不认假期也不认停课。
</Step>
</Steps>

<Callout type="info">
  考试提醒依赖通知权限。没开的话考试照样保存，但提醒可能送不到。
</Callout>

## 场景 9：早八一定要响

超级岛是通知，被系统管控时可能迟到。早八这种必须叫醒的用**上课闹钟**兜底。

<Steps>
<Step>
点开早八那节课，在操作面板点**「设这节课的闹钟」**。
</Step>
<Step>
确认弹窗信息（每周 X HH:MM，提前 N 分钟），在系统时钟里点**保存**。
</Step>
<Step>
同时保留超级岛：设置 → 超级岛与通知，确认**上课前提醒**已开，
提前量设在 10–20 分钟。
</Step>
<Step>
电池优化设成**「无限制」**，并打开自启动。
</Step>
</Steps>

<Callout type="warn">
  系统闹钟**不认假期、不认停课**，到期就响。放假前记得去
  **系统时钟**里关掉，应用内只能取消记录。
</Callout>

## 场景 10：新学期开始了

<Steps>
<Step>
**先导出备份**：设置 → 数据备份与迁移 → 导出全部数据。留个回退点。
</Step>
<Step>
**新建一张课表**：右上角菜单 → 课表管理 → 新建，命名「大二下」之类。
旧课表留着不删，随时能切回去对比。
</Step>
<Step>
**改开学日期与学期周数**（设置 → 点顶部摘要卡）。这一步最容易忘。
</Step>
<Step>
在新课表里[导入或录入](/docs/guide/import)课程。
</Step>
<Step>
核一遍**时间模板**（有些学校新学期作息会调）。
</Step>
<Step>
旧的桌面小组件如果还指着旧课表，到
[设置 → 桌面小组件 → 各卡片绑定管理](/docs/guide/widget#各卡片绑定课表)改绑定。
</Step>
</Steps>

## 场景 11：要一次录很多课

手机上一条条填太慢，用**局域网编辑**：设置 → 局域网编辑 → 开启，
在电脑浏览器打开显示的地址、输 PIN，就能在电脑上编辑手机课表。
页面显示「已连接 N 台」和最近活动，用完点**停止**。

也可以走[表格导入](/docs/guide/import#表格导入)——在电脑上填好 CSV
再传回手机导入，比手机上敲字快得多。

<Callout type="warn">
  局域网编辑只在局域网内传输，不上传云端。
  但在宿舍/公司这种共享网络下**用完及时停**，别一直开着。
</Callout>

## 场景 12：学期末想看看这学期有多忙

右上角菜单 → **课程统计**。里面有热力图、课程排行、教室与教师排行、
12 个成就徽章和一段自然语言总结。

想每周自动收到小结：**课程统计页 → 右上角设置 → 本周课程小结**，
打开后每周日 21:00 推送。

统计页右上角**分享**可以把统计导出成**长图（PNG）或 PDF**，
带官网二维码，适合发社交平台。

详见[课程统计](/docs/guide/statistics)。
