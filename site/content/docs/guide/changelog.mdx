## v2.1.2 正式版

2026-09-09 发布。

**新增**

- 桌面卡片「情侣课表」：导入 TA 课表后，卡片可绑定「情侣课表」合并视图，我的课与 TA 课按周偏移映射到同一时间轴，同时段同名合并为「一起课」，我 / TA / 一起三色区分
- 情侣课表卡片后台实时合并：应用不在前台时仍按双方课表实时计算，TA 开课倒计时照常走字

**优化**

- 玻璃模式由四档收敛为「实体卡片 / 高斯模糊 / 液态玻璃」三档，原先独立的「启用模糊」开关并入档位
- 壁纸页开关更名为「顶栏玻璃 / 信息栏玻璃」，材质跟随全局玻璃模式
- 关闭模糊后的说明文案改为准确描述实际表现

**修复**

- 实体卡片模式下部分菜单弹窗文字看不清
- 教务导入：`http` 开头的学校门户恢复可导入
- 情侣课表卡片跨周与停课显示错配

## v2.1.1.8 预发布

2026-09-08 发布。

**新增**

- 首页「二级悬浮菜单」：右上角菜单展开为悬浮玻璃卡，添加课程 / 日程 / 考试直接选中
- 悬浮卡片液态玻璃质感，与主菜单同一套材质
- 关于页「请喝咖啡」入口、鸣谢名单新增成员

**优化**

- 教务数据更新与鸣谢名单在 GitCode / 蒲公英渠道下走国内镜像直连
- 首次同步不再被冲突提示挡路
- 超级岛与上课提醒在后台限制下自动重试
- 诊断页新增自启动状态检测
- 课程详情展开动画、下拉快捷导入、日程与考试时间选择、输入框对比度、更新弹窗排版等一批体验优化

**修复**

- 更换壁纸或切换日 / 周课表时偶发闪退
