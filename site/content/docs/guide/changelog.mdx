## v2.1.3.1 预发布

2026-09-22 发布。

**新增**

- 日视图课卡天气：日视图两张课卡上显示当节天气（温度与图标），周视图课卡与课程详情弹层一并接上，三处共用同一套展示；数据来自免费天气服务并本地缓存，断网时显示上一次的结果
- 天气设置页：可选城市与数据来源，「显示位置」三选与「显示内容」三个开关，每项都能单独关掉
- 天气一键定位：用当前位置取天气；系统定位拿不到时退回按网络估算，并在界面上如实标注这是估算值
- 一键同步课表到系统日历：点一下把课程写进系统日历里一个本应用专属的日历（不依赖任何云账户），重复点击不产生重复日程，节假日是否跳过跟随该页开关，不想要了可在应用内一键移除
- 「外观编辑」页：整个首页按真机比例缩成一张预览，顶部直接切日 / 周视图，底部进壁纸与材质设置，改完立刻在预览里看到效果；入口有三处
- 壁纸位置编辑页支持双指缩放：放大后拖动跟手 1:1，「重置」把位置与缩放一起归位
- 日视图「回今日」浮钮：底部居中的玻璃按钮，显示今日是周几与秒数，尺寸与底栏一致
- 「液态玻璃」材质：全局玻璃模式多出这一档，高级材质页可逐项微调；课程卡片也能单独选这一档
- 材质面板分成「通用」与「课程卡片」两页：卡片材质可以单独配，不再只能跟着全局走
- 课程弹窗改用系统同款形态：底部弹窗与居中玻璃对话框换成系统一致的样式，面板仍是本应用的液态玻璃

**优化**

- 玻璃更省电：柔光档模糊半径基线 60 → 32（约省 2.5 倍渲染开销）；顶栏渐进模糊改为按像素记忆化，每打开一个新页面不再整条重算（原先每页固定 36~49ms）；被上层压住的玻璃不再占采样名额；字体选择弹层首帧不再卡
- 外观编辑页版式：顶栏收成一行、日 / 周切换挪到标题位置、预览卡放大
- 预览出图节奏：拖动过程中照常出图，不用先停手
- 天气设置页：数据来源置顶、说明文字收窄，打开开关即定位
- 首页菜单条目行距统一为紧贴，去掉分类边界那道多余空行
- 卡片磨砂滑杆：拉到 0 才是真的完全清透（量程一并收成 0~24）
- 材质命名：六种语言里的材质名统一为「液态玻璃」

**修复**

- 首页右上角菜单让位：一级整张卡朝右收（支点钉在被点那一行的右上角）、二级面板不跟着缩、被点那一行不再显示成两份、二级玻璃不再把一级玻璃采进去造成重影；原先那道 10px 接缝一并归零
- 玻璃的一批观感问题：顶栏玻璃带底部那条黑边、返回键圆底顶部那圈暗弧、贴底弹窗上沿的暗色线、课程卡片边光只剩四个角的白钩、壁纸页四颗悬浮按钮的玻璃在转场里偏在一边、悬浮钮「两层圈圈」、圆钮展开收起后明暗抖动、柔光球在壁纸上的白边过重、弹窗开合时的黑影块、模糊一开就有的黑边
- 日视图：「回今日」在惯性还没停时点不动；滑回原日后星期栏多亮一格
- 下拉快捷导入：需要「到顶部再拉一下」才触发；下拉收起时页面会被一起滚走
- 自定义文字色与强调色：放在壁纸上时改为保留色相、只调明暗，不再直接压成黑白
- 天气：不是本周的灰卡不再显示天气行；天气图标改为「第一个勾上的项目」认领；设置子页补齐区块标题与间距
- 桌面小组件色条颜色不跟着刷新（表现为「字是绿的、色条是红的」）
- 外观编辑：从日视图进编辑页不再闪回周视图；小屏进场的预览从第一帧就带圆角；非缩放路径不再烤到转场中的歪画面
- 壁纸相关的两处：卡片的预模糊底图现在跟随壁纸对齐值，卡内外背景不再错位；设置里壁纸行的文件名在别的系统存下的路径下不再显示成一整条路径

## v2.1.2 正式版

2026-09-09 发布。

**新增**

- 桌面卡片「情侣课表」：导入 TA 课表后，卡片可绑定「情侣课表」合并视图，我的课与 TA 课按周偏移映射到同一时间轴，同时段同名合并为「一起课」，我 / TA / 一起三色区分
- 情侣课表卡片后台实时合并：应用不在前台时仍按双方课表实时计算，TA 开课倒计时照常走字

**优化**

- 玻璃模式由旧四档收敛为「实体卡片 / 高斯模糊 / 柔光玻璃 / 液态玻璃」四档，原先独立的「启用模糊」开关并入档位
- 壁纸页开关更名为「顶栏玻璃 / 信息栏玻璃」，材质跟随全局玻璃模式
- 关闭模糊后的说明文案改为准确描述实际表现

**修复**

- 实体卡片模式下部分菜单弹窗文字看不清
- 教务导入：`http` 开头的学校门户恢复可导入
- 情侣课表卡片跨周与停课显示错配
