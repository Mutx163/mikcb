## v3.0.0 预发布（尚未发版）

> **发布状态**：已定档预发布渠道，尚未打 tag、未上架，官网 `releases` 页要等 GitHub Release 发布后才会自动出现本版。以下条目对照仓库内 `docs/releases/v3.0.0.md` 整理，发版后以实际安装包与 Release 正文为准。

本次重点：全站界面换成 Compose 重写版、首页多了月视图、云备份恢复前先看差异。

本版要求 Android 13（minSdk 33）及以上。老用户可直接覆盖安装，课表、日程、壁纸和设置都会保留；只有教务导入的登录状态需要重新登录一次。

**新增**（共 20 条，这里挑 8 条）

- 全站界面换成 Compose 重写版：页面、弹层、玻璃材质和转场统一到 miuix 组件，滚动与切页更跟手，不再依赖 Flutter 运行时
- 首页多了月视图：周 / 日 / 月三个同级视图，停在哪个视图会记住，冷启动回到原视图
- 首页底栏换成可左右滑的玻璃底栏：切页有跟手转场，圆钮只给当前页亮
- 首页「更多功能」汇总页：没有固定入口的页面按分类收齐，八宫格磁贴
- 课表导出与分享：导出干净课表图，截屏后也会提示分享
- 云备份恢复前先看差异：恢复拆成「预览差异 → 确认」两步，恢复后还能撤销
- 通知点击落回对应页面：冷启动和已运行两路都解析
- 外观编辑：整屏缩成卡片的入场 / 出场，改完即时预览

**优化**（共 12 条，这里挑 4 条）

- 底栏玻璃更省：切页时不再每帧重算整屏模糊
- 月视图拖动更顺：拖动时不再每帧重建整页
- 顶栏玻璃统一成官方做法，各页面自动跟着生效
- 六种语言文案补齐：新界面补上译文，清掉过长的中文和没人用的文案

**修复**（共 20 条，这里挑 4 条）

- 月视图：设了壁纸就进不去、矮屏面板被挤成 0
- 壁纸：删除档案会误删别的课表在用的图
- 备份 / 云同步 / 整份传输：个别字段类型不对导致整份备份被拒或整档静默消失
- 全站按钮底色统一：修掉一百多处按钮和背景同色、看不出能点的问题

**移除**

- 旧版 Flutter 页面与运行时已下线，安装包只保留 Compose 一套界面。

## v2.1.4.1 预发布

2026-10-19 发布。本次重点：更新日志改成「本次重点 + 分类分组」、软件更新页重做、转场更顺。

**新增**

- 更新日志有了「本次重点」与分类分组：每个版本顶部最多 3 条重点，条目按新增 / 优化 / 修复 / 移除分组并带条数；更新弹窗、软件更新页、历史版本页与官网共用同一份
- 历史版本页改成「3 条重点 + 分类计数 + 分组展开」，121 个历史版本补齐各自的本次重点

**优化**

- 软件更新页重做：一个状态只给一个动作，版本关系压成一行「旧 → 新」
- 应用图标换成「发丝描边 + 同色系极轻投影」
- 首页菜单改成「先收缩、再推页面」
- 转场更顺：进页面时把悬浮钮、回今日钮与顶栏玻璃带冻结成预糊位图

**修复**

- 软件更新页三个真问题：「已是最新版本」下面挂着能点的「立即下载」、检查失败被画成「已是最新版本」、下载中按钮文案错误
- 「查看 Release」以前永远打开 GitCode 某个版本页，现在按当前下载渠道选主机
- 并发下载同一张壁纸时，其中一次会误报「写入失败」
- 备份恢复写盘没有走设置事务，中途被杀会留下混合态

## v2.1.3.4 预发布

2026-10-18 发布。本次重点：设置页「桌面小组件效果预览」、桌面小组件周末文案。

**新增**

- 桌面小组件周末文案：周六、周日一节课都没排时显示「周末愉快」，周五没课了显示「周末要开始了」；调休上班的周末不算周末，周末有课时也不会误显示

## v2.1.3.3 预发布

2026-10-18 发布。本次重点：超级岛「速览」、壁纸画质恒按最高档、更新提示只显示本次重点。

**新增**

- 超级岛「速览」：显示设置页加悬浮按钮，不用先选课就能让岛按当前阶段弹出约 30 秒；起岛成功后 App 自动退到后台，岛直接出现在桌面
- 课前快捷操作的勿扰选项：需要哪些权限提前可见，下课恢复不会越权改回别的设置，另加一个「优先通知」档

**优化**（共 9 条，这里挑 5 条）

- 更新提示只显示本次重点：3 条短标题 + 新增 / 优化 / 修复 / 移除各多少条，完整内容在同一弹窗里点「查看全部」展开
- 壁纸画质恒按最高档：不再需要自己挑三档；Bing 静默降尺寸时自动识别，并按相邻档重试
- 壁纸图库：缩略图有看得见的加载态、失败可点重试，大图下载显示百分比
- 启动：启动画面加入场动效，换入首页加一次交叉淡入，最短停留从 650ms 缩到 400ms
- 自动换壁纸的几种结局各有一句话，不再有安静无声的结局

**修复**（共 49 条，这里挑 5 条）

- 一大批保存失败被吞掉的问题：删除课程、作业、考试、作息、设置等几十个入口，失败时会如实提示
- 备份恢复遇到畸形数据不再静默清空，缺整份课程字段的备份也不再被当成空课表清掉
- 时间口径一批：没补零的 9:00 不再排到 10:00 后，早八不再算进晚间
- 教务密码自动填充与可分享日志收紧：云端数据不能再换白名单，课程名、教室、定位坐标在日志里都会脱敏
- 更新与传输的信任链：更新校验只信直连渠道，安装包直链逐跳校验

## v2.1.3.1 预发布

2026-09-22 发布。

**新增**

- 日视图课卡天气：日视图两张课卡上显示当节天气（温度与图标），周视图课卡与课程详情弹层一并接上，三处共用同一套展示；数据来自免费天气服务并本地缓存，断网时显示上一次的结果
- 天气设置页：可选城市与数据来源，「显示位置」三选与「显示内容」三个开关，每项都能单独关掉
- 天气一键定位：用当前位置取天气；系统定位拿不到时退回按网络估算，并在界面上如实标注这是估算值
- 一键同步课表到系统日历：点一下把课程写进系统日历里一个本应用专属的日历（不依赖任何云账户），重复点击不产生重复日程，节假日是否跳过跟随该页开关，不想要了可在应用内一键移除
- 「外观编辑」页：整个首页按真机比例缩成一张预览，顶部直接切日 / 周视图，底部进壁纸与材质设置，改完立刻在预览里看到效果；入口有三处
- 壁纸位置编辑页支持双指缩放：放大后拖动跟手 1:1，「重置」把位置与缩放一起归位
- 日视图「回今日」浮钮：底部居中的玻璃按钮，显示今日是周几与秒数，尺寸与底栏一致
- 「液态玻璃」材质：全局玻璃模式多出这一档，高级材质页可逐项微调；课程卡片也能单独选这一档
- 材质面板分成「通用」与「课程卡片」两页：卡片材质可以单独配，不再只能跟着全局走
- 课程弹窗改用系统同款形态：底部弹窗与居中玻璃对话框换成系统一致的样式，面板仍是本应用的液态玻璃

**优化**

- 玻璃更省电：柔光档模糊半径基线 60 → 32（约省 2.5 倍渲染开销）；顶栏渐进模糊改为按像素记忆化，每打开一个新页面不再整条重算（原先每页固定 36~49ms）；被上层压住的玻璃不再占采样名额；字体选择弹层首帧不再卡
- 外观编辑页版式：顶栏收成一行、日 / 周切换挪到标题位置、预览卡放大
- 预览出图节奏：拖动过程中照常出图，不用先停手
- 天气设置页：数据来源置顶、说明文字收窄，打开开关即定位
- 首页菜单条目行距统一为紧贴，去掉分类边界那道多余空行
- 卡片磨砂滑杆：拉到 0 才是真的完全清透（量程一并收成 0~24）
- 材质命名：六种语言里的材质名统一为「液态玻璃」

**修复**

- 首页右上角菜单让位：一级整张卡朝右收（支点钉在被点那一行的右上角）、二级面板不跟着缩、被点那一行不再显示成两份、二级玻璃不再把一级玻璃采进去造成重影；原先那道 10px 接缝一并归零
- 玻璃的一批观感问题：顶栏玻璃带底部那条黑边、返回键圆底顶部那圈暗弧、贴底弹窗上沿的暗色线、课程卡片边光只剩四个角的白钩、壁纸页四颗悬浮按钮的玻璃在转场里偏在一边、悬浮钮「两层圈圈」、圆钮展开收起后明暗抖动、柔光球在壁纸上的白边过重、弹窗开合时的黑影块、模糊一开就有的黑边
- 日视图：「回今日」在惯性还没停时点不动；滑回原日后星期栏多亮一格
- 下拉快捷导入：需要「到顶部再拉一下」才触发；下拉收起时页面会被一起滚走
- 自定义文字色与强调色：放在壁纸上时改为保留色相、只调明暗，不再直接压成黑白
- 天气：不是本周的灰卡不再显示天气行；天气图标改为「第一个勾上的项目」认领；设置子页补齐区块标题与间距
- 桌面小组件色条颜色不跟着刷新（表现为「字是绿的、色条是红的」）
- 外观编辑：从日视图进编辑页不再闪回周视图；小屏进场的预览从第一帧就带圆角；非缩放路径不再烤到转场中的歪画面
- 壁纸相关的两处：卡片的预模糊底图现在跟随壁纸对齐值，卡内外背景不再错位；设置里壁纸行的文件名在别的系统存下的路径下不再显示成一整条路径

## v2.1.2 正式版

2026-09-09 发布。

**新增**

- 桌面卡片「情侣课表」：导入 TA 课表后，卡片可绑定「情侣课表」合并视图，我的课与 TA 课按周偏移映射到同一时间轴，同时段同名合并为「一起课」，我 / TA / 一起三色区分
- 情侣课表卡片后台实时合并：应用不在前台时仍按双方课表实时计算，TA 开课倒计时照常走字

**优化**

- 玻璃模式由旧四档收敛为「实体卡片 / 高斯模糊 / 柔光玻璃 / 液态玻璃」四档，原先独立的「启用模糊」开关并入档位
- 壁纸页开关更名为「顶栏玻璃 / 信息栏玻璃」，材质跟随全局玻璃模式
- 关闭模糊后的说明文案改为准确描述实际表现

**修复**

- 实体卡片模式下部分菜单弹窗文字看不清
- 教务导入：`http` 开头的学校门户恢复可导入
- 情侣课表卡片跨周与停课显示错配
