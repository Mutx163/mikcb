这一页讲的是「课程在应用里怎么增删改」。课表从哪来见[导入与迁移](/docs/guide/import)。

## 先理解三个概念

应用把一次上课拆成三层，理解后所有操作都不会迷路。三个词的确切含义见
[名词与数据说明 → 三个层次](/docs/guide/glossary#三个层次课程--排课--单节课)，这里只讲怎么用：

- **课程**：以课程名称为唯一标识。改名称等于新建一门课，想改显示效果请改**简称**
- **排课记录**：一门课的一个上课时间。高数周一 1-2 节、周三 3-4 节就是两条排课
- **单节课**：落在某一个具体周次上的一次课。**调课、停课、本节课备注都作用在这一层**

## 添加课程

<Steps>
<Step>
在首页点**右上角菜单 → 添加**，或点玻璃坞中间的**圆钮**。
</Step>
<Step>
弹出「添加」面板，三选一：**添加课程**（整学期重复课）、**添加日程**、**添加考试**。
选「添加课程」。
</Step>
<Callout type="info">
  添加页对共享字段有明确说明：**课程简称、颜色、性质、简介等字段，
  会同步给同名课程的其他排课记录**。也就是说改一处，同名课一起变。
</Callout>

<Step>
填写**共享信息**区（对同名课程的所有排课生效）：

- **课程名称**（必填）：课程唯一标识，填完整名
- **课程简称**（建议填）：用于超级岛等场景，建议 3 个汉字以内。可点「取前两字」自动生成
- **课程性质**：必修 / 选修
- **课程简介**（可选）：同名课程共享，长期有效
- **课程颜色**：点色块打开调色盘，支持 HSB 精确调色
</Step>
<Step>
填写**上课安排**区（只影响这一条排课）：

- **星期 / 开始节次 / 结束节次**：连堂填起止，单节课起止相同
- **上课周次**：见下方「周次设置」
- **授课教师 / 上课地点**：可从历史记录里选，不用重复输入
- **上课时间方案**：默认「跟随当前课表」，只有这节课的上下课时间和课表不一致时才改
</Step>
<Step>
点**保存**。提示「课程添加成功」即完成。
</Step>
</Steps>

### 沿用已有课程

临时加课时不必重新填一遍。在课程名称栏右侧点**「沿用已有课程」**，
选择课表里已有的课程，会自动带入课程名、简称、颜色等共享信息，
你只需要填新的星期 / 节次 / 周次。

<Callout type="info">
  课表里还没有任何课程时，这个按钮没有可选项。先手动录入一门，之后临时加课就能直接选了。
</Callout>

### 一次添加多个上课时间

一门课一周上多次（如周一和周三），在添加页底部点**「添加排课时间」**，
可以在同一个页面里继续加第二条、第三条排课，而不用保存后再重新添加一遍。

## 周次设置

「上课周次」支持两种模式，用顶部标签切换：

| 模式 | 用法 |
| --- | --- |
| **连续周** | 填开始周到结束周，再选「全部 / 单周 / 双周」过滤 |
| **自定义周** | 逐周勾选，适合不连续的周次。支持「全选 / 单周 / 双周」批量操作 |

页脚会实时显示「已选 N 周：第 X、Y、Z 周」，方便核对。

<Callout type="warn">
  至少选择一个上课周次，否则保存时会提示「请至少选择一个上课周次」。
</Callout>

## 点开课程能做什么

在首页点课程卡片（周视图、日视图都可以），会打开课程操作面板。
面板顶部显示课程名、性质、周次与节次，下面是可选的快捷入口：

| 入口 | 说明 |
| --- | --- |
| **备注** | 打开备注面板，见下方「课程备注」 |
| **添加任务 / 任务清单** | 给这门课建一条待办，见[任务清单](/docs/guide/organize) |
| **设这节课的闹钟** | 走系统时钟通道的闹钟，见[超级岛与提醒](/docs/guide/super-island) |

底部三个按钮是主要操作：

- **编辑课程**（主按钮）：打开完整编辑页，可改所有字段与全部排课
- **调课**：把本周这一节挪到别的周 / 星期 / 节次
- **停课 / 恢复**：暂停某一周或全部周次

删除在右上角：点右上角菜单里的「删除课程」。

### 调课

调课只影响**当前查看的这一周这一节**：原课在这一周被移除、新位置生效，
其他周次完全不变（提示原文是「仅改第 N 周本节，原课该周移除，其他周不变」）。

<Steps>
<Step>
在课程操作面板点**「调课」**。
</Step>
<Step>
确认提示里的信息：原位置（第 N 周 · 星期 X · 第 A-B 节 · 地点）。
</Step>
<Step>
选择**调到目标周**、**星期**、**开始节次 / 结束节次**，必要时改**上课地点**。
</Step>
<Step>
点**「确认调课」**。提示「已调到 第 N 周 星期X 第A-B节」即完成。
</Step>
</Steps>

<Callout type="info">
  只有当前查看周次里**确实有这节课**时才能调课。如果这一周这门课本来就没排，
  调课按钮是禁用的——只能走「编辑课程」改排课本身。
</Callout>

### 删除

点右上角菜单的「删除课程」后，会让你选删除方式：

| 选项 | 效果 |
| --- | --- |
| **删这个课** | 删除这条排课的全部周次 |
| **删这节课** | 只删除当前查看周次的这一次 |

<Callout type="warn">
  如果当前卡片不是这一周的真实排课（例如你正在看「显示非本周课程」的半透明卡片），
  只能删整条排课，删单节的选项不可用。
</Callout>

### 停课

临时放假、老师出差，用停课比删除更合适——课表结构保留，之后能一键恢复。

在课程操作面板点「停课」，二选一：

- **停本周**：仅暂停当前周这一次。适合临时冲掉一节课
- **全部停**：暂停所有周次。适合这门课整体停了

停课的课程在课表上会显示「停」标记。再次打开面板点「恢复」即可复原。

## 课程备注

备注分两层，用途不同：

| 层级 | 作用范围 | 适合记什么 |
| --- | --- | --- |
| **课程简介** | 同名课程共享，长期有效 | 课程说明、老师风格、教室位置 |
| **本节课备注** | 仅对第 N 周这一次课生效 | 作业、要带的物品、课堂提醒 |

在课程操作面板点「备注」打开面板。勾选**「有作业」**后，
周视图的课程卡片上会显示一个作业圆标，一眼能看出哪节课有作业要交。

## 课程总览与编辑

右上角菜单 → **课程总览**，可以按列表方式查看和编辑全部课程：

- 右上角切换排序：**按添加顺序 / 按课程名称 / 按排课时间**
- 有排课冲突时，顶部会显示「冲突 N 节」入口，点进去看具体冲突组合
- 每条课程显示共排课节数，有冲突的会提示「展开查看冲突详情」
- 空课表时页面会提示「长按课表或点击右上角添加课程」

## 一键重新配色

觉得整套颜色不好看，不用重新导入：右上角菜单 → **课表重新配色**。

- 点**「换一批颜色」**随机刷一套
- 用**「上一套 / 下一套」**在历史配色间来回切换，顶部显示「第 N/M 套」
- 不满意可以回到导入时的原色

<Callout type="info">
  重新配色只影响颜色，不动课程与排课。空课表时会提示先导入或添加课程。
</Callout>
