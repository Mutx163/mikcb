不打开应用也能看到课表，主要靠桌面小组件。

## 今日小组件

显示当天的课程安排，并会与**课程快照**同步更新。

添加方式：长按桌面空白处 → 小组件 → 找到轻屿课表 → 拖到桌面。

## 课程统计小组件

提供两种尺寸：

| 尺寸 | 内容 |
| --- | --- |
| 2×2 | 精简的课程统计 |
| 2×4 | 更完整的统计信息 |

统计内容包括学期 / 周双视图、趋势、热力图，以及教师与教室排行。

## 刷新机制

小组件由系统在特定时机刷新，同时应用在课表变更、课程快照更新时也会主动推送。

<Callout type="warn">
  如果小组件长时间不更新，检查电池优化是否限制了该应用的后台活动。设为「无限制」后通常恢复正常。
</Callout>

## 玻璃坞与外观

应用提供两种形态：

- **经典界面**
- **玻璃坞**：液态玻璃风格的底部导航

课程卡片支持真折射玻璃样式，也可以自定义壁纸。这些属于纯外观选项，不影响功能。
