不打开应用也能看到课表，主要靠桌面小组件。入口：**设置 → 桌面小组件**。

## 可用卡片

应用提供 10 种尺寸/用途的卡片：

| 卡片 | 内容 |
| --- | --- |
| **主卡 2×2** | 今日课程精简展示 |
| **迷你列表 2×2** | 更紧凑的课程列表 |
| **概览 2×4** | 更完整的今日课程 |
| **列表 4×4** | 大尺寸课程列表 |
| **今日横条 4×1** | 一行横条 |
| **今日横宽 4×2** | 横向宽卡 |
| **统计 2×2** | 精简课程统计 |
| **统计概览 2×4** | 更完整的统计 |
| **统计横条 4×1** | 一行统计 |
| **考试倒计时 2×2** | 下一场考试倒计时 |

点小组件会直接打开首页（或绑定的课表页面）。

## 添加方式

<Steps>
<Step>
进入**设置 → 桌面小组件**。
</Step>
<Step>
在「**快速添加到桌面**」区点想要的卡片。
</Step>
<Step>
支持的桌面会**直接弹出系统添加确认**（不是权限弹窗），确认后即可固定到桌面。
</Step>
<Step>
不支持应用内添加时，按提示**长按桌面 → 小组件 → 轻屿课表**，手动添加对应卡片。
</Step>
</Steps>

<Callout type="info">
  页面会先显示「正在检查当前桌面是否支持应用内添加小组件…」，
  然后把结果显示在说明里。以页面实际显示为准。
</Callout>

## 各卡片绑定课表

桌面上可以同时放多张卡片，**每张卡片可以绑定不同的课表**。

在页面底部的「**各卡片绑定管理**」区，为每张已添加的卡片选一个来源：

- **跟随当前课表**：切课表时卡片内容跟着变（默认）
- 直接指定**某张具体课表**
- **情侣课表**：显示情侣叠加后的课（我的 + TA 一起）
- **TA 的课表**：只显示对方的课

后两项只在导入过对方课表后出现。

<Callout type="info">
  桌面上还没有卡片时，这里会提示「先添加一张再回来绑定」。
  卡片绑定的课表被删掉后，打开时会提示「这张卡片绑定的课表已失效」并按普通方式打开。
</Callout>

## 显示项

| 项目 | 说明 |
| --- | --- |
| **背景样式** | 半透明玻璃感 / 纯色卡片 / 渐变卡片 |
| **课程颜色** | 关闭（经典配色）/ 仅色条 / 色条+文字 |
| **显示地点** | 关闭后改显周次与课程数 |
| **显示倒计时** | 显示下节课倒计时 |
| **隐藏已上完课程** | 只显示未结束的课程 |
| **课后显示明日课程** | 今日课程结束后自动显示明天 |

### 倒计时提前量

设置上课前多少分钟自动切换到倒计时模式：

- **始终显示**
- **上课前 5/10/15/20/30/40/50/60 分钟**

下面还有**倒计时样式**可选。

## 卡片外观

| 项目 | 范围 |
| --- | --- |
| **卡片高度** | -16 ~ 16，0 为默认档。正数更高，负数更矮 |
| **卡片圆角** | 拖动调节 |

高度和圆角都是**全局**的，改了之后所有卡片一起变。

## 精确闹钟权限

如果页面顶部出现「**精确闹钟权限未授予**」提示条，点「去授权」开启。

未授予时，课程边界只能**非精确刷新**，桌面卡片可能延迟更新。

<Callout type="info">
  授权失败时会打开应用信息页，在其中手动开启「闹钟和提醒」权限即可。
</Callout>

## 刷新机制

小组件由系统在特定时机刷新，同时应用在**课表变更、课程开始与结束**时也会主动推送。

<Callout type="info">
  没改课表时卡片内容本来就不会变——**先手动加一节课试试**，
  如果加了也不动才是真的没刷新。
</Callout>

<Callout type="warn">
  小组件长时间不更新时，按顺序检查：

  1. **电池优化**是否限制了后台活动（设为「无限制」）
  2. **精确闹钟权限**是否已授予
  3. **移除小组件后重新添加**
  4. 确认课表确实有变更（无变更时内容不会变）

  另外注意：**假期期间小组件会隐藏课程**，如果整周空白先检查节假日标记。
</Callout>
