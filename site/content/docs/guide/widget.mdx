不打开应用也能看到课表，主要靠桌面小组件。

## 添加小组件

<Steps>
<Step>
长按桌面空白处，进入编辑模式。
</Step>
<Step>
点「小组件」，在列表里找到轻屿课表。
</Step>
<Step>
把需要的尺寸拖到桌面。
</Step>
<Step>
长按已放置的卡片可调整大小或进入设置。
</Step>
</Steps>

## 卡片类型

**今日系列**

显示当天的课程安排，会与**课程快照**同步更新。提供多种尺寸，从迷你列表到横向宽卡，适应不同桌面布局。

**课程统计小组件**

| 尺寸 | 内容 |
| --- | --- |
| 2×2 | 精简的课程统计 |
| 2×4 | 更完整的统计信息 |

统计内容包括学期 / 周双视图、趋势、热力图，以及教师与教室排行。详见[课程统计](/docs/guide/statistics)。

**情侣课表卡片**

导入 TA 的课表后，卡片可以绑定「情侣课表」合并视图：

- 我的课与 TA 的课按周偏移映射到同一时间轴
- 同时段同名课程合并为「一起课」
- 我 / TA / 一起三色区分，一眼看清
- 点击卡片打开情侣课表覆盖层

也可以单独绑定「TA 的课表」而不合并。TA 解绑后卡片自动回落「跟随当前课表」。

## 卡片绑定哪张课表

每张卡片都可以单独选择数据来源：当前课表、某张指定课表，或情侣课表。**改课表不会连带影响其他卡片**，这是多课表场景下的关键设计。

## 课程颜色

今日系列卡片支持课程色显示，三档可选：

| 档位 | 效果 |
| --- | --- |
| 关闭 | 回到经典配色 |
| 仅色条 | 课程名前加一根课程色竖条 |
| 色条 + 文字 | 竖条与课程名、状态胶囊文字都用课程色 |

颜色按 WCAG 相对亮度自动钳制——浅色卡只压暗、深色卡只提亮，色相不变，浅黄、青柠这类浅色系在浅底上也看得清。

## 刷新机制

卡片由系统在特定时机刷新，应用在**课表变更**、**课程快照更新**时也会主动推送。应用不在前台时，情侣课表卡片仍按双方课表实时合并，TA 的开课倒计时照常走字。

<Callout type="warn">
  如果小组件长时间不更新，检查电池优化是否限制了该应用的后台活动。设为「无限制」后通常恢复正常。
</Callout>

## 玻璃坞与外观

应用提供两种形态：

- **经典界面**
- **玻璃坞**：液态玻璃风格的底部导航

课程卡片支持真折射玻璃样式，也可以自定义壁纸。玻璃模式分为「实体卡片 / 高斯模糊 / 液态玻璃」三档，纯外观选项，不影响功能。
