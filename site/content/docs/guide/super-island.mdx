title: 超级岛与提醒
description: 提醒时段配置、超级岛显示内容、上课前快捷操作、上课闹钟与自检诊断的完整操作。
---

这是轻屿课表最核心的能力：把课程状态接进系统通知体验，不用打开应用也能知道
「下一节在哪、这节课上到哪」。

## 前置条件

开始配置前，先确认两件事：

- **通知权限**已授予（Android 13+ 必需）
- 想用超级岛的话，系统需 **HyperOS 3.0.300 及以上**，且开启**焦点通知 / promoted ongoing** 权限

详见[快速开始 → 权限清单](/docs/guide/quick-start#权限清单引导第-3-页)。

<Callout type="info">
  系统版本不够时应用**仍可正常发普通提醒**，只是没有超级岛效果。
</Callout>

## 入口与结构

**设置 → 超级岛与通知**。页面分三组：

| 分组 | 内容 |
| --- | --- |
| **提醒** | 提醒时段（开关与时机） |
| **显示内容** | 上课前提醒显示、课中/下课提醒显示 |
| **维护与自检** | 后台保活、自检 |

## 提醒时段

### 提醒开关

| 开关 | 说明 |
| --- | --- |
| **上课前提醒** | 课程开始前 N 分钟弹出 |
| **课中与下课提醒** | 上课后到下课前的展示。这一项同时控制「课中」和「下课」两段 |

两个开关可自由组合，互不影响。

### 重点提醒切入时机

控制课中阶段什么时候切到「重点提醒」（超级岛 + 高优先级通知）：

| 选项 | 效果 |
| --- | --- |
| **一上课就切换** | 一上课进入重点提醒，下课前 N 秒开始秒级倒数 |
| **下课前 5/10/15/20/30 分钟** | 到点才切到超级岛与重点提醒 |

下方的说明文字会实时告诉你当前组合的实际效果，例如「课中普通通知，下课前 10 分钟重点提醒」。

### 展示方式

| 开关 | 说明 |
| --- | --- |
| **课中状态栏通知** | 上课后是否在状态栏保留通知 |
| **展示超级岛** | 关闭后不触发系统超级岛（仍走普通通知） |

### 时间阈值

| 项目 | 可选值 | 说明 |
| --- | --- | --- |
| **上课前弹出时间** | 1/5/10/15/20/30/40/50/60 分钟 | 课前多久开始提醒 |
| **下课前秒级阈值** | 15/30/45/60/90 秒 | 进入秒级倒数的时机 |
| **课中时间样式** | 最近时间 / 总时长 | 紧凑提醒里显示什么 |

「最近时间」显示距离下一个时间点（如下课）还有多久，「总时长」显示这节课
一共多长。空间小的岛用「最近时间」更好读。

### 铃声时间矫正

学校铃声比课表快或慢时，用这个滑块整体平移：

- 铃声比课表**快** → 设置**提前**（负值）
- 铃声比课表**慢** → 设置**延后**（正值）

范围 ±30 秒。

## 显示内容

两组配置分别对应两个阶段：

- **上课前提醒显示**：课前倒计时阶段的显示
- **课中与下课提醒显示**：上课中和下课提醒阶段的显示

两组**互不影响**。也可以打开「跟随上课前提醒设置」，让课中/下课阶段完全沿用课前配置
（打开后下面的独立设置会变灰不可编辑）。

### 显示字段开关

| 开关 | 说明 |
| --- | --- |
| **显示课程名** | 是否显示课程名 |
| **优先显示课程简称** | 有简称时优先用简称。建议简称控制在 3 个字以内 |
| **显示地点** | 超级岛会显示上课地点 |
| **显示倒计时** | 打开后会出现「倒计时格式」选项 |
| **显示阶段状态文案** | 关闭倒计时后仍显示「即将上课 / 上课中 / 下课提醒」 |
| **隐藏前缀文案** | 隐藏「即将上课」这类前缀 |

### 倒计时格式

显示倒计时打开后可选。注意刷新频率差异：

- **纯分钟样式**按分钟刷新（省电）
- **带秒样式**按秒刷新（更精确，但更耗电）

可选：智能、智能（带秒）、分秒（中文 / 冒号 / m s / m/s）、
仅分钟（中文 / m / 斜杠）、仅秒（中文 / 简写）。

### 上课前快捷操作

只在**上课前提醒的展开通知**里显示，可以在课前一键开启静音或免打扰：

| 选项 | 说明 |
| --- | --- |
| 不显示 | 不显示快捷操作 |
| 打开静音 | 提供「静音」按钮 |
| 打开免打扰 | 提供「免打扰」按钮 |
| 静音和免打扰 | 两个都提供 |

<Callout type="info">
  按钮点了没反应通常是**权限没给**：免打扰第一次用会跳系统授权页，
  授权后才有反应。取消静音/免打扰失败时应用会弹提示，不会静默失败。
</Callout>

下面还有一个**「自动执行」**选项（可选 5/10/15/20/30 分钟）：到点自动打开所选模式，
**下课后自动恢复，重启手机也会恢复**。

<Callout type="warn">
  免打扰**首次使用会跳到系统授权页**需要先授权。
  快捷操作在下课后会自动恢复，不用担心忘关。
</Callout>

### 超级岛预览

这两页顶部都有**实时预览卡片**，直接显示当前配置下超级岛长什么样，
包含三个阶段：即将上课 / 上课中 / 下课提醒。改任何开关都会即时更新，
**不用等下一节课才能看效果**。

### 左侧图标与展开态

| 项目 | 说明 |
| --- | --- |
| **小米岛左侧文字图标** | 把课程名或地点生成到左侧图标位（仅小米手机样式生效） |
| 左侧文字内容 | 课程名 / 地点 / 课程名+地点 |
| 左侧图标样式 | 仅文字 / 图标+文字 |
| 左侧图标 Logo | 自定义图片，可调节圆角 |
| 左侧文字大小 / 水平偏移 / 垂直偏移 / 粗细 / 清晰度 | 精细调整排版 |
| **展开态大图标** | 应用图标 / 自定义图片 / 隐藏 |

<Callout type="info">
  左侧文字图、展开态大图标和自定义图片都**按当前阶段单独保存**——
  课前和课中可以配成两套不同的样子。
</Callout>

### 展开详情逐字段自定义

展开超级岛后显示的 9 行信息，可以**逐行决定显隐和顺序**：

阶段、课程简称、进度、状态、上课时间、地点、老师、下节课、备注。

- 用每行的**开关**决定显示还是隐藏
- 用**上下箭头**调整顺序（顺序即行序）
- 隐藏的字段会归到「已隐藏」分区，随时可以加回来
- 点**「恢复默认顺序与显示」**回到初始状态

<Callout type="warn">
  全部字段都关掉时，展开态会没有正文。此时系统会自动回退显示摘要文案，
  不会出现「可展开的空通知」。
</Callout>

## 上课闹钟

与超级岛/普通通知不同，**上课闹钟走系统时钟应用（AlarmClock）**，
即使应用被清理也会响。适合早八这类必须叫醒的场景。

<Callout type="info">
  闹钟是**交给系统时钟管的**，所以手机没装可处理的时钟应用时会提示
  「未找到可处理的时钟应用」。这是系统限制，不是应用坏了。
</Callout>

### 单节课闹钟

<Steps>
<Step>
点开课程卡片，在操作面板里点**「设这节课的闹钟」**。
</Step>
<Step>
确认弹窗里的信息：会在系统时钟创建**每周 X HH:MM 的重复闹钟**，
比上课提前 N 分钟响（N 取你在设置里的提前量），并按这节课的上课周次重复。
在弹层里选择：

- **上课前 N 分钟提醒**（快捷档，N 取你在设置里的提前量，默认 30 分钟）
- **自定义提醒时间…**：自己选具体时刻
- **打开系统时钟**：直接进系统时钟管理已有闹钟
</Step>
<Step>
不想要默认提前量的话，在弹层里点**「自定义提醒时间…」**自己选时刻。
</Step>
<Step>
也可以点**「打开系统时钟」**直接管理已有闹钟。
</Step>
<Step>
确认后跳转到系统时钟保存页，**在系统时钟里点保存**才算完成。
</Step>
</Steps>

如果这节课已经设过闹钟，弹层顶部会显示「已设提醒：HH:MM」，
底部有**「取消」**按钮可以移除记录。

<Callout type="info">
  这节课的节次时间超出当前时间模板时，会提示「这门课的节次超出时间模板，
  无法设置闹钟」。先核对时间模板再设闹钟。
</Callout>

<Callout type="warn">
  系统闹钟**无法识别假期与调休，也不管你有没有停课**，到期照常响铃。
  删除闹钟需要到**系统时钟**里完成，应用内只能取消记录。
</Callout>

## 后台保活

设置 → 超级岛与通知 → **后台保活**。两项可选：

| 选项 | 说明 |
| --- | --- |
| **从最近任务中隐藏应用** | 开启后应用尽量不显示在最近任务列表 |
| **轻屿课表后台保活服务** | 系统无障碍服务，仅用于后台刷新小组件与重排课程提醒 |

<Callout type="info">
  保活服务**不会读取屏幕内容，也不会代替你执行任何点击操作**。
  开启需要在系统设置中授予「无障碍」权限，可随时关闭。
</Callout>

## 自检（测试与诊断）

设置 → 超级岛与通知 → **自检**。这是排查超级岛问题的主战场。

| 功能 | 说明 |
| --- | --- |
| **测试通知** | 点「开始测试」发送一条测试通知，约 8 秒内进入上课前提醒阶段，用于验证超级岛、通知栏和课程简称的显示效果。测试中有「取消测试」 |
| **选课测试** | 选一门真实课程 + 一个阶段（课前倒计时约 3 分钟 / 上课中约 4 分钟），**强制起岛**。没有真实课程时会改用自检预设课程（不写入课表）。起岛后顶部显示「选课测试中 · 课程名」，点「停止测试」恢复正式调度 |
| **上岛状态诊断** | 显示原生实时服务状态、通知构造结果，以及具体「不上岛原因」 |
| **自动刷新** | 每秒自动拉取诊断状态，关掉后只在手动刷新时更新 |
| **假期状态覆盖** | 模拟假期状态，用来验证提醒和小组件是否正确隐藏课程 |
| **本地诊断日志** | 一键导出日志或状态快照，直接通过系统分享发给开发者；也可以清空后重新收集 |
| **查看手机日志** | 打开完整应用日志 |

下面还有一组只在测试版出现的按钮（崩溃测试、异常卡顿测试），
用来验证崩溃和卡顿上报，正式版看不到。

<Callout type="info">
  状态快照适合发给开发者：它包含完整的原生字段，比截图有用得多。
</Callout>

<Callout type="warn">
  选课测试和发送测试通知后，**请按 Home 键回到桌面查看**——
  停留在应用内时系统通常不会弹出超级岛。
</Callout>

### 诊断页分区

- **环境与权限**：系统版本、通知权限、焦点通知等
- **服务状态**：原生实时服务是否运行中
- **课程数据 / 时间与阶段 / 阶段开关 / 岛显示配置**：当前生效的配置快照
- **通知判定结果**：是否判定为应该上岛
- **最近诊断日志**：原生侧的实时记录
- **原始调试数据**：默认折叠，排查时展开核对完整原生字段

## 排查清单

如果超级岛或提醒不生效，按顺序检查：

<Steps>
<Step>
**通知权限**是否已授予（Android 13+ 必需）。
</Step>
<Step>
**时间模板与开学日期**是否与实际一致，时间错了提醒自然不准。
</Step>
<Step>
**当前课表**是否选对，通知跟随当前课表；当天是否有课。
</Step>
<Step>
**是否在假期内**——超级岛在假期期间不显示。
</Step>
<Step>
**焦点通知权限**是否开启（超级岛前置条件）。
</Step>
<Step>
**自启动与电池优化**：自启动开启、电池设为「无限制」。
</Step>
<Step>
用**自检页**发一条测试通知，看「不上岛原因」里写了什么。
</Step>
</Steps>

<Callout type="warn">
  部分厂商 ROM 对后台和通知的管控较激进。即使开关全部打开，深度睡眠时仍可能被限制。
  这种情况建议把**上课闹钟**作为兜底——它走系统时钟通道，即使应用被清理也会响。
</Callout>
