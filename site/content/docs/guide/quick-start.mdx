这一页覆盖从「装好应用」到「课表能正常提醒」的完整路径。全程约 5 分钟。

## 下载与安装

- 正式包发布在 [GitHub Releases](https://github.com/Mutx163/mikcb/releases)，当前以 `arm64-v8a` 为主
- 也可以从[官网](https://163366.xyz)下载最新版本
- 系统要求：Android 8.0（API 26）及以上，重点适配小米 / HyperOS 设备

应用为 GPL-3.0 开源，无需注册账号，也没有广告。

之后更新版本时，进**设置 → 关于 → 关于软件**点版本更新即可在应用内下载安装；
下载慢或失败时可在高级选项里切换下载渠道与镜像线路。详见[更新与支持](/docs/guide/about)。

<Callout type="warn">
  **方法数/架构不匹配**是安装失败的常见原因。正式包以 `arm64-v8a` 为主，老设备请先确认 CPU 架构，再选择对应产物；不确定时直接下载 `arm64-v8a`，近几年的主流机型都支持。
</Callout>

### 在应用内更新

不想每次去网页下载的话，**设置 → 关于 → 关于软件 → 版本更新**可以直接检查与下载：

| 项目 | 说明 |
| --- | --- |
| **下载安装包方式** | 应用内下载（下完直接弹安装界面）/ 系统管理器（交给系统下载管理器，完成后从通知安装） |
| **下载渠道** | 国内下载 / 国际源下载；网络不通时切换试试 |
| **下载线路与镜像** | 点「测速并推荐」自动挑最快的镜像，也可以自己填自定义镜像前缀 |
| **检测测试版本** | 打开后会把测试版纳入更新检查。普通使用建议关闭 |
| **弹窗提醒** | 发现新版本时在首页自动弹窗；关掉后只在图标上显示红点 |

<Callout type="info">
  GitHub 访问不稳定时会看到「暂时无法读取版本信息」。这不是应用坏了，
  切到国内下载方式或换个网络再试即可。
</Callout>

## 首次启动引导

首次打开会进入一段分页引导，共 5 页，**建议完整走完再开始用**：

<Steps>
<Step>
**第 1 页 · 欢迎**：选择语言，然后选择接下来要做什么——
「开始使用」「导入课表」「从备份恢复」三个入口都在这一页。
</Step>
<Step>
**第 2 页 · 隐私协议**：向下滚动读完隐私、第三方 SDK 与免责说明，勾选
「我已阅读并同意友盟相关隐私说明」后才能继续。不勾同意无法进入应用。
</Step>
<Step>
**第 3 页 · 系统权限**：按页面顺序逐项点开系统设置页授权，返回应用后状态会自动刷新。
</Step>
<Step>
**第 4 页 · 个性化定制**：选择菜单样式（列表 / 八宫格）、导航形态（经典 / 玻璃坞）、
视觉效果（实体卡片 / 高斯模糊 / 液态玻璃）、深浅色模式与主题色。这些**立即生效**，
之后都能在「设置 → 外观与配色」里改。
</Step>
<Step>
**第 5 页 · 使用技巧**：课程简称建议、三种导入方式说明，以及最后 3 条提醒
（超级岛的系统版本要求、先调好提醒阈值、用测试通知验证）。
</Step>
</Steps>

<Callout type="info">
  引导页顶部有进度提示（如「2/3 已完成」）。每一页都需要滑到底部才能进入下一页，
  避免没看到关键信息就跳过。

  已经用过的老用户不用担心找不回来：**设置 → 使用引导与权限**可以随时重新打开
  引导（权限页、个性化页、技巧页都在里面）。隐私那一页是只读的，不需要再勾一次同意。
</Callout>

## 权限清单（引导第 3 页）

如果你主要使用超级岛或实时通知，**这一页必须全部做完**。按页面给出的顺序操作最省事：

| 项目 | 作用 | 不做会怎样 |
| --- | --- | --- |
| 申请通知权限 | 所有提醒的前提 | 提醒、超级岛全部收不到 |
| 打开通知设置 | 检查通知总开关、锁屏展示、实时通知权限 | 锁屏看不到、通知被折叠 |
| 打开焦点通知设置 | HyperOS 3.0.300+ 的 promoted / 超级岛权限 | 普通通知正常，但不上岛 |
| 打开自启动设置 | 允许开机自启与后台常驻 | 重启后提醒链路不恢复 |
| 打开电池策略设置 | 建议改成「无限制」 | 深度睡眠时提醒延迟或丢失 |
| 打开后台保活辅助 | 进一步提升后台稳定性 | 后台被杀概率升高 |

<Callout type="warn">
  不同 MIUI / HyperOS 版本的入口名称差异较大。找不到某一项时，在系统设置里搜索
  「自启动」「电池优化」「焦点通知」。**自启动受系统限制，应用读不到真实状态**，
  请以系统页面里的开关为准。
</Callout>

### 权限状态怎么看

第 3 页顶部会显示「已就绪 N/M」。各项状态含义：

- **通知权限**：已开启 / 未开启
- **焦点通知 / 超级岛**：系统已允许 / 已开启但系统暂未确认 / 建议检查
- **电池优化**：无限制 / 仍受限制
- **超级岛系统支持**：需 HyperOS 3.0.300 及以上

<Callout type="info">
  系统版本不够时**应用仍可正常发普通提醒**，只是没有超级岛效果。可以先正常用，
  等系统升级后再打开焦点通知。
</Callout>

## 设置时间模板与时间基准

导入或录入课程前，先把两个时间基准定下来，**否则提醒会整体偏移**。

<Steps>
<Step>
**设置开学日期**：进入「课表设置」，点顶部摘要卡（显示「当前第 N 周 / 共 M 周」），
进入学期设置后选「设置开学日期」。可选范围 2020 年至 2035 年。
</Step>
<Step>
**设置学期周数**：同页选「选择学期周数」，按本校实际教学周数调整。
</Step>
<Step>
**同步当前周**：如果显示的当前周和实际不符，点「同步当前周」一键对齐。
（需要先设置开学日期，否则这一项是灰的。）
</Step>
<Step>
**配置时间模板**：进入「课表设置 → 时间模板」，按本校作息调整每节课的起止时间。
</Step>
</Steps>

<Callout type="warn">
  **开学日期没设置会连带影响很多功能**：导出日历里的课程、单节课闹钟、
  统计里的学期进度都会报「请先设置学期开始日期」。这是新手最常见的问题。
</Callout>

## 首页快速上手

装好课表后，首页这几个位置用得最多：

| 位置 | 操作 |
| --- | --- |
| 左上角标题 | 点击切换课表（可选「经典文字」或「大 Logo」样式） |
| 顶部信息栏 | 点周次切换周；「回本周」按钮回到当前周 |
| 课表网格 | 左右滑动切周；点课程卡片打开详情与操作面板 |
| 空网格区域 | 不响应点击——要点右上角或圆钮明确选择添加什么 |
| 右上角菜单 | 列表菜单或八宫格菜单，可自定义条目与排序 |
| 底部玻璃坞（玻璃坞形态） | 切「周课表 / 日课表」，中间圆钮快速添加 |
| 页面顶部下拉 | 开了「首页下拉快捷导入」时，下拉直接重跑一次教务快捷导入 |

<Callout type="info">
  首页顶部还有一对**情侣课表开关**（开启叠加视图 / 关闭），只在导入过对方课表后
  才有意义。详见[同步与备份 → 情侣课表](/docs/guide/sync-backup#情侣课表)。
</Callout>
