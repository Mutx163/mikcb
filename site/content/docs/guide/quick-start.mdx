## 下载与安装

- 正式包发布在 [GitHub Releases](https://github.com/Mutx163/mikcb/releases)，当前以 `arm64-v8a` 为主
- 也可以从[官网](https://163366.xyz)下载最新版本
- 系统要求：Android 8.0（API 26）及以上，重点适配小米 / HyperOS 设备

应用为 GPL-3.0 开源，无需注册账号，也没有广告。

## 首次启动建议开启的权限

如果你主要使用超级岛或实时通知，建议在系统设置里同时打开：

<Steps>
<Step>
**通知权限**：Android 13+ 需要显式授予，否则收不到课前提醒。
</Step>
<Step>
**自启动**：保证重启后提醒链路能自动恢复。
</Step>
<Step>
**电池无限制**：避免系统后台冻结导致提醒延迟或丢失。
</Step>
<Step>
**焦点通知 / promoted ongoing 权限**：超级岛显示的前置条件。
</Step>
</Steps>

<Callout type="warn">
  不同 MIUI / HyperOS 版本的入口名称差异较大。若找不到某一项，可在系统设置中搜索「自启动」「电池优化」「焦点通知」。
</Callout>

## 设置时间模板

导入或录入课程前，建议先按学校作息配置节次时间：

1. 进入设置中的**时间模板**
2. 按本校作息调整每节课的起止时间
3. 保存后，课表的行高与提醒时间会按新模板计算

时间模板会影响提醒的触发时刻。如果模板与实际作息不符，课前提醒会整体偏移。
