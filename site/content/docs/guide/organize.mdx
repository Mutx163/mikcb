除了课程，应用还能管考试、日程和作业任务。三者互不干扰：
**日程按具体日期插入日视图时间线，不会改动课程本身**。

## 考试安排

入口：**右上角菜单 → 考试安排**。

### 添加考试

<Steps>
<Step>
在考试列表页点右上角**添加**图标，或在首页添加面板里选**「添加考试」**。
</Step>
<Step>
填写**关联课程**（必选，从当前课表的课程里选）。
</Step>
<Step>
填写**考试名称**（必填）、**考试日期**（必选）、**开始时间 / 结束时间**。
</Step>
<Step>
**考场**留空则使用上课教室，也可以单独填；还可填**座位号**。
</Step>
<Step>
设置**提醒**：不提醒 / 考前 30 分钟 / 1 小时 / 1 小时+30 分钟 / 1 天 / 1 天+1 小时，
也可以点「添加提醒」自定义（按天/小时/分钟组合，可添加多个）。
</Step>
<Step>
**备注**选填。点保存。
</Step>
</Steps>

### 列表能看什么

- 顶部概览：今日 N 场 / 共 N 场，以及**倒计时**（「今天」或「N 天后」）
- 正在进行的考试会显示「进行中」标记与「至 HH:MM」
- 每张卡片显示时间区间、考场、座位、提醒状态（已设提醒 / 未设提醒）
- 已结束的考试归到「已结束」分区

考试倒计时也可以放到桌面：**考试倒计时 2×2** 小组件。

<Callout type="info">
  考试安排会进入提醒链路，按你配置的提前量通知。
  考试提醒依赖通知权限，未开启时日程/考试仍会保存，但提醒可能无法送达。
</Callout>

## 日程安排

日程是「非课程的一次性或重复性安排」：开组会、办证件、拿快递、自习。

入口：**右上角菜单 → 日程安排**，点右上角**添加**。

### 添加日程

| 字段 | 说明 |
| --- | --- |
| **日程标题** | 必填 |
| **日期** | 开始日期 / 结束日期。跨日会在卡片上显示「跨日」标记 |
| **时间** | 开始时间 / 结束时间。同日结束时必须晚于开始 |
| **地点** | 选填 |
| **日程颜色** | 选一个容易和课程区分的颜色 |
| **备注** | 选填 |

### 重复设置

| 选项 | 说明 |
| --- | --- |
| **不重复** | 单次日程 |
| **每天** | 按天重复 |
| **每周** | 按开始日期对应的星期重复（显示「每周X」） |

选择重复后**必须设置结束日期**，否则会提示「请选择重复结束日期」。

### 日程提醒

可设置「不提醒」或「提前 N 分钟」。

### 编辑与删除范围

改一条**重复日程**时，会先问**编辑范围**：

- **仅本次**：只改这一次
- **全部重复日程**：改整个系列

删除同理，会问**删除范围**：「仅删除本次」或「删除全部重复日程」。

### 暂停日程

日程可以**暂停**而不删除。暂停后归入「已暂停」分区，不会显示提醒。

列表按**即将到来 / 进行中 / 已过期 / 已暂停**分区展示。

<Callout type="warn">
  导入课程时选择「替换现有」会**同时清空当前课表上的独立日程**。
  如果日程很重要，替换前先确认。
</Callout>

## 任务清单

作业和待办的轻量管理。入口：**右上角菜单 → 任务清单**。

### 添加任务

两个入口：

- 任务清单页点右上角**添加**
- **点开课程卡片 → 在操作面板点「添加任务」**：会自动关联这门课和当前周次

| 字段 | 说明 |
| --- | --- |
| **任务标题** | 必填，例如「完成第三章习题」 |
| **备注** | 补充说明，选填 |
| **截止日期** | 可选，不填就是「无截止日期」 |
| **来源课程** | 从课程卡片进来时自动填好 |

从课程卡片添加时，如果该课程当前周已有任务，会直接打开那条任务让你编辑。

### 筛选与分组

- 顶部按时间筛选：**全部 / 今日 / 本周**
- 也可按**课程筛选**（全部课程 / 无关联课程 / 具体课程）
- 列表分三个区：**已逾期 / 任务清单（进行中）/ 已完成**
- 勾选任务即标记完成；**长按一条任务可以直接删除**

### 与课程联动

任务关联课程后，在课程操作面板里会显示这条任务的标题，
下面标注「任务清单」或「已完成」。点进去可直接编辑。

<Callout type="info">
  另一种轻量方式：在课程备注里勾选**「有作业」**，
  周视图的课程卡片上会显示作业圆标。适合不用管理截止日期的场景。
</Callout>

## 冲突检测

两门课排在同一时段时会自动检测出来。入口：**右上角菜单 → 冲突**。

- 课程总览页顶部在有冲突时显示「冲突 N 节」，点进去看详情
- 冲突页按**冲突组合**列出，显示「与「XXX」冲突」
- 绑定了情侣课表时，还能直接「查看对方排课」

首页也能看到：默认在冲突课程上显示「冲突」小胶囊（可在课程卡片设置里关掉）。

<Callout type="info">
  冲突课程会自动**层叠显示**。在「设置 → 课程卡片 → 冲突课程透明度」
  里调低透明度，可以同时看到多节课。
</Callout>
