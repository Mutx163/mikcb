## 课表与周次

**为什么显示的「当前周」和实际不一样？**

开学日期没设对。进入**设置**，点顶部摘要卡 → 设置开学日期，
然后点「同步当前周」对齐。周次由开学日期推算，不是手机日历周。

**单双周怎么设？**

在课程编辑页的「上课周次」里：连续周模式下选「单周」或「双周」；
自定义周模式下点「单周 / 双周」批量勾选。详见[课程与排课](/docs/guide/courses#周次设置)。

**这周突然没课了怎么办？**

用**停课**而不是删除：点开课程 → 「停课」→「停本周」。
课表结构保留，之后可一键恢复。

**有两门课撞在同一时间？**

应用会自动检测并在卡片上显示「冲突」小胶囊。点右上角菜单 → 冲突看详情。
冲突课程会自动层叠显示，可调低透明度同时看多节。详见[考试、日程与任务](/docs/guide/organize#冲突检测)。

## 提醒与超级岛

**为什么超级岛不显示？**

按顺序看：系统需 HyperOS 3.0.300+、开启焦点通知权限、通知权限、
当天有课、不在假期内。然后到**设置 → 超级岛与通知 → 自检**看「不上岛原因」。
详见[超级岛与提醒 → 排查清单](/docs/guide/super-island#排查清单)。

**测试通知发了但岛没弹出来？**

**按 Home 键回到桌面**。停留在应用内时系统通常不弹超级岛。

**提醒比实际铃声早/晚几十秒？**

用**「铃声时间矫正」**滑块整体平移（±30 秒）。铃声比课表快就设提前，
慢就设延后。

**假期里超级岛不弹、小组件是空的？**

正常。法定节假日和自定义假期期间，超级岛、提醒和小组件都会隐藏课程。
到「设置 → 节假日标记」看有没有假期覆盖今天。

**学校放假安排和国家规定不一样怎么办？**

内置的是全国统一数据，学校特殊安排要手动覆盖：
**设置 → 节假日标记 → 自定义假期 → 添加假期**，把需要上课的日期选上，
**类型选「调休上班」**。它优先级最高，能盖住法定假期，
保存后课程、提醒、超级岛和小组件一起恢复。
详见[故障排查 → 假期日期和学校的不一样](/docs/guide/troubleshooting#假期日期和学校的不一样)。

**想让早八一定能响，怎么办？**

两个一起开：超级岛提醒 + **上课闹钟**。闹钟走系统时钟通道，
即使应用被清理也会响。注意闹钟**不认假期和停课**。
见[常见场景怎么做 → 场景 8](/docs/guide/recipes#场景-9早八一定要响)。

**后台被杀了收不到提醒怎么办？**

打开自启动、电池设为「无限制」、开启后台保活辅助。仍不行的话用
**上课闹钟**兜底——它走系统时钟通道，即使应用被清理也会响。

## 课程数据显示

**课程简称为什么不自动填？**

设计如此。简称需要你手动填（可点「取前两字」），建议 3 个汉字以内。
超级岛和小组件空间有限，长名会被截断。

**改了课程名，之前的记录没了？**

课程**以名称作为唯一标识**，改名字等于新建了一门课。
要改显示效果请改简称，不要改课程名。

**一门课一周上两次怎么加？**

不用添加两次。在添加页底部点**「添加排课时间」**，
同一门课可以有多条排课记录。

## 数据与多设备

**换手机怎么迁移？**

三种方式任选：[完整备份导出 → 新机导入](/docs/guide/sync-backup#数据备份与迁移)、
[二维码面对面传输](/docs/guide/import#二维码面对面传输)、或配置 WebDAV 云同步。

**两台设备怎么保持同步？**

配置**云同步**（坚果云 WebDAV）。它是显式的，不会后台静默上传；
每次同步都会保留一个可恢复版本。

**备份文件能直接打开看吗？**

可以，它是明文数据文件。但**不建议手动编辑**——格式可能随版本调整，
改坏了应用会提示导入失败。

**局域网编辑安全吗？**

数据只在局域网内传输，不上传云端，用完点「停止」即关闭访问。
但在公共网络下建议不要长时间开启。连不上时看
[故障排查 → 局域网编辑连不上](/docs/guide/troubleshooting#局域网编辑连不上)。

**情侣课表为什么看不到对方的课？**

八成是**坚果云槽位选重复了**——两边必须选不同槽位。其余原因和排查顺序见
[故障排查 → 情侣课表看不到对方的课](/docs/guide/troubleshooting#情侣课表看不到对方的课)。

**换机后二维码传输中途断了？**

重新开始即可，常见提示的含义都列在
[故障排查 → 二维码传输中断](/docs/guide/troubleshooting#二维码传输中断)。

## 权限与隐私

**为什么必须给这么多权限？**

通知、自启动、电池无限制、焦点通知这几项是**提醒链路能跑起来的前提**。
不给也能用课表本体，但收不到提醒、看不到超级岛。

**教务系统账号会被上传吗？**

不会。账号密码只在你本机与学校服务器之间传输。
云同步快照里会包含你记住的学校账号，所以用云同步时务必使用应用专用密码。

**友盟统计是什么？必须开吗？**

是可选的第三方统计与性能监控 SDK，**只有你勾选同意后才会初始化**。
首次启动引导的隐私页里可以完整阅读说明。

**无障碍权限是干什么的？**

只用于「后台保活辅助服务」——后台刷新桌面小组件与重排课程提醒。
**不会读取屏幕内容，也不会代替你执行任何点击操作**，可随时关闭。

## 外观

**液态玻璃很卡怎么办？**

在**设置 → 外观与配色 → 磨砂玻璃**里把玻璃模式改成「实体卡片」或「高斯模糊」。
中低端设备建议不要开液态玻璃。

**设置改乱了怎么恢复？**

各设置页底部都有「恢复默认设置」，按范围重置（不影响课程数据）。
注意重置课表页面会**一并清除壁纸**。

**改了壁纸后信息栏文字看不清？**

应用会自动检测对比度，不足时切换成自动白/黑并给出提示。
也可以在「课表页面 → 文字颜色」里手动换色。

## 导入相关

**教务导入要我的账号密码，会有风险吗？**

账号密码只在你本机与学校服务器之间传输，不经过应用作者。「记住密码」的凭据
也只存在本机。用云同步时快照里会包含记住的学校账号，所以务必用
**应用专用密码**。

**「快捷导入」是什么？要不要每次都重新录？**

它是把第一次导入的操作步骤存下来（**不含账号密码**），以后点一下自动重放。
教务网站改版后失效，重录一次就行。

**表格导入提示「未识别表格格式」？**

表头对不上。用导入页里下载的官方模板重填，必填列是
课程名 / 星期 / 开始节 / 结束节 / 上课周。

**AI 识图导入的课对不上？**

AI 会自己把可疑行写进「识别提醒」，先看那里。常见原因是截图**没带星期表头**，
或者把班级信息 `[1-3]班` 误识别成了节次。导入后逐条核一遍。

## 下载与更新

**在哪里下载？**

[GitHub Releases](https://github.com/Mutx163/mikcb/releases) 或[官网](https://163366.xyz)。
装了之后在**设置 → 关于 → 关于软件 → 版本更新**里可以直接检查更新。

**应用内检测不到新版本？**

应用从 GitHub Releases 读取版本信息，网络访问不了 GitHub 时就检测不到。
到「版本更新 → 高级选项」把下载方式切到**国内下载**，
再点「测速并推荐」换条镜像线路重试，或直接去 Release 页面下。

**下载很慢或一直失败？**

同样在「版本更新 → 高级选项」里处理：保持「国内下载」，
在「下载线路与镜像」里测速推荐或手动换线路；都慢也可以填自定义镜像地址。

**下载完装不上？**

正式包以 `arm64-v8a` 为主，先确认设备架构，别的架构去 Release 页面找对应产物。

**正式版和测试版怎么选？**

普通使用关掉「测试版检测」。测试版更新快但可能不稳定，
而且只有调试/性能包才带内存状态这类诊断入口。

**哪里看每个版本改了什么？**

**设置 → 关于 → 关于软件 → 更新日志**，或在 GitHub Releases 看完整说明。

**能直接在应用里反馈问题吗？**

可以。**设置 → 关于 → 关于软件 → 问题反馈**里列了 GitHub Issue 和
小红书 / 酷安 / QQ 群等渠道。涉及日志的问题优先走 GitHub Issue。

**怎么支持作者？**

免费无广告的项目靠大家续命。**设置 → 关于 → 关于软件 → 请作者喝杯咖啡**，
金额随意。

下载渠道、镜像线路与反馈流程的完整说明见[更新与支持](/docs/guide/about)。

## 其他

**支持 iOS 吗？**

不支持。当前只面向 Android 维护，重点适配小米 / HyperOS 设备。

**支持哪些语言？**

界面支持简体中文、繁体中文（台湾 / 香港）、英文、日文、韩文。
在**设置 → 通用 → 语言选择**里切换。文档站目前只有简体中文。

**我的学校没有适配怎么办？**

先看[常见场景怎么做 → 场景 2](/docs/guide/recipes#场景-2我的学校没被适配)，
那里按「教务 → 表格 → AI 识图 → ICS → 手动」的顺序给了完整方案。
然后去 [qingyu_warehouse](https://github.com/Mutx163/qingyu_warehouse) 提 issue。
自己会写脚本的话，见[AI 协作适配教务](/docs/dev/jiaowu-adapter)。

**怎么反馈问题最有效？**

带上**设备型号、系统版本、应用版本、复现步骤和日志**。
日志收集方式见[故障排查 → 收集日志再反馈](/docs/guide/troubleshooting#收集日志再反馈)。
反馈渠道：GitHub Issue 最优先，也有 QQ 群、小红书、酷安等，
见[更新与支持](/docs/guide/about)。
