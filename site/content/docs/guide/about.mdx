## 怎么更新应用

**设置 → 关于 → 关于软件**，在「支持与更新」一栏点 **版本更新**。页面会显示当前版本、最新版本，以及「更新时间」。

- 有新版本时，直接点**「立即下载」**就行，下载完会交给系统安装
- 网络通畅时一般一次就能成功，不用管下面的高级选项

### 下载安装包方式

| 方式 | 说明 |
| --- | --- |
| **应用内下载** | 下载完成后直接在应用内弹安装界面。系统没弹出的话，从通知或文件管理器手动安装 |
| **系统管理器** | 交给系统下载管理器，完成后从系统通知安装 |

下载过程中可以**取消下载**。镜像源没返回总大小时，进度只显示已下载体积。

### 下载慢或失败时

页面下方有一组「下载方式」和「下载线路与镜像」的**高级选项**，只在下载不顺利时用：

| 项 | 说明 |
| --- | --- |
| **下载渠道** | **蒲公英下载**（国内高速，推荐）/ **GitHub 下载**（原生 + 国内镜像）/ **GitCode 直连**（发行版直连，国内速度快） |
| **下载线路与镜像** | 在国内下载方式下，可测速推荐线路、手动切换，或填自定义镜像地址 |

<Callout type="warn">
  下载方式切到国际源后，下面的线路设置就不生效了，需要先切回国内下载再调。
  填自定义镜像地址时，必须是完整的 `http` 或 `https` 开头地址。
</Callout>

### 新版本弹窗提醒

「弹窗提醒」开启后，发现新版本时首页会自动弹窗；关闭后只显示红点角标，不打扰。

### 测试版

想在正式发布前尝鲜，可以在更新页的高级选项里打开**测试版检测**（页面会标
「正式版 / 含预发布」）。测试版稳定性一般，不是主力机日常使用建议不要开。

## 关于软件这一页还有什么

设置 → 关于 → **关于软件**，整页分几块：

### 产品

| 条目 | 内容 |
| --- | --- |
| **项目定位** | 这是什么、适合谁、核心能力 |
| **导入与迁移** | 当前导入方式、备份恢复和迁移建议（四条，等于本站[导入与迁移](/docs/guide/import)的浓缩版） |
| **开源仓库** | GitHub 地址、Release 与反馈入口；也可以直接打开教务适配仓 |
| **参与教务适配** | 会抓包 / 网页调试 / JavaScript 的同学看这里 |
| **教务导入适配者** | 来自适配仓 maintainer 字段的名单，带「N 个适配项」计数。本地有缓存时先显示缓存再后台刷新 |
| **代码贡献者** | 开发人员与教务导入适配者名单 |

### 免责与风险提示

- 超级岛、焦点通知、后台提醒和保活效果依赖系统版本、机型、厂商策略、权限、
  自启动、电池策略等外部条件，**无法保证所有设备表现完全一致**
- 检查更新、镜像下载、导入导出与分享依赖网络环境与第三方服务
- 迁移或覆盖数据前，请先自行确认备份文件完整可用

### 社区与鸣谢

**问题反馈**页把渠道集中在一处，点一下就能复制或跳转：

| 渠道 | 操作 |
| --- | --- |
| GitHub Issue | 打开仓库 Issue 页，可提交问题、建议或查看已有反馈 |
| QQ 群 | 复制群号 |
| 酷安 | 复制酷安号 |
| 小红书 | 复制小红书号 |
| 微信公众号 | 复制公众号名称，到微信里粘贴搜索 |

打开失败时会提示「无法打开，已复制相关信息」，不至于让你卡住。

支持入口里是**微信 / 支付宝**二维码，可保存到相册；下面有**鸣谢名单**
（读的是仓库里的 `docs/donors.json`，加载失败只提示，不影响使用）。

<Callout type="info">
  「立即更新」提交给系统下载管理器后，会在系统通知里看到下载进度，
  完成后直接从通知栏安装即可。
</Callout>

## 看更新记录

同一页的**「更新日志」**列出了每个版本改了什么，升级前想了解变化可以翻一下。

## 遇到问题去哪反馈

应用内入口：**设置 → 关于 → 关于软件 → 问题反馈**。里面按问题类型列了不同渠道：

- **崩溃、课程显示异常、导入失败，或想提功能建议** → 优先走 **GitHub Issue**，
  页面可直接打开 Issue 页或复制地址
- 社区渠道：**小红书、酷安、QQ 群、微信公众号**（页面会复制对应号，去对应 App 搜索关注）

<Callout type="warn">
  涉及复现步骤、截图、版本号和日志的问题，**建议优先走 GitHub Issue**。
  社区私聊容易被刷掉，且不好贴日志。
</Callout>

### 这样反馈，开发才能快速定位

不是随便说「我的课表错了」。有效反馈带上这几样：

<Steps>
<Step>
**复现步骤**：一步一步做了什么才出现这个问题，越具体越好。
</Step>
<Step>
**设备与版本**：手机型号、Android / HyperOS 版本、应用版本号。
</Step>
<Step>
**截图或录屏**：能直观说明问题的最好。
</Step>
<Step>
**日志**：根据问题类型，从对应位置导出日志一起附上（见下）。
</Step>
</Steps>

不同问题去哪取日志，见[故障排查 → 收集日志再反馈](/docs/guide/troubleshooting#收集日志再反馈)。

### 学校没被适配？

导入课表时学校列表里没有你的学校，用导入页底部「缺少学校？去反馈」提交，
建议写上学校名称、教务系统网址、登录后课表页链接或截图。详见
[导入与迁移 → 学校列表里没有我的学校](/docs/guide/import#学校列表里没有我的学校)。

## 支持这个项目

轻屿课表是**开源、免费、无广告**的项目。如果你觉得好用，可以通过
**设置 → 关于 → 关于软件 → 请作者喝杯咖啡**（支持作者）打赏，金额随意。
支持入口里还有 QQ 群等交流渠道。

## 开源与许可

- 源码以 **GPL-3.0-or-later** 协议在 [GitHub](https://github.com/Mutx163/mikcb) 发布
- **设置 → 关于 → 关于软件 → 开源许可** 里列出了本应用用到的所有开源组件及其许可证，
  可以按组件名搜索，点进看全文
- 友盟统计等分析服务**只有在你于首次引导里勾选同意隐私说明后**才会启用，
  适用友盟自身的用户协议与隐私政策

## 隐私与第三方 SDK

这部分在首次启动引导第 2 页完整出现，之后可以在
**设置 → 关于 → 使用引导与权限 → 隐私协议**随时重看（只读，不用再勾一次同意）。

- 课表、时间模板、课程记录和大部分设置**默认保存在你的设备本地**
- 只有主动使用检查更新、下载更新、导入导出等联网功能，或你勾选同意后
  初始化友盟 SDK 时，才会与外部服务发生数据交互
- 接入的是友盟移动统计 SDK、应用性能监控 SDK 及高级运营分析依赖库
- 教务系统账号密码只在你本机与学校服务器之间传输

详见[官网隐私政策](https://163366.xyz)与
[快速开始 → 首次启动引导](/docs/guide/quick-start#首次启动引导)。
