## 数据存在哪里

- 课表、课程设置、备份文件默认保存在设备本地
- 教务导入的登录凭据可按你的选择保存在本地安全存储
- WebDAV 同步的快照存在你自己配置的第三方服务里，开发者不运营中心服务器
- 局域网编辑为可选能力，数据仅经本机 HTTP 服务，不经中心服务器

## 什么时候会联网

| 场景 | 目的 |
| --- | --- |
| GitHub Releases / 官网版本信息 | 检查更新、下载安装包 |
| 节假日数据 | 拉取公共节假日，失败时用内置兜底 |
| 教务系统 / 适配仓索引 | 你主动触发导入或同步时 |
| WebDAV | 你启用云同步时 |
| 局域网编辑 | 你主动开启后，同一局域网内浏览器读写课表 |

## 日志与诊断

应用日志默认仅用于本地排查更新、导入、提醒、页面与崩溃问题。**只有你主动导出并分享时，日志才会离开设备。**

## 第三方服务

在你同意隐私政策后，应用可能初始化友盟移动统计 / U-APM 等 SDK，用于匿名化使用统计与崩溃诊断。友盟是独立第三方服务，受其自身隐私政策约束。

官网（163366.xyz）使用 Google Analytics 了解页面访问情况，**仅在你点击「同意」后加载**；浏览器开启「禁止跟踪」时同样不加载。

<Callout type="info">
  可以在应用内清除日志、关闭统计记录；也可以随时清除官网本地存储中的同意记录。
</Callout>

## 用户协议要点

- 应用用于个人学习与课表管理，导入的数据来源须合法
- 不得利用本应用或适配脚本做破坏性、批量化或未经授权的数据抓取
- 提醒、超级岛、通知、小组件等表现受系统版本、厂商策略、权限与电池策略影响，无法保证所有设备完全一致
- 官网安装包以 Android `arm64-v8a` 为主，安装前请确认系统版本、架构与来源可信度
- 预发布版本用于体验新功能，稳定性可能低于正式版
