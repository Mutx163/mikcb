## 第一次用，按顺序看这五步

<Steps>
<Step>
[快速开始](/docs/guide/quick-start) — 装好、走完引导、把权限开齐、
设好开学日期和时间模板
</Step>
<Step>
[导入与迁移](/docs/guide/import) — 教务导入 / 表格 / ICS / AI 识图 / 二维码，
挑一条把课表弄进来
</Step>
<Step>
[课程与排课](/docs/guide/courses) — 补简称、加课、调课、停课
</Step>
<Step>
[超级岛与提醒](/docs/guide/super-island) 和 [桌面小组件](/docs/guide/widget) —
让锁屏和桌面也能看到课
</Step>
<Step>
[同步与备份](/docs/guide/sync-backup) — 导出一份备份，换机不至于从头再来
</Step>
</Steps>

<Callout type="warn">
  **三条最容易踩的坑**，出问题先查这三项：

  1. **开学日期没设**（或设错了）→ 周次不对、提醒偏移、统计和导出日历报错
  2. **课程简称没填** → 超级岛和小组件上课程名被截断
  3. **时间模板和本校作息不符** → 提醒时刻整体偏，行高也不对
</Callout>
