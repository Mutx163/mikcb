## 环境准备

工具链版本以仓库为准（`android/gradle/wrapper`、`android/settings.gradle`、`android/app/build.gradle`），不要照官方模板抄版本：

| 工具 | 版本 |
| --- | --- |
| JDK | 21 |
| Gradle | 9.8.2（wrapper 锁定） |
| AGP | 9.4.1 |
| Kotlin | 2.4.21 |
| Android SDK | compileSdk 37 / targetSdk 36 / minSdk 33 |

## 常用命令

```powershell
# L0：单模块 JVM 单测（改哪个域跑哪个）
pwsh -File scripts/test-kotlin-module.ps1 -Module "pages/<域>"

# L1：编译验证（全机互斥闸门）
pwsh -File scripts/safe-gradle.ps1 :app:compileDevDebugKotlin

# L2：全量 JVM 单测
pwsh -File scripts/safe-gradle.ps1 :app:testDevDebugUnitTest
```

<Callout type="warn">
  L1 / L2 必须走 `scripts/safe-gradle.ps1`：闸门内置全机互斥锁，裸跑 `./gradlew` 会和并行任务抢锁。出包（`assemble*` / `bundle*`）与真机验证由维护者执行，不交给自动化脚本。
</Callout>

## 代码约定

- 页面结构、卡片、字号、颜色只用共享套件（`QingyuPageScaffold` / `QingyuPageList` / `QingyuCard` / `MiuixTheme.textStyles.*`），源码守卫 `ComposePageStyleGuardTest` 会判；需要保留的写法登记在 `tool/compose_style_exceptions/<域>.txt`，且只进不出会被判红
- JVM 单测写在 `android/app/src/test/kotlin/`；说「已验证」必须写明真机验证了哪条路径，写不出来就标「未验」
- 界面文案统一走 ARB（`i18n/` 六份），改完跑 `python tool/gen_compose_arb_catalog.py` 重新生成 `ArbCatalog.kt`
- 应用支持简体中文、繁体中文（台湾 / 香港）、英文、日文、韩文
- 修改超级岛规则时，需同步原生实现、预览组件与对应测试
- 编译 / 测试分工与提交纪律见仓库 [AGENTS.md](https://github.com/Mutx163/mikcb/blob/main/AGENTS.md)

## 提交与 PR

- 提交信息用中文，说明改了什么与为什么
- 小步提交，避免把无关文件一起提交
- 仓库是共享工作区，常有并行开发，提交前确认只暂存自己负责的路径

更完整的约定见仓库的 [CONTRIBUTING.md](https://github.com/Mutx163/mikcb/blob/main/CONTRIBUTING.md) 与 [行为准则](https://github.com/Mutx163/mikcb/blob/main/CODE_OF_CONDUCT.md)。

## 参与学校适配

教务适配在独立仓库 [qingyu_warehouse](https://github.com/Mutx163/qingyu_warehouse)。需要网页调试、抓包或 JavaScript 基础，欢迎为自己学校补充适配脚本。

**也可以用 AI 协作完成一次适配**：读 skill、打开教务页后由你自己登录、在已登录会话里探测接口。启动指令与安全红线见 [AI 协作适配教务](/docs/dev/jiaowu-adapter)。
