# 架构守卫域映射 —— pre-commit 红项归因的数据源（2026-10-20 立）
#
# 用途：架构守卫读的是**整个工作区**，并行会话的在途改动会顶爆别人的域。
# pre-commit 拦下时，.githooks/guard_attribution.sh 用本文件回答两个问题：
#   ① 红项守卫读哪些文件（域）；② 这些文件里有没有不属于本次提交的在途改动。
# 域与本次提交无交集 → 红项来自外来在途改动，放行；域内混入在途改动 → 无法与
# 本次提交切分，放行但打印警告；红项确属本次提交引入 → 照旧拦下。
#
# 格式（| 分隔，# 开头是注释）：
#   test=<完整测试名>|<失败证据片段，多个用 ~ 相隔>|<所属测试文件名>|<域路径，空格分隔>
#   file=<测试文件名>|<域路径，空格分隔>
#
# - 失败证据片段 = 该测试 expect 的 reason 文本里的独特子串。reason 只在失败时
#   打印，测试名会出现在通过用例的进度行里，所以**不能**拿测试名当失败证据。
# - test= 行按证据片段匹配（优先）；同一文件里没被任何 test= 认领的失败，
#   再按 file= 行的整文件回退域归因。
# - 域路径：目录以 / 结尾（前缀匹配）；文件路径精确匹配（或作为目录前缀）。
# - 新增守卫测试时必须同步登记，否则红项按「无法归因 = 本次提交引入」拦下。
#
# test= 条目的域取自 god_file_unit_guard_test.dart 各棘轮的实测读取面：
#   - screen 棘轮：主文件 + 2 个 part + Directory('lib/screens') 的 part 清点
#   - provider 棘轮：主文件 + Directory('lib/providers/timetable')
#   - 设置域棘轮：主文件 + Directory('lib/screens/settings')
#   - 全仓 part 棘轮：Directory('lib') 递归
