合规信息

隐私政策

轻屿课表重视用户隐私。应用主要在本地保存课表、时间模板、导入记录和提醒配置，只有在你主动使用联网能力时，才会和外部服务发生数据交互。

1. 本地保存的数据

  • 课程、周次、时间模板、多课表配置
  • 教务导入结果、.ics 导入结果、备份恢复数据
  • 提醒配置、桌面小组件状态、部分应用日志

2. 何时会访问网络

  • 检查版本更新、下载安装包
  • 读取 GitHub Releases、官网版本信息与镜像线路
  • 使用教务网页登录导入、仓库适配信息读取
  • 你主动开启统计 / 诊断能力后，才会初始化对应 SDK 或上传必要数据

3. 日志与诊断

应用日志默认仅用于本地排查更新、导入、提醒、页面和崩溃问题。只有在你主动导出并分享日志时，日志文件才会离开设备。

4. 第三方服务

版本更新、官网展示、GitHub Releases、部分统计或诊断能力可能依赖 GitHub、镜像线路或友盟等第三方服务。相关能力都以用户主动触发为前提。

5. 联系与反馈

如你对数据处理、日志导出或联网行为有疑问，可通过 GitHub Issue 或应用内反馈入口联系维护者。
