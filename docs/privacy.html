合规信息

隐私政策

轻屿课表重视用户隐私。应用主要在本地保存课表、时间模板、导入记录和提醒配置，只有在你主动使用联网能力时，才会和外部服务发生数据交互。

1. 本地保存的数据

  • 课程、周次、时间模板、多课表配置
  • 教务导入结果、.ics 导入结果、备份恢复数据
  • 提醒配置、桌面小组件状态、部分应用日志

2. 何时会访问网络

  • 检查版本更新、下载安装包
  • 读取 GitHub Releases、官网版本信息与镜像线路
  • 使用教务网页登录导入、仓库适配信息读取
  • 你主动开启统计 / 诊断能力后，才会初始化对应 SDK 或上传必要数据

3. 日志与诊断

应用日志默认仅用于本地排查更新、导入、提醒、页面和崩溃问题。只有在你主动导出并分享日志时，日志文件才会离开设备。

4. 第三方服务

版本更新、官网展示、GitHub Releases、部分统计或诊断能力可能依赖 GitHub、镜像线路或友盟等第三方服务。App 内统计 / 诊断以你主动开启为前提。官网访问统计见下一节。

5. 官网访问统计

访问本官网（mutx.ccwu.cc）时，我们可能使用 Google Analytics（GA4）了解页面访问与交互，以便改进官网。测量 ID 写在页面 meta 中（形如 G-XXXXXXXX）。

  • 仅在你点击「同意」后才会加载 Google Analytics 脚本；未同意或点击「拒绝」则不加载。
  • 可能收集的数据包括：页面路径、语言、设备 / 浏览器类型、来源、以及我们主动上报的交互事件（如下载按钮点击）。不用于广告投放。
  • 若浏览器开启「禁止跟踪」（Do Not Track），即使你曾同意，我们也不会加载 Google Analytics。
  • 你可随时清除本站本地存储中的同意记录，或使用浏览器隐私模式访问，以停止后续统计。

6. 联系与反馈

如你对数据处理、日志导出、官网统计或联网行为有疑问，可通过 GitHub Issue 或应用内反馈入口联系维护者。
