# 隐私说明

> 完整交互式说明见应用内「使用引导与权限」及「关于」页的隐私、第三方 SDK 与免责说明。
> 本文档供 GitHub / 开源访客快速了解数据处理概况。

## 数据存储

- **课表、课程设置、备份文件** 默认保存在设备本地（SharedPreferences / 应用私有目录）
- **WEBDAV 云同步**（可选）：用户自行配置坚果云或自定义 WEBDAV；快照由用户选择的第三方服务存储，开发者不运营中心服务器
- **教务导入**：网页登录凭据可按用户选择保存在本地安全存储中

## 网络请求

应用可能在以下场景发起网络请求：

| 场景 | 目的 |
|------|------|
| GitHub Releases | 检查应用更新、下载 APK |
| 节假日数据 | 拉取公共节假日信息（失败时使用内置兜底） |
| 教务系统 / 仓库索引 | 用户主动触发导入或同步 |
| WEBDAV | 用户启用云同步时 |
| 局域网编辑（可选） | 用户主动开启后，在同一局域网内通过浏览器读写课表；访问需 PIN；离开后可选择是否保持开启；数据仅经本机 HTTP 服务，不经中心服务器 |
| 友盟（Umeng） | 统计与崩溃诊断（需用户在首次引导中同意） |

## 第三方 SDK

在用户同意隐私政策后，应用可能初始化 **友盟移动统计 / U-APM** 等 SDK，用于：

- 匿名化使用统计
- 崩溃与性能诊断

详细说明与退出方式见应用内隐私页面。友盟为独立第三方服务，受其隐私政策约束。

## 数据删除

- 卸载应用将删除本地数据
- 云同步远端文件需用户在 WEBDAV 服务中自行管理
- 可在应用内清除日志、关闭统计记录（见设置与诊断页）
