开源参与

贡献指南

轻屿课表是开源项目。无论你想修 Bug、补 UI、完善官网、做国际化，还是补学校教务适配，都可以从下面几个入口开始。

1. 先看源码与协议

  • 主仓库 GitHub
  • 开源协议 GPL-3.0

2. 先反馈问题再动手

  • 提交 Issue
  • 描述复现步骤、机型、系统版本、日志或截图，会更容易被处理。

3. 教务适配参与

  • qingyu_warehouse 适配仓库
  • 如果你会网页调试、抓包或 JavaScript，可以优先参与学校教务导入适配。

4. 其他可参与方向

  • Flutter 页面与交互优化
  • 官网与下载引导信息完善
  • 多语言翻译与本土化适配
  • 版本更新说明与文档整理
