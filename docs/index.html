常见问题

你可能想知道的

轻屿课表怎么导入课表？

支持三种导入方式：

  1. 教务系统导入：点击右上角菜单 → 导入课程表 → 选择你的学校 → 登录教务系统自动同步
  2. 文件导入：支持 iCal (.ics) 格式，点击导入后选择手机中的 .ics 文件即可
  3. 手动添加：点击课表空白处 → 添加课程 → 填写课程信息
支持哪些学校的教务导入？

目前已适配 100+ 所高校，完整列表见 已适配学校页面，持续扩展中。如果你的学校暂未适配，可以使用 .ics 文件导入、AI 识图导入或手动添加课程，也欢迎在 qingyu_warehouse 提交你学校的适配需求。

轻屿课表是免费的吗？

是的，轻屿课表完全免费，无广告，无需注册。开源项目，代码公开透明。

支持 iOS 或鸿蒙吗？

目前仅支持 Android 系统，重点适配 HyperOS（小米/红米）。暂无 iOS 和鸿蒙版本计划。

我的手机为什么不支持超级岛？

超级岛功能需要小米 HyperOS 3.0.300 及以上版本才能使用。请在「设置 → 我的设备」中检查系统版本，如果低于 3.0.300，请先升级系统。

课表数据会丢失吗？

课表数据存储在本地，支持 WebDAV 云同步与完整备份导出恢复。建议定期备份，换机时可通过云同步或备份文件迁移。

怎么设置单双周？

添加或编辑课程时，在「重复」选项中选择「单周」或「双周」即可。也支持自定义周次范围，灵活适配各种排课方式。
