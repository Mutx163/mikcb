概览

不只是看课表。 也是看清今天。

你反复确认的，往往不是今天有什么课，而是还有多久开始、现在到哪一节、下一节在哪里。轻屿课表围绕这些时刻重新组织信息，让查看、提醒、切换和导入都更自然。

教务导入 支持学校教务课表导入

优先面向“不要手动录课”的真实需求，支持已适配学校的网页登录导入。

.ics 导入 支持日历课表快速迁移

如果学校没有教务适配，也能先通过 .ics、备份恢复等方式把课表迁进来。

后续维护 导入后还能继续改

导入只是开始，后面还能调课、补课、改单独时间模板，不会被导入结果锁死。

多课表 学期、身份、课程方案分别保存
分阶段提醒 课前、课中、下课前自然切换
时间模板 支持全局模板与课程级覆盖
Android 优化 强调通知链路与日常使用稳定性

体验

看一周，也看当下。

周视图课表、左右滑周、一键回本周，再加上多课表切换，重点不是把更多内容堆上去，而是让你每次打开时都更快进入状态。

体验主线 先看到今天，再决定要不要继续看整周。

首页入口优先回答“现在上到哪一节、还有多久开始”，周视图再承接更完整的排课信息。

切换 多课表切换

学期、身份、不同课程方案独立保存。

联动 当前周同步

左右滑周后也能一键回到今天所在周。

能力

提醒，不只是一条通知。

从上课前的预热提醒，到课中状态，再到下课前重点提醒，信息会随着课程阶段变化。你看到的是连续流程，而不是孤立的一个时间点。

01
课前 提前知道下一节课

在真正出门前，先把课程名、地点和开始时间交代清楚。

02
课中 在系统层持续保持状态感

通知栏、超级岛和组件维持“正在上课”的连续感，不用反复进 App 确认。

03
课后 自然切换到下一节课

快下课、刚下课、下一节课之间是连贯切换，不是每次都从零开始。

时间模板

不同学校作息不同，时间模板应该独立存在。

全局时间模板库让课表可以快速切换节次时间。对特殊课程，还可以单独覆盖时间模板。导入、调课和迁移都更轻松。

模板库 全局时间模板

一套课表可以快速切到新的作息，不必逐节修改时间。

覆盖 课程级覆盖

特殊课程可以单独处理，不破坏整个课表的统一节次。

迁移 导入时自动补齐节次

.ics 导入、备份恢复和调课时更容易保持时间结构完整。

平台

专注 Android。重点适配 HyperOS。

轻屿课表从一开始就更关注 Android 通知链路、HyperOS 超级岛、小组件和真实使用稳定性，而不是追求泛平台外观上的一致。下载安装前，你也能先看清最低系统版本和安装包架构。

系统联动

桌面小组件、状态栏提醒、超级岛与应用内状态可以形成更完整的承接关系。

数据迁移

支持 .ics 导入、完整备份导出与恢复，也支持版本更新与预发布检测。

安装兼容

最低支持 Android 8.0（API 26）。当前官网提供 Android arm64-v8a 安装包，暂不提供 32 位 armeabi-v7a 或 x86 / x86_64 版本。

常见问题

你可能想知道的

轻屿课表怎么导入课表？

支持三种导入方式：

  1. 教务系统导入：点击右上角菜单 → 导入课程表 → 选择你的学校 → 登录教务系统自动同步
  2. 文件导入：支持 iCal (.ics) 格式，点击导入后选择手机中的 .ics 文件即可
  3. 手动添加：点击课表空白处 → 添加课程 → 填写课程信息
支持哪些学校的教务导入？

目前已适配部分高校的教务系统，持续扩展中。如果你的学校暂未适配，可以：

  • 使用 .ics 文件导入（从学校教务系统导出日历格式）
  • 使用 .ics 文件导入或 AI 识图导入
  • 手动添加课程

也欢迎在 GitHub 提交你学校的适配需求。

轻屿课表是免费的吗？

是的，轻屿课表完全免费，无广告，无需注册。开源项目，代码公开透明。

支持 iOS 或鸿蒙吗？

目前仅支持 Android 系统，重点适配 HyperOS（小米/红米）。暂无 iOS 和鸿蒙版本计划。

我的手机为什么不支持超级岛？

超级岛功能需要小米 HyperOS 3.0.300 及以上版本才能使用。请在「设置 → 我的设备」中检查系统版本，如果低于 3.0.300，请先升级系统。

课表数据会丢失吗？

课表数据存储在本地，支持完整备份导出与恢复。建议定期备份，换机时可通过备份文件迁移。

怎么设置单双周？

添加或编辑课程时，在「重复」选项中选择「单周」或「双周」即可。也支持自定义周次范围，灵活适配各种排课方式。
