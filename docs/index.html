概览

不只是看课表。 也是看清今天。

你反复确认的，往往不是今天有什么课，而是还有多久开始、现在到哪一节、下一节在哪里。轻屿课表围绕这些时刻重新组织信息，让查看、提醒和切换都更自然。

多课表 学期、身份、课程方案分别保存
分阶段提醒 课前、课中、下课前自然切换
时间模板 支持全局模板与课程级覆盖
Android 优化 强调通知链路与日常使用稳定性

体验

看一周，也看当下。

周视图课表、左右滑周、一键回本周，再加上多课表切换，重点不是把更多内容堆上去，而是让你每次打开时都更快进入状态。

体验主线 先看到今天，再决定要不要继续看整周。

首页入口优先回答“现在上到哪一节、还有多久开始”，周视图再承接更完整的排课信息。

切换 多课表切换

学期、身份、不同课程方案独立保存。

联动 当前周同步

左右滑周后也能一键回到今天所在周。

能力

提醒，不只是一条通知。

从上课前的预热提醒，到课中状态，再到下课前重点提醒，信息会随着课程阶段变化。你看到的是连续流程，而不是孤立的一个时间点。

01
课前 提前知道下一节课

在真正出门前，先把课程名、地点和开始时间交代清楚。

02
课中 在系统层持续保持状态感

通知栏、超级岛和组件维持“正在上课”的连续感，不用反复进 App 确认。

03
课后 自然切换到下一节课

快下课、刚下课、下一节课之间是连贯切换，不是每次都从零开始。

时间模板

不同学校作息不同，时间模板应该独立存在。

全局时间模板库让课表可以快速切换节次时间。对特殊课程，还可以单独覆盖时间模板。导入、调课和迁移都更轻松。

模板库 全局时间模板

一套课表可以快速切到新的作息，不必逐节修改时间。

覆盖 课程级覆盖

特殊课程可以单独处理，不破坏整个课表的统一节次。

迁移 导入时自动补齐节次

.ics 导入、备份恢复和调课时更容易保持时间结构完整。

平台

专注 Android。重点适配 HyperOS。

轻屿课表从一开始就更关注 Android 通知链路、HyperOS 超级岛、小组件和真实使用稳定性，而不是追求泛平台外观上的一致。

系统联动

桌面小组件、状态栏提醒、超级岛与应用内状态可以形成更完整的承接关系。

数据迁移

支持 .ics 导入、完整备份导出与恢复，也支持版本更新与预发布检测。

下载

从 GitHub Releases 开始体验。

当前发布以 Android arm64-v8a 为主。国内网络建议优先使用国内下载；如果你想拿原始 GitHub 包，也可以直接走 GitHub 原版入口。

适合直接安装 默认展示最新正式版，点开后就能看到版本、时间和下载入口。
测试更新更快 正式版与预发布版在同一个弹窗里左右切换，验证更新通道更直接。
国内下载更省心 会预热并优先选择更快的镜像，不用自己先猜该点哪条线路。

手机端默认先看正式版；需要测试时再切到右侧预发布版。

点开后先读版本信息，再准备下载线路；需要原始包也能直接切到 GitHub。
