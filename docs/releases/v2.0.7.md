# v2.0.7

相对 v2.0.6 累计说明（本地草稿；发版前需对齐 pubspec / tag / latest.json）。

### 修复

- HyperOS 过滚物理：修复 `applyBoundaryConditions` 浮点精度断言失败，边界漂移时返回值不再超过位移量
- HyperOS 页面状态：`_HyperosBlurredPageState.notify()` 检查调度器阶段，避免在布局 / 绘制期间直接 `setState()`
- 毛玻璃头控制器：`FrostedHeaderController._setUserScrolling()` 延迟 `notifyListeners()` 到帧后回调，防止滚动通知期间触发帧重建
- 云同步：备份列表加载改用 try-finally 确保 `_loadingBackups` 状态正确重置
- 反馈页：小米 MIUI 上 `url_launcher` 返回假阳性，改用原生 MethodChannel 直接发起 Intent

### 优化

- 云同步：WebDAV 地址输入框新增 HTTP 明文协议安全警告（发布包默认禁止明文 HTTP）
- 反馈页：酷安、小红书链接改用原生 Intent 启动，兼容性更好
- 本地化：补充同步错误、反馈渠道打开等中文 / 英文 / 日文 / 韩文翻译键

### 测试

- 补充 HyperOS 过滚物理浮点精度边界测试
- 更新 HyperOS 选择列表弹窗测试
