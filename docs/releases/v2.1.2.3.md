# v2.1.2.3

- 新增 截屏后一键分享干净课表图：在课表页截屏后会浮出一条胶囊提示，点它就把课表渲染成一张干净图片、走系统分享面板发出去；图上只有课表本身，不带 App 顶栏、右上角玻璃球、底部坞和壁纸，只在图片底部保留一行品牌信息（图标、名称与官网二维码），出图按你当时看到的那一周与视图（周视图 / 日视图）。菜单里也新增了「分享课表图片」入口。开关在「课表页面」设置里，仅 Android 14 及以上提供，旧系统不显示这项；连续截屏时提示 6 秒内不重复弹。
- 新增 长按空白格出的虚线框可上下拖动改节数：虚线框上下各多一个把手，按着往上拉能缩短、往下拉能拉长，跨节时有轻微震动；拉到第 1 节、最后一节，或者碰到已经有课的格子就停住。框住几节，加课表单就预填几节。虚线框与加号的颜色改为跟随时间轴墨色（有壁纸时自动在黑白之间切换），不再固定半透明白 / 黑。
- 修复 首页右上角两颗玻璃球（更多 / 爱心）看场合发虚或发黑：没有壁纸、球底与页面底同为纯色时整颗融进页面，现在补了一圈细描边和一层外阴影；切回浅色主题时球会停在深色底图上，现在跟随主题一起刷新。
- 修复 关掉弹窗的瞬间玻璃球阴影突然冒出来：收回过程中球由弹窗临时绘制、那颗没带阴影，交接时就现形；现在两侧共用同一套描边和外阴影，交接不再跳。
