# v2.0.5.6

### 新增

- 数据备份与迁移：新增「二维码面对面传输」，两台手机无需网络、无需连接，一台连播二维码、另一台扫码即可传输当前课表或全部数据（喷泉码多帧编码，漏帧可自动补齐并校验完整性）
- 日视图：星期栏变为跟手滑杆，按住左右拖动即可快速滑动日视图，一次划过整周；轻扫仍可切换上一周 / 下一周
- 外观：毛玻璃风格可选「高斯模糊 / 液态玻璃」；液态玻璃用于弹窗、筛选小窗、首页菜单与子页顶栏（实验性，需 Impeller）
- 外观：液态玻璃支持通透 / 轻柔 / 标准 / 浓郁预设，并可展开自定义厚度、模糊、着色、高光等参数
- 课表布局：课程卡片表面效果可选不透明、半透明、高斯模糊、液态玻璃
- 课程：支持单独设置卡片文字颜色；导入「随机课程颜色」可同步开启「随机字体颜色」（同色系深色字，关闭则纯白）
- 启动：冷启动展示圆角图标 + 应用名品牌页，与系统启动画面衔接；老用户进入主界面前不再闪加载圈
- 设置与多数子页：顶栏支持大标题，上滑后收成居中小标题（更接近系统设置）
- 取色：课程颜色选择改为 HyperOS 风格取色器
- 日期：学期开始等日期选择改为 HyperOS 月历弹层

### 优化

- 数据备份与迁移：导入预览现在会同时展示课程、考试、任务、日程、作息模板、时间规则、地点规则和设置的变化，确认导入影响更清楚
- 数据备份与迁移：选择课程、指定周次或作息模板进行覆盖时，只处理选中的范围，不会误删其他本地数据；整张课表覆盖仍会明确列出将被替换的内容
- 数据备份与迁移：导入前会检查任务、考试与课程 / 作息模板的关联，缺少关联数据时会先阻止导入，避免导入后内容不完整
- 数据备份与迁移：导入撤销失败时仍保留撤销记录，方便再次恢复
- 局域网编辑：课程颜色输入更安全，非法颜色会自动恢复为默认颜色；网页服务增加安全限制，降低异常数据影响
- 课程编辑：课程开始周和结束周会自动限制在当前学期周数内，减少超出学期范围的课程数据
- 更新检查：支持在首页直接查看版本更新，下载过程显示实时进度；也可选择系统下载器，并在关于页按需加载长篇更新说明
- HyperOS：系统字体粗细调整会同步到按钮、弹层、导航等控件，输入框切换输入法后更稳定
- 设置与子页：折叠大标题的展开、收起和回弹更连贯，短页面进入时不再出现顶栏闪动；时间方案管理页打开更流畅
- 弹层与菜单：选择弹层、底部弹窗和首页菜单统一液态玻璃材质，浅色与深色主题下的遮罩和内容可读性更一致
- 支持作者：捐款名单与开源许可证等说明加载更轻量，长篇更新说明滚动更流畅

- 导入课程：开启随机课程颜色时，与本地已有课程合并也会套用新配色与可选字体色，不再总是保留旧色
- 课程统计长图分享：内置图标等资源会预加载到显示缓存，导出更完整、更不易缺图
- HyperOS 弹层与选择列表：在液态玻璃面板上嵌套控件更透、避免叠多层玻璃
- 日视图：日程、考试、摘要卡片跟随「课程卡片表面效果」设置，四种样式与首页一致；面板不再强制不透明底，可透出壁纸
- 设置预览：课程卡片设置、课表页面设置里的预览会显示壁纸，并与首页使用同一套玻璃与模糊效果
- 设置预览：调整毛玻璃 / 液态玻璃参数时预览实时跟随
- 性能：课程网格的玻璃改为整块共享一次背景采样（此前按天分列重复采样），进入设置页与滑动课表更流畅
- 性能：首页壁纸预模糊直接复用位图，省去多余的 PNG 编解码与重复副本，内存占用下降
- 启动：等本地课表初始化完成后再收起品牌页，避免主页短暂露出加载指示器
- 日视图：卡顿时轻扫仍可正确甩动翻页，减少「滑了却弹回」
- 日视图：滑动过程中星期栏可提前预览目标日高亮
- 性能：日视图切换日 / 周时本地状态静默落盘，减少整页重建与平台同步开销
- 壁纸对比：顶栏与课卡文字按壁纸分区采样亮度自动对比；用户自定义颜色保留，强调色不再被自动反转
- 液态玻璃顶栏：去掉顶部 1px 色差描边，状态栏区域更干净
- 设置：列表右侧状态灰字缩短（如「日志排查」「未绑定」「状态检查」）；节假日入口改为「放假与调休」等更短文案
- 外观设置预览：预览改为主题色 / 字体模式示意，不再误用课卡配色
- Android 启动画面：图标圆角与 Flutter 品牌页对齐
- 开关、输入框、分段标签与选择列表的交互更接近系统控件
- 冷启动：品牌页收起前预热壁纸与顶栏模糊，减少主页刚出现时的闪白 / 闪磨砂
- 液态玻璃弹层：半透明遮罩更轻，弹窗层次更清晰且不糊死折射
- 课程总览：列表首字母色标更清晰可读
- 设置首页：大标题顶栏随列表滚动折叠，内容可从顶栏下方滑过
- 弹窗与选择列表：恢复自下而上的滑入动画，压暗层随动画淡入更柔和
- 列表选择弹窗：所有条目统一高度，视觉更整齐；弹窗最小宽度增大，短文案不再局促
- 列表选择弹窗（液态玻璃）：压暗层不再混入玻璃的模糊 / 折射采样，弹出动画期间玻璃保持实时通透，不再先全透明再突变为模糊
- 折叠大标题顶栏：松手自动吸附到展开 / 收起端点，收起后首行内容恰好停靠在小标题下方
- 设置首页：顶栏壳与子页完全统一，滚动到顶栏下方时磨砂 / 液态玻璃正常显示（此前被不透明底色盖住）
- 滑动条：轨道铺满可用宽度，拖动触感按档位分级
- 日视图：跨周滑动改为全局连续滚动，按住拖动可一路滑过多个周，手势不中断、不再卡住或顶住
- 日视图：星期栏跨周时整行（周次、日期与选中指示）跟随内容平滑滑过，与周视图顶栏一致的跟手效果；周内切换仅指示条跟随
- 相册选图：改用系统相册（Photo Picker）选择图片，无需申请存储权限
- 日视图：快速连续滑动时选中日与页面内容保持一致，不再滞后；滑动过程不再因整页刷新而卡顿
- 毛玻璃 / 液态玻璃面板：分组与选择卡片改为半透明玻璃色，面板模糊与折射清晰可见，不再叠不透明白卡
- 液态玻璃弹窗底部、首页顶栏毛玻璃带边缘：不再出现 1px 发丝线接缝
- 切换课表弹窗：去掉冗长副标题，更简洁
- 内部：UI 框架完成从 Forui 到 flutter_miuix 的迁移，移除遗留依赖，包体与启动开销更小

### 修复

- 首页：点击顶部标题重新可以打开课表快速切换弹窗（此前迁移后点击无响应）
- 首页：情侣模式顶栏爱心图标恢复粉色，壁纸下顶栏图标颜色不再丢失
- 首页：壁纸模式下状态栏图标深浅恢复正确，不再在深色壁纸上显示深色图标
- 课表卡片：整张卡片任意位置均可点击进入编辑（此前点空白区域无反应）
- 子页：折叠大标题搭配顶栏扩展行（如导入进度条）时，内容上边距不再在页面刷新后跳变
- 列表选择弹窗：修复弹出时压暗层瞬间全黑
- 设置：右侧状态文字过长时不再溢出
- 壁纸跟随周切换时，课程卡片的磨砂与壁纸不同步，滑动中会反向漂移
- 关闭毛玻璃后，壁纸预处理仍会执行，白白消耗性能与电量
- 磨砂强度在不同分辨率 / 缩放的设备上不一致，且与顶栏模糊对不齐
- 星期栏在开启模糊但未纳入壁纸范围时，会用不透明底盖住玻璃效果
- 状态栏：透明 scrim，避免部分 HyperOS 设备边缘出现 1px 发丝线
- 徽标：红点角标上的数字恢复白字，不再在部分场景显示黑字
- 折叠大标题顶栏：滚动中途松手不再停在半折叠位置
- 日视图：跨周不再瞬移、卡顿或闪现——周次与星期栏日期不再滞后到松手才跳变，跨周过渡无叠影
- 毛玻璃弹窗：内容不再顶到屏幕顶部、玻璃铺满全屏，改为按内容高度贴底展示
