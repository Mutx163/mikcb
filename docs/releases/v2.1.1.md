# v2.1.1

- 新增任务：添加与编辑任务页支持设置完成状态，可直接登记已完成的任务，也能把已完成任务改回未完成。
- 新增课程卡：毛玻璃卡面的文字颜色自动适配壁纸——彩色字自动转为黑白、黑白灰字对比度不足时同样自动调整，保证清晰可读，日程卡与周预览也同步支持自定义字色。
- 优化课程卡：实心卡面的简介字色自动跟随标题字色的明暗，历史遗留的字色错位也会自动纠正，不再出现白标题配黑简介的卡片。
- 优化任务：添加任务页选择来源课程时同一门课只显示一次、课程较多时可上下滚动，截止日期只在日期行展示一次；任务清单行改用环形勾选钮，完成态带勾号更直观。
- 优化周报提醒：重启手机、升级应用或调整系统时间后，周报通知仍能准时送达，不再漏发。
- 优化界面细节：点底栏切换日/周视图立即到位、不再播放展开动画，超级岛预览的课程名与地点统一显示在摄像头右侧、与灵动岛实际显示一致，二维码传输的文字补齐多语言翻译并统一警示配色。
