# v1.3

## 新增

- 新增学期账单式课程统计：总览、成就徽章、数据故事、每日课时分布、必修/选修比例、课程排名，支持分享长图
- 新增局域网浏览器编辑课表：手机开本地 Web 服务，电脑浏览器改课表；Android 前台保活维持连接
- 新增表格导入课程：CSV 模板导入、周次表达式、教务系统快捷导入宏
- 新增统一 Forui 提示：普通 Toast、轻量短提示、带操作按钮提示（如撤销主题、切换镜像源）
- 新增共用选择 Sheet：主题、学期周数、时段方案、课程颜色等，设置页与添加课程页复用
- 课程简称新增「取前两字」快捷填充
- 课程操作菜单补充编辑/调课/停课/删除次级操作与单双周标识

## 优化

- 全面迁移至 Forui 设计体系：课表、设置、添加课程/考试/日程、导入、关于、统计、用户引导、Live 诊断等界面统一新视觉
- 应用内 SnackBar 提示迁移为 Forui Toast，与主题、对话框风格一致
- 优化课程字段说明：Sheet 逐项解释名称、简称与同步规则；明确完整名称与超级岛简称的使用场景
- 优化课程字段选择、跟课 Sheet 与操作菜单的布局和键盘弹出时的滚动体验
- 优化课程统计总览卡片的布局与 Forui 视觉一致
- 优化局域网 Web 编辑界面的交互与脚本稳定性
- 优化节假日查询的准确性与边界情况处理
- 优化超级岛按自然周调度当前课程
- 优化应用启动：预热 bundled 资源目录，减少首次打开相关页面的等待
- 优化课表数据逻辑：Provider 拆分为模块化结构，便于维护
- 更新多语言文案（含统计界面、调课副标题等）

## 移除

- 移除 TDesign / liqkit_ui 组件依赖，统一使用 Forui
