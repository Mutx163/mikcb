# v2.0.6

相对 v2.0.5 / v2.0.4 累计说明（本地草稿；发版前需对齐 pubspec / tag / latest.json）。

### 新增

- HyperOS 边界解耦（PR1）：`lib/ui/hyperos` 去除对 models / providers / services / l10n 的业务依赖；课表专用毛玻璃预览与首页区域模糊迁至 `lib/widgets/`
- HyperOS Motion / App Bridge：平台动画与业务映射外置到 `hyperos_motion_bridge`、`hyperos_app_bridge`
- HyperOS 组件拆分（PR2）：`hyperos_widgets` 拆为 `widgets/indicators`、`layout`、`tiles`、`cards`，保留 barrel 兼容导出
- HyperOS 语义色（PR3）：扩展 `HyperosColors`（primary、surfaceContainer、error、outline 等）

### 优化

- 更新检查：优先按 tag 构造 `mikcb-{version}-arm64-v8a.apk` 下载链，减少对 `expanded_assets` 子请求的依赖（国内超时 / 403 更稳）
- 选择弹窗：行高与 `hyperosSelectPopupEstimatedHeight` 共用首末 / 中间垂直边距模型，贴边与高度估算更一致
- 滑块：拖动时按 `divisions` 归一化写入；展示仍保留原始值，兼容历史 off-grid 数值（如冲突课透明度 0.72）
- 冲突课透明度默认值：`0.72` → `0.70`（已保存配置不变，仅缺省 / 新装）
- 支持开发者页：赞助区块改用 `HyperosCard(padding:)`，去掉多余嵌套 `Padding`
- 纯单选列表（下载渠道等）不再默认画小蓝点；主题色等场景需显式传入 `prefix`

### 修复

- `HyperosChoiceTile`：`showDivider` / `dividerIndent` 真正绘制行间分隔线（关于页下载渠道、课表主题列表等）
- `HyperosChoiceTile`：`isFirstInPopup` / `isLastInPopup` 真正影响弹窗行上下边距
- 选择 / 列表行内容在按下高亮区域内垂直居中
- 选择列表选中项标题变为主题蓝色（`highlightSelectedText`）
- 浮窗选项小蓝点与弹窗高度偏差
- `HyperosChoiceTile` 的 `prefix` 参数未生效
- 按下高亮在控制卡末行裁切，避免多余下半圆阴影
- 超级岛提醒时段、布局与节次、桌面小组件等设置页「最后一张卡片」底部边距叠加 / 缺失
- 超级岛：节假日按日判断（避免 sticky 假日连日不显示）、DST 周次、前台服务启动失败重试、stop 后重排下一触发
- 云同步：备份列表改用 `HyperosNavigation` 打开

### 调整

- 清理调试图与临时高斯模糊总结文档
- 更新 CONTRIBUTING、`.gitignore`
- 补充 HyperOS 选择行 / 滑块 / 分隔线相关测试
