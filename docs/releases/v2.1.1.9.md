# v2.1.1.9

- 新增 桌面小组件课程颜色：今日系列卡片（2×2、2×2 迷你列表、2×4、4×4、4×1 横条、4×2 横宽卡）在课程名前加一根课程色竖条，课程名与状态胶囊文字也一并换成课程色的可读版本，一眼认出是哪门课。
- 新增 课程颜色开关（小组件设置）：三档可选——「关闭」回到加色之前的经典配色，「仅色条」只加竖条不动文字，「色条 + 文字」完整贯穿；不喜欢的随时关掉。
- 新增 全 App 主题色贯穿：继首页八宫格之后，添加弹窗、周次选择、更新提示、开关、日期/时间/数字/颜色选择器等弹窗与控件全部跟随设置里的主题色，整个应用一个色调。
- 新增 主题预设色块预览：设置弹窗内直接呈现各预设色块，挑选更直观；「默认」预设即小米原色配方，引导页默认选中。
- 优化 主题色所见即所得：浅色模式下选亮黄就是要看到亮黄，强调色不再被自动回墨成黑色；深色模式近黑颜色自动提亮，按钮和文字始终可辨识。
- 优化 引导页主题色板：色块下方标注主题名，相近的深色不再靠猜；色板排布优化，不再溢出屏幕。
- 优化 主题管理同步：在外观设置里切换预设主题立即生效，主题管理页与外观页选择保持同步。
- 优化 首页右上角入口定名「添加」：一个动词配展开箭头更直接，子项「添加课程 / 日程 / 考试」自带宾语。
- 优化 二级菜单展开观感：展开子菜单时主菜单压暗减半，背景、主菜单、子卡三层亮度分明，层次更贴近系统相册。
- 优化 日程安排列表：「进行中」改为标题旁绿色圆点徽标，元信息合并为「日期 · 时刻」单行灰字，跨天日程时刻单独成行，行内图标与箭头垂直居中。
- 优化 课程色可读性：色条与文字色按 WCAG 相对亮度自动钳制，浅色卡只压暗、深色卡只提亮（绝不反向拉近底色），色相全程不变；浅黄、青柠这类原本在浅底上几乎隐形的浅色系现在同样清晰。
- 优化 渐变背景卡片：渐变风格下主标题保持白色、不上课程色，只加课程色竖条，不牺牲主标题对比度。
- 优化 状态胶囊：底色与圆角保持不变，只换文字色，与现有卡片样式同一语系。
- 优化 老数据与缺色兼容：快照里没有课程颜色时整条加色链路静默回落，旧备份与第三方数据源不会画出灰条。
