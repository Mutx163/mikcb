# v2.1.1.5

- 新增 桌面小组件深色模式：系统切换深色主题时，桌面课表、统计等小组件配色自动跟随，夜里看不再刺眼。
- 新增 精确闹钟权限引导：课程提醒需要精确闹钟权限时给出引导页，按引导授权后自动重排提醒并明确反馈结果。
- 新增 更新日志自动扫描：应用日志页可自动扫描历史版本说明，快速核对某次更新改了什么。
- 优化 应用内更新安全性：下载的安装包会校验官方 SHA-256 摘要，校验失败自动删除残留文件重下，避免装到不完整或被篡改的包；系统弹窗拦截下载时会给出明确提示。
- 优化 数据安全性：本地存储损坏时按条目隔离坏数据、保住其余内容；云同步回滚后自动清理同步基线，不再用旧基线覆盖云端新数据。
- 优化 启动速度与小组件数据：启动关键路径不再做磁盘读写，首帧更快；统计小组件的周课时、学期进度改由原生直接计算，刷新更快更准。
- 移除 「减弱玻璃效果」手动开关：玻璃降级完全跟随系统透明度与对比度信号，不再需要手动开关。
