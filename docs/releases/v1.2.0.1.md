# v1.2.0.1

- 新增日视图时间轴：在周视图点击当天或任意日期后，可以直接展开成单日时间轴，按时间顺序查看当天课程与安排，阅读密度更低，聚焦更强。
- 新增日程系统：现在可以在“添加内容”里直接创建日程，支持开始/结束日期、跨日日程、地点与备注，并会插入到日视图里和课程一起展示。
- 优化日视图交互：周内切日、边界切周、回到今天、关闭后重新展开等行为更连贯，进入后会记住上次打开的视图状态与日期。
- 优化进行中展示：日视图里的课程与日程都支持更直观的进度展示，正在进行中的内容更容易被看到，日程状态文案也和课程文案做了明确区分。
- 优化超级岛自定义资源：岛标签 Logo / 展开图标的替换和清理逻辑更完整，更新安装包与历史资源文件不再持续堆积。
