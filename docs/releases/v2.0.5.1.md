# v2.0.5.1

### 新增

- 问题反馈：支持微信公众号通道——一键复制「轻屿课表」并可拉起微信搜索关注
- 考试提醒：支持系统级考试提醒调度，可设置考前多时段与自定义提醒时间
- 考试安排：列表页增加概览（今日 / 临近 / 进行中）与更清晰的条目布局
- 桌面小组件：考试进行中时优先展示考试状态

### 优化

- 应用内提示（Toast）改为系统风格胶囊样式，更轻、更不挡内容
- 弹窗与底部弹层支持磨砂 / 浮层样式，模糊强度跟随外观设置；关闭模糊时保持不透明底
- 表单内选择行、节假日编辑等控件对齐输入框样式，设置页观感更统一
- 时间模板：切换到节次更少的方案时，若课表仍有课排在超出节次，会拦截并提示「有课排到第 N 节」
- 添加考试：提醒时间支持自定义多档，编辑与展示更顺手
