# v2.0.8

相对 v2.0.7 累计说明（本地草稿；发版前需对齐 pubspec / tag / latest.json）。

### 修复

- 超级岛：`TimetableProvider` 初始化失败后可自动重试，不再缓存永久失败的 Future
- 超级岛：应用回到前台时幂等自愈（重算时间上下文、强制同步原生快照、校准 30s tick）
- 存储：课程 `add/update/delete/save` 完整读改写串行化，避免并发丢课
- 调试深链：`mikcb-debug://` 不再误走外部文件导入，消除 `No content provider` 红字栈
- 调试深链：Flutter 平台 `pushNamed` 未知路由改为吞掉，避免「找不到路由生成器」断言
- HyperOS 列表：修复多行控件（选择行 / 滑块等）在裸 `Column` 下首尾行内边距不均、像「贴顶 / 悬空」的问题
- HyperOS 滑条：对齐 `ListGroup` / `ControlCardRows` 的首尾内边距，避免贴底
- HyperOS 圆角：矮卡片 / 单行控件不再套设置组 24dp，避免上下圆角连成「胶囊」
- HyperOS 选择行：`edgeToEdge` 卡片末行不再多叠 12dp 空白，修复「展开态大图标」等单行文字偏上
- HyperOS 按压高亮：裁剪圆角跟随自适应表面半径，与卡片实际圆角一致
- 页面转场：仅在推入/弹出动画中裁剪圆角，落地后取消裁剪，避免正常使用与截图出现半边圆角
- 课表「回本周」浮动按钮：不再用 `Opacity` 包裹毛玻璃层，避免 `BackdropFilter` 失效只剩实色底
- 桌面小组件 / 超级岛：从 Flutter 偏好完整解析法定假日与自定义假期，假日当天正确隐藏课程（不再依赖常缺失的 profile 级 `isHoliday` 标记）
- 节假日数据变更后强制失效并重推桌面小组件 / 超级岛快照，避免仍显示当天课程
- HyperOS 页头：`headerExtension` 每帧新建实例不再清空测量高度，避免使用引导进度条等 inset 闪烁
- HyperOS 页：横向 `PageView` 滚动不再误触发顶部毛玻璃状态
- HyperOS 转场：blur settle 的 post-frame 链路主动 `scheduleFrame`，测试与嵌套回调下也能收敛

### 优化

- 设置页分区标题统一为「灰色 `HyperosSectionLabel` 在卡片上方 + 白卡片内纯控件」：
  - 布局与节次、桌面小组件、外观文字颜色、情侣课表、备份迁移、局域网、使用引导、云同步状态区等
  - 去掉偏好列表卡片上的黑色卡片标题与长篇灰色脚注
- 布局与节次：课表密度 / 冲突透明度等滑块改为「左侧纯标题 + 右侧数值」
- 页面转场：
  - 动画中保持更大卡片圆角（约 40dp），中段几乎满圆角、仅在落地带收起
  - 「转场速度」从布局与节次挪到外观与配色（高斯模糊卡片之后、背景显示区域之前）
- 节假日标记：
  - 主页仅保留开关、自定义假期、法定假日；刷新与更新日志收入右上角高级设置
  - 高级设置：更新日志占满上方可滚动区域；「检查更新」固定底栏（卡片底色 + 安全区一体）
  - 自定义假期：条目在上、添加在下；条目对齐标准导航行（标题 / 类型 / 日期，点击编辑、长按删除）
  - 法定假日：标准导航行只读展示（无箭头），过期项降低对比度
  - 新增 / 编辑假期弹层对齐 HyperOS 表单（日期行、分段类型、实心主次按钮）
  - 编辑已有自定义假期：弹层内可删除；确认改为底部实心按钮弹层，避免 sheet 上叠 dialog
- 关于页：新增「开源许可证」子页（本应用 GPL 说明 + `LicenseRegistry` 组件列表与搜索）
- 使用引导：隐私与提示正文对齐关于页「项目定位」字号与主文字色
- HyperOS 次要按钮：改用 `secondary` 底色，避免在脚手架灰底上几乎看不见
- HyperOS 导航行：支持长按与可选隐藏箭头，便于只读列表与长按删除
- 超级岛上课前显示：倒计时格式为单行 `ListGroup` + `SelectTile`，避免双行与徽章错位
- 关于页：项目定位 / 导入与迁移弹层改为黑字正文、完整换行；列表副标题恢复系统灰阶 `listDetail`；说明字号对齐版本号行
- 课表管理：
  - 列表行对齐 HyperOS 标准行（箭头边距与 `HyperosListTile` 一致）
  - 更多操作为底部 `HyperosSheet` + 选项列表（删除等破坏性操作红色）
  - 新建 / 重命名改为底部表单弹层 + 实心 `HyperosButton`（与云同步连接表单一致）
  - 当前课表右侧勾选与未选中箭头同位；三点菜单与箭头同色灰
- 外观 / 布局「浅色模式 / 深色模式」分区标题去掉加粗与主题色抢色
- 提醒时段与相关设置页：继续对齐 HyperOS 系统设置列表风格；标题去掉斜杠
- 课程总览 / 冲突：
  - 外层仅保留「查看冲突详情」入口 + 主课程列表（去掉冲突分区标题与重复列表）
  - 新增冲突详情页：互撞组合、时段，可跳转对应排课编辑
  - 编辑页排课记录：冲突对方改为标准导航行（标题 + 冲突标签 + 副标题 + 箭头）
- 澎湃 UI 库：新增 `HyperosRadius` / `HyperosAdaptiveCard` / `HyperosSurfaceRadiusScope`，`ListGroup` / `ControlCard` / 色块 / 按钮等统一矮高度圆角策略
- 文案：多语言偏好说明去掉句末多余句号，观感更贴近系统设置
- 导入课程：随机课程颜色改为导入首页总开关，ICS / AI / 教务 / 表格子页不再各自放开关
- 新增 debug/profile 真机调试深链与 `tool/qa.ps1` 轻量验收脚本
