# v2.0.8

相对 v2.0.7 累计说明（本地草稿；发版前需对齐 pubspec / tag / latest.json）。

### 修复

- 超级岛：`TimetableProvider` 初始化失败后可自动重试，不再缓存永久失败的 Future
- 超级岛：应用回到前台时幂等自愈（重算时间上下文、强制同步原生快照、校准 30s tick）
- 存储：课程 `add/update/delete/save` 完整读改写串行化，避免并发丢课
- 调试深链：`mikcb-debug://` 不再误走外部文件导入，消除 `No content provider` 红字栈
- 调试深链：Flutter 平台 `pushNamed` 未知路由改为吞掉，避免「找不到路由生成器」断言
- HyperOS 列表：修复多行控件（选择行 / 滑块等）在裸 `Column` 下首尾行内边距不均、像「贴顶 / 悬空」的问题
- HyperOS 滑条：对齐 `ListGroup` / `ControlCardRows` 的首尾内边距，避免贴底

### 优化

- 设置页分区标题统一为「灰色 `HyperosSectionLabel` 在卡片上方 + 白卡片内纯控件」：
  - 布局与节次、桌面小组件、外观文字颜色、情侣课表、备份迁移、局域网、使用引导、云同步状态区等
  - 去掉偏好列表卡片上的黑色卡片标题与长篇灰色脚注
- 布局与节次：课表密度 / 冲突透明度 / 转场速度等滑块改为「左侧纯标题 + 右侧数值」
- 超级岛上课前显示：倒计时格式改回单行 `ListGroup` + `SelectTile`，避免双行与徽章错位
- 关于页：项目定位 / 导入与迁移弹层改为黑字正文、完整换行；列表副标题恢复系统灰阶 `listDetail`
- 课表管理：
  - 列表行对齐 HyperOS 标准行（箭头边距与 `HyperosListTile` 一致）
  - 更多操作为底部 `HyperosSheet` + 选项列表（删除等破坏性操作红色）
  - 新建 / 重命名改为底部表单弹层 + 实心 `HyperosButton`（与云同步连接表单一致）
  - 当前课表右侧勾选与未选中箭头同位；三点菜单与箭头同色灰
- 外观 / 布局「浅色模式 / 深色模式」分区标题去掉加粗与主题色抢色
- 提醒时段与相关设置页：继续对齐 HyperOS 系统设置列表风格；标题去掉斜杠
- 新增 debug/profile 真机调试深链与 `tool/qa.ps1` 轻量验收脚本
