# v2.1.1.2

- 新增超级岛自检提示：因关闭「上课前提醒」导致测试通知暂不出现时，自检会说明岛将在课程真正开始后出现并指引打开该开关，与真的无课区分开。
- 优化玻璃效果：MIUI/HyperOS 截图预览悬浮窗显示期间课程卡与顶栏不再退回实体外观，截图全程保持玻璃质感。
- 优化超级岛自检入口：从「诊断」页迁回「超级岛与通知」维护组，更容易找到；入口行只留「自检」一行，与同组其他开关样式一致。
- 优化玻璃坞内嵌页：考试安排、课程统计、设置等底栏内嵌页的列表可以滚动到底，最后一行内容不再被悬浮药丸挡住。
- 优化学期总览卡：2×2 宫格压缩为单行四项指标，高度约缩小三分之二，数字回归常规字重更清爽，分享导出长图同步变紧凑。
