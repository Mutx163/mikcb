# v1.2.1.10

## 新增

- 全新主题系统：支持预设主题（含护眼/高对比度等）、保存自定义主题、导入导出、重命名与复制
- 主题切换撤销：应用预设或导入的主题后底部出现撤销按钮，8秒内可一键还原到应用前的设置
- 主题修改检测：应用主题后若调整了颜色等设置，系统自动标记，提醒用户已偏离原主题
- 低对比度配色警告：文字颜色与背景对比度不足时自动弹出提醒
- 小部件明日课程预览：今日课程结束或今日无课时，若明日有课程则自动显示明日课程信息

## 优化

- 大号小部件顶部信息区布局优化：整合显示周次、日期与课程数量，信息更清晰
- 主题导入导出改用顶部浮层提示，配合图标和关闭按钮，视觉效果更醒目
