# v3.0.0.1

> 本次重点：课表导入执行日志、首页宽屏、课卡上的字不再被省略号吃掉

本版接在 3.0 第一个测试版之后：补上课表导入的执行日志，修掉几处文字截断和小组件误报，平板宽屏的列宽也统一了。

## 新增 · 1

- 课表导入执行日志：教务导入不顺利时，顶栏 ⋮ 菜单里多了「课表导入执行日志」入口，能直接看到这次执行到哪一步、卡在哪个环节、返回了什么码；面板按每次执行分组，每行是时间、类别和键值，长内容单行横向滚动不截断，底部可复制或分享脱敏后的文本；同一份记录也会写进应用日志，事后还能翻。

## 优化 · 3

- 首页宽屏：内容区宽到 600dp 起，课表收进 640dp 的居中宽列，600–840dp 的竖屏平板不再整行通栏；手机宽度下逐像素不变，星期栏跟着一起收窄。
- 教务导入的执行窗口：预算从 30 秒放宽到 60 秒，你读弹窗的时间不再算进去——不会因为多看一眼就超时，也不会把正在看的对话框取消。
- 导入的阶段提示与超时提示补齐六种语言，不再中英混排。

## 修复 · 8

- 实体材质下，顶栏右上角的「更多」球会露出一块多边形底板；现在退回实心圆，不再对空采样层做模糊，液态档不变。
- 课卡上的字不再被省略号吃掉：周卡的地点行放两行、字号略降，日卡的地点和天气放两行，「教三305」「小雨 · 23° · 62%」这类能看全。
- 桌面小组件：周六周日都排了课时，周五不再宣布「周末要开始了」（停课也算排了课）。
- 繁体中文：导出统一写「匯出」、校历统一写「校曆」。
- 英文：Super Island 统一收口为 Live Island（设置、直播预览、诊断页等处）。
- 课表导入执行日志的空态补了一句边界说明：日志已脱敏，但仍可能带课程名、教室这类信息，分享前自己看一眼。
- 日文、韩文界面里导入相关的三条提示混着中文（「教务」「后面」），改成对应的日文、韩文说法。
- 没标题的弹层顶部不再多出一段空白：以前就算没有标题，弹层也会留一行 6+12dp 的空标题位，现在没有标题时整行不画，把手下面直接接正文。
