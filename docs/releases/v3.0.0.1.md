# v3.0.0.1

> 本次重点：网络请求统一、二维码生成改用成熟编码库、课表导入执行日志

本版接在 3.0 第一个测试版之后：把网络请求、二维码生成、图片加载三处底层换成成熟实现，补上课表导入的执行日志，另修一批文字截断、通知与文案问题。

## 新增 · 2

- 课表导入执行日志：教务导入不顺利时，顶栏 ⋮ 菜单里多了「课表导入执行日志」入口。每次执行导入脚本算一轮，面板按轮分组，表头写明学校与适配器；一轮结束会写清结果和原因——成功、超时、被前置检查拦下、课程数据有问题等，失败那一轮的第一行现场记录不会丢。每行是时间、类别与键值，长内容单行横向滚动不截断，底部可复制或分享脱敏后的文本；同一份记录也会写进应用日志，事后还能翻。
- 诊断日志能只看网络：日志页新增「网络」筛选，一次导入或更新里的网络请求（地址、状态码、耗时、失败原因）可以一键筛出来；「被取消」和「超时」分开记，不再混成一种。

## 优化 · 6

- 网络请求统一：天气、更新检查、关于页、Bing 壁纸、教务适配仓、节假日与图片下载这些请求改走同一套实现，失败原因按统一口径记录（连不上、超时、HTTP 状态、被取消、数据过大分开记），排查时不再各说各话。
- 二维码生成改用成熟编码库：局域网传输页和统计分享的二维码由 ZXing 生成，原先手写的编码算法退役；编码体积上限按实测重新校准。
- 图片加载改用成熟库：缩略图、壁纸预览等图片加载与内存缓存交给 Coil 承担，原先手写的缓存、线程池和在途去重退役；缓存上限仍是 16MB。
- 首页宽屏：内容区宽到 600dp 起，课表收进 640dp 的居中宽列，600–840dp 的竖屏平板不再整行通栏；手机宽度下逐像素不变，星期栏跟着一起收窄。
- 教务导入的执行窗口：预算从 30 秒放宽到 60 秒，你读弹窗的时间不再算进去——不会因为多看一眼就超时，也不会把正在看的对话框取消。
- 导入的阶段提示与超时提示补齐六种语言，不再中英混排。

## 修复 · 8

- 实体材质下，顶栏右上角的「更多」球会露出一块多边形底板；现在退回实心圆，不再对空采样层做模糊，液态档不变。
- 课卡上的字不再被省略号吃掉：周卡的地点行放两行、字号略降，日卡的地点和天气放两行，「教三305」「小雨 · 23° · 62%」这类能看全。
- 桌面小组件：周六周日都排了课时，周五不再宣布「周末要开始了」（停课也算排了课）。
- 通知冷启动：App 被系统回收后，恢复时点一条新的通知不再被吞掉，会正常落到对应页面。
- 没标题的弹层顶部不再多出一段空白：以前就算没有标题，弹层也会留一行 6+12dp 的空标题位，现在没有标题时整行不画，把手下面直接接正文。
- 首页天气失败时的提示与设置页统一，不再一处说「更新失败」、另一处换一种说法。
- 繁体中文：导出统一写「匯出」、校历统一写「校曆」。
- 日文：35 处中文逗号「，」改成日文的「、」，另有一句整句是中文的说明按日文重译；同时修掉一处混进简体的「教务」，以及导入相关四处中英日韩混排。
