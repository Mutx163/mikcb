# v2.0.5

### 新增

- 新增诊断日志解析器模块：从日志查看器中抽离为独立文件，支持结构化字段解析、日志级别自动推断、增量追加与 isolate 大文件解析
- 新增 HyperOS 胶囊滑块轨道样式：模拟系统音量条视觉，轨道全高胶囊包裹滑块，最小值时活性填充收缩为圆形
- 新增 HyperOS 控制组件无障碍语义：导航栏、选择行、开关行均添加 `Semantics` 标签，适配屏幕阅读器
- 补全中英标题文案：铃声时间矫正、左侧图标圆角、左侧文字大小/偏移、页面过渡速度、浮窗按钮透明度、课程卡片间距、行高、紧凑字号、课程卡片字号（日 / 韩 / 繁体仍回退）

### 优化

- 重构运行日志查看器：使用独立解析器替代内联实现，支持大日志文件自动走 isolate 解析、增量追加避免全量重解析、展开/折叠单条日志详情、设备信息区块可折叠
- 优化 HyperOS 滑块：新增 `_HyperosCapsuleTrackShape` 自定义轨道绘制，活性填充胶囊端部跟随滑块圆角包裹；移除旧轨道实现
- 优化 `HyperosControlCard`：移除 `plainTitle` 参数，标题行行为统一，简化调用方代码
- 优化 `HyperosNavigationBar`：导航栏高度随系统字体缩放增长，避免大字体下标签被裁剪
- 优化 `HyperosNumberPicker`：范围变更时正确跳转到新列表位置，避免 `FixedExtentScrollController` 断言失败
- 优化 `HyperosBadge`：改用 `Positioned.fill` + `Align` + `Transform.translate`，支持任意对齐方向的精确定位
- 优化 `HyperosSearchBar`：清除按钮通过 `ValueListenableBuilder` 自动响应文本变化，无需依赖父组件重建
- 优化 `AppLogService`：流式监听改为 body 去重（忽略 header 时间戳变化），避免无意义的重复解析；导出时才写入 `exportedAt`
- 优化 `FrostedHeaderController`：快速滚动时 `dispose` 用 `jumpTo` 替代 `animateTo`，避免 `_TickerProviderStateMixin` 断言错误
- 优化 `HyperosSwitch` / `HyperosSelect`：添加 `Semantics(button: true, label: ...)` 无障碍标签
- 优化测试覆盖：新增胶囊轨道渲染、`HyperosSliderTile` 底部内边距、`HyperosControlCardScope` 感知等测试用例

### 修复

- 修复 `HyperosConfirmDialog` 在嵌套导航器中关闭错误路由的问题：提前捕获目标 `Navigator`，避免 `useRootNavigator: true` 时弹出错误路由
- 修复 `HyperosNumberPicker` 范围变更时 `itemExtent` 不匹配导致的滚动控制器断言崩溃
- 修复 `FrostedHeaderController` dispose 期间 `TickerProvider` 已卸载时 `animateTo` 触发断言失败

### 调整

- `.gitignore` 新增 `layout_dump.json`、`package-lock.json`
