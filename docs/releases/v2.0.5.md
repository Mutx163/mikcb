# v2.0.5

> 相对 **v2.0.4** 的**完整累计**预发布说明。  
> 开发过程中的中间迭代记为 **v2.0.4.1 → v2.0.4.5**（未单独打 tag）；本文件为全部集合，对外发版与更新检测只认 **v2.0.5**。

### 新增

- 局域网编辑：支持「离开后保持开启」——回到设置页可选择继续运行，不必每次重新开服务
- 局域网编辑：控制台支持浅色 / 深色主题切换，并记住本机偏好
- 局域网编辑：浏览器端支持切换课表档案
- 关于页：新增「开源许可证」列表（本应用 GPL 说明 + 第三方组件许可证检索）
- 课程总览：冲突详情页（互撞组合、时段，可跳转对应排课编辑）
- 导入课程：首页增加「随机预设色」总开关（各导入子页统一）
- 运行日志：独立解析能力，大文件更顺畅，支持单条展开详情
- HyperOS：胶囊滑块轨道样式、控件无障碍语义，界面组件与语义色更完整
- HyperOS：列表滑动到顶 / 到底时提供轻触反馈（各设置页与可滚动列表通用）
- 课程统计：支持模块化长图导出（可选模块）与品牌水印，便于分享完整学期数据故事
- 捐款名单：添加欧宝XOU

### 优化

- 局域网编辑：控制台统一白系风格；课程库「新建课程」固定在工具栏右侧；课程卡片标题、时段与操作区更清晰
- 局域网编辑：「离开后保持开启」与页面状态、状态栏通知对齐，返回设置再进入可正确恢复运行中会话
- 局域网编辑：访问地址与 PIN 等同排版，去掉网址外框；避免 `http://` 与 IP 难看断行；复制按钮改用 HyperOS 标准图标按钮
- 局域网编辑：从课表网格点进某节课时，弹窗优先展示并高亮该时间段，不必在多时段里翻找
- 课表档案：单门坏课不再整库清空；档案更新与情侣课表导入 / 解绑更稳
- 课表写入：重命名前合并当前课表，避免旧数据盖掉新修改
- 云同步：自动上传前校验云端基线，远程已变时不再静默覆盖本机上传
- 局域网写操作绑定当前课表会话，课表不一致时提示刷新
- 云恢复：快照不带教务密码时，不再用空密码覆盖本机已记住的同账号密码
- 回到前台时先自动拉取云同步再刷新超级岛，减少短暂显示旧课表
- 更新检查：优先按版本构造 APK 直链，国内网络下更稳
- 正式包恢复教务门户与自建 WebDAV 等 HTTP 场景可用性
- 超级岛 / 桌面小组件：完整识别法定假日与自定义假期，假日当天正确隐藏课程
- 节假日变更后强制刷新小组件与超级岛；自定义补班可覆盖法定假日，假期模式下补班仍可上课
- 超级岛：初始化失败可自动重试；回前台自动校准显示；假日变更会正确收起超级岛
- 设置页分区标题统一为「灰标签在上 + 白卡片内纯控件」
- 布局与节次：滑块改为「左标题 + 右数值」
- 时间模板：快速生成弹层在编辑与管理页共用
- 页面转场圆角更自然；「转场速度」挪到外观与配色
- 节假日：主页更精简；刷新与更新日志收入高级设置；自定义假期可编辑删除
- 课表管理：列表、更多操作与新建 / 重命名弹层对齐 HyperOS
- 提醒时段等页对齐系统设置列表风格
- 使用引导隐私正文、关于页说明排版与字号色阶更统一
- 选择列表打开时自动滚到当前选中项；选中标题主题蓝；行分隔与边距更准确
- 冲突课透明度默认值调整为 0.70（已有配置不变）
- 反馈页酷安 / 小红书等链接在 MIUI 上打开更可靠
- 课表「回本周」浮动按钮毛玻璃效果更稳定
- 矮高度卡片圆角更自然，避免单行控件变成「胶囊」
- 列表到边触感：仅在内容真正到达边缘时轻触一次；需滑入约半屏内容后再回边才会再次震动；边缘附近反复小幅拉动不重复触发；页面重建时状态保持稳定；强度与系统选择/开关一致

### 移除

- 设置页去掉偏好列表上冗长黑色卡片标题与大段灰色脚注
- 课程总览去掉冲突分区重复列表，改为入口 + 独立冲突详情页
- 纯单选列表（如下载渠道）默认不再画小蓝点
