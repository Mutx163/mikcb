# v2.1.3.3

- 修复 打开 Bing 图库可能删掉别的课表正在用的壁纸：图库原本只把「当前这一张」算作要保留的，漏掉了其余课表和草稿里正在用的那些，缓存一满就会把它们当垃圾删掉，首页当场裂图。现在按所有正在使用的壁纸一起保护。
- 修复 外观编辑页退出后又「回魂」弹出一个新页面：关掉页面时若还有等弹层收起才推的页面，它会推到已经退栈的页面上。现在页面一退出，这类推页就直接放弃。
- 修复 Bing 壁纸「每天自动更换」那颗开关点了没反应：开关那一行插在弹层里、不在设置页的界面树下，页面自己的刷新带不到它，于是值其实已经存好了、灯却不亮（下载照跑、提示照弹，看上去像只有提示在动）。现在那一行自己盯着存档变化，与它挂在哪一层无关。
- 修复 开启自动换后不再多弹一页要你拖动取景：原先要弹出一页要你拖位置再点「完成」，还会顺手把壁纸设置弹层收起来，看着就像「点了没反应」；现在直接按默认状态应用。
- 修复 冷启动时 Bing 自动换跑两遍：冷启动与回到前台两条路会同时触发，而「今天换过没有」是先读后写的判断、没有互斥，于是下两遍也写两遍。现在第二次直接等第一次的结果。
- 修复 定位失败时白等一轮：定位的原生预算约 12 秒，而 Dart 侧的超时是 10 秒，于是正常返回的坐标也被砍成超时、再走一次兜底，白白多等一轮。现在超时放宽到 15 秒。
- 修复 外观编辑页的「完成」与「取消」在弹窗刚收起那不到一秒里点了没反应：那时栈顶还压着弹窗那条路由，按钮关掉的是它、当前页纹丝不动，画面上像什么都没发生。材质面板那条路径同样有这个问题，一并修好。
- 修复 两处健壮性缺口：超级岛的原生通道此前没有超时上限（原生主线程一卡就没有恢复路径）；没绑定时间模板的课程缺少最基本的数据校验，畸形节次会一路写进库里。
- 优化 自动换的三种结局现在各有一句话：换成功、今天已经换过、以及 Bing 还没放出今天那张（会如实说明先用哪一天的那张顶一顶，例如「昨天」），不再有结局是安静无声的。
