# v2.1.3.3

- 修复 Bing 壁纸「每天自动更换」那颗开关点了没反应：开关那一行插在弹层里、不在设置页的界面树下，页面自己的刷新带不到它，于是值其实已经存好了、灯却不亮（下载照跑、提示照弹，看上去像只有提示在动）。现在那一行自己盯着存档变化，与它挂在哪一层无关。
- 修复 开启自动换后不再多弹一页要你拖动取景：原先要弹出一页要你拖位置再点「完成」，还会顺手把壁纸设置弹层收起来，看着就像「点了没反应」；现在直接按默认状态应用。
- 修复 外观编辑页的「完成」与「取消」在弹窗刚收起那不到一秒里点了没反应：那时栈顶还压着弹窗那条路由，按钮关掉的是它、当前页纹丝不动，画面上像什么都没发生。材质面板那条路径同样有这个问题，一并修好。
- 优化 自动换的三种结局现在各有一句话：换成功、今天已经换过、以及 Bing 还没放出今天那张（会如实说明先用哪一天的那张顶一顶，例如「昨天」），不再有结局是安静无声的。
