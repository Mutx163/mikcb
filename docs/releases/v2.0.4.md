# v2.0.4

> 自 **v2.0** 以来的累计更新。中间迭代按 **v2.0.1 → v2.0.2 → v2.0.3 → v2.0.4** 分段列出，便于对照你本地做过的小版本。

---

## v2.0.1

### 新增

- 新增超级岛课前快捷操作自动恢复：静音或免打扰会在下课后自动恢复，重启手机后也会恢复

### 优化

- 优化课程统计界面：成就徽章配色、课程排名可展开查看时段详情，总览、每日分布、必修/选修比例与数据故事卡片统一 HyperOS 视觉
- 优化应用启动：老用户可更快进入主界面，版本信息异步加载不再阻塞首帧
- 优化关于页更新检测：应用图标居中展示，当前版本与最新版本对比更清晰
- 优化添加考试页表单布局与课程关联选择体验
- 优化数据迁移页概览信息排版
- 优化应用内更新日志与 Release 说明的阅读排版
- 优化课表方案与时段方案读取性能
- 优化课表首页壁纸预加载，不再阻塞首帧

## v2.0.2

### 新增

- 新增云备份列表页：可查看 WebDAV 历史备份，支持按备份项执行恢复与删除
- 新增云备份索引服务：统一管理备份 ID、索引序列化、去重与按规则清理
- 新增服务消息与运行日志多语言体系：错误码、导入结果、同步失败原因等可按当前语言展示
- 新增 WebDAV 同步互斥门闩：避免上传/拉取/恢复并发导致状态错乱
- 新增课程周次、节假日名称、枚举值等辅助本地化模块
- 新增 i18n 合并与审计脚本，便于批量维护 ARB 与日志文案

### 优化

- 应用对外名称统一为「轻屿课表」，调试版/性能版标题同步纳入多语言
- 全面补全中/英/日/韩及繁体界面文案，覆盖设置、导入、云同步、统计、超级岛、局域网编辑等主要流程
- 优化 WebDAV 同步流程：补全备份索引读写、当前备份标记与恢复后回传策略
- 优化云同步设置页：补充云备份入口与相关交互反馈
- 优化添加课程、考试、导入与数据迁移流程的提示文案，减少误操作
- 优化课程统计展示：总览、成就徽章与数据故事组件视觉一致性提升
- 优化 HyperOS 顶部浮层标题栏点击层级，修复右上角操作按钮偶发不可点击
- 优化课表导入页与快捷导入宏交互，对齐 HyperOS 审计规范
- 优化 Android 今日课程小组件文案，支持多语言资源
- 优化局域网 Web 编辑页脚本与 i18n 加载
- 优化超级岛测试流程：防重复点击、测试期间启用上课态展示，并提示返回桌面查看
- 超级岛测试页在未设置开学日期时给出明确提示

### 修复

- 修复超级岛在 App 未运行时误弹：后台闹钟 / WorkManager 唤醒后，若今天无课、处于假期或未设置开学日期，会停止已显示的超级岛并重新调度
- 修复超级岛上周课程残留：调度路径按真实日历周次重算选课，单双周、自定义周、结课周后不再弹出旧课
- 修复超级岛误弹修复影响前台上岛：前台直启与测试路径不再被课表快照校验误杀，恢复 v2.0 上岛体验
- 修复超级岛测试被课表快照校验立即终止的问题
- 修复 Flutter 选课在设开学日期后未按日历周过滤结课周课程的问题
- 对齐原生调度与 Flutter 逻辑：单双周、自定义周次、停课周、课后窗口等场景结论一致；学期前周次计算与 Dart 对齐（`week < 1` 返回 0）
- 修复 v2.0 HyperOS 审计项与快捷导入相关交互问题

## v2.0.3

### 新增

- 新增情侣课表：支持导出当前课表给对方导入，绑定后在首页一键开启叠加视图
- 情侣叠加视图直接在课表首页展示：我的课 / TA 的课 / 一起上课 / 共同空闲四色语义，共同空闲时段以淡绿底高亮
- 新增情侣课表设置页：导出、导入、解绑与绑定状态管理；对方课表以只读 Profile 保存，不影响当前课表与超级岛
- 新增情侣课表坚果云独立登录与自动拉取：可为对方课表单独配置 WebDAV 账号，定时同步对方课表
- 新增情侣课表课程详情与周次偏移：支持查看对方课程详情、按周次偏移对齐学期，并可自定义叠加颜色
- 新增运行日志查看器实时流：支持日志增量监听、自动跟随最新、时间正/倒序切换与显示选项折叠
- 新增超级岛测试夹具与触发服务，便于诊断页复现上课态场景
- 新增应用字体规格模块，系统字体与 MiSans 切换时同步作用于 Forui 排版体系

### 优化

- 优化课程操作菜单：冲突课程支持分段切换预览、冲突列表可展开查看，长内容滚动体验更稳定
- 优化课表首页顶栏：已绑定情侣课表时显示心形开关，点击即可开启/关闭叠加模式
- 优化课表设置列表：情侣课表入口右侧仅显示简短绑定状态，避免冗长副标题
- 优化 HyperOS 页面框架、过滚动回弹、浮层标题栏与选择/输入组件的视觉一致性
- 优化课表设置、添加课程、课程模板选择等页面的 HyperOS 布局与交互细节
- 优化问题反馈页平台入口图标：GitHub / 小红书 / 酷安 / QQ 更换为真实品牌图标，并按品牌配色调整底板对比度
- 优化课程统计任务收尾与展示细节
- 补全与调整多语言文案（情侣课表、运行日志、服务错误提示、枚举值等）
- 优化应用运行日志记录与 MIUI 超级岛通道相关日志条目

### 修复

- 修复 HyperOS 浮层标题栏在部分页面右上角操作按钮点击区域不稳定的问题

## v2.0.4

### 优化

- 优化节假日设置页：官方节假日名称统一走本地化映射，历史英文缓存名称可自动回退为当前语言文案
- 优化节假日更新日志区：移除固定高度造成的空白感，滚动手感改为更稳定的无阻尼风格

- 优化「外观与配色 > 文字颜色」布局：修复内容整体右移与缩进异常，恢复与同页设置项对齐
- 优化超级岛显示设置（上课前/课中下课）：修复「展开态大图标」等单行选择项视觉偏上、卡片高度异常与交互不统一问题

- 优化 HyperOS 过滚动阻尼参数，改善列表拖拽回弹手感
- 优化 overlay 子页顶部毛玻璃：修复路由 settle 期间重复调度导致模糊长期不生效的问题

- 修复法定节假日在部分缓存场景显示英文的问题（如 Public holiday / Holiday）
- 修复 edge-to-edge 单行选择行在部分页面的底部 inset 误判导致的垂直偏移问题

### 调整

- 移除桌面小组件页面底部灰色说明文案，简化页面信息层级
