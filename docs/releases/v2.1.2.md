# v2.1.2

- 新增 桌面卡片「情侣课表」：导入 TA 课表后，各桌面卡片绑定可选「情侣课表」合并视图——我的课与 TA 课按周偏移映射到同一时间轴，同时段同名合并为「一起课」，我 / TA / 一起三色一眼分清；点击打开情侣课表覆盖层，与单独绑定「TA 的课表」并列可选。
- 新增 情侣课表卡片后台实时合并：App 不在前台时，桌面卡片仍按双方课表实时算合并结果，TA 课开课倒计时照常走字；TA 解绑后自动回落「跟随当前课表」。
- 优化 玻璃模式设置：由四档收敛为「实体卡片 / 高斯模糊 / 液态玻璃」三档，与引导页「视觉效果」同一套说法；原先独立的「启用模糊」开关并入档位，选项更少、更好选。存量设置自动兼容，观感不变。
- 优化 壁纸页玻璃开关：首页「顶栏高斯模糊 / 信息栏高斯模糊」更名「顶栏玻璃 / 信息栏玻璃」，说明改为材质跟随全局玻璃模式；关闭即直接透出壁纸，在实体卡片档下也不再自相矛盾。
- 优化 关闭模糊后的说明文案：改为准确描述——弹窗类为不透明纯色底，首页模糊区域与「回本周」按钮为半透明，均不再采样模糊。
- 修复 实体卡片模式下部分菜单弹窗行文字看不清：右上角菜单在实体卡片档曾出现白字写在白底上，现已按材质自动改用主题墨色。
- 修复 教务导入：http 开头的学校门户恢复可导入。此前域名白名单无法覆盖适配仓持续新增的 http 教务地址，部分学校 WebView 登录会被系统拦下。
- 修复 情侣课表卡片跨周与停课显示：周日收课后的「明天」条、我方停课周、双方周窗口不重叠时，不再把课配错对或吞掉 TA 独有的课；颜色与是否合并与 App 内情侣课表一致。
