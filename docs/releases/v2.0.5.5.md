# v2.0.5.5

### 新增

- 地点时间匹配：按教室关键词自动绑定时间模板（前缀/包含/精确匹配，长词优先），支持预览命中与一键应用到当前课表
- 地点时间匹配：教学楼关键词可聚类辅助配置；手动指定过时间模板的课程不会被覆盖
- 课程备注：支持「整门课」与「本节课（按周）」两套备注，本节课可标记作业
- 课程卡片与日视图：有备注/作业时显示角标；点备注可打开编辑（情侣课表只读）
- 情侣课表日视图：开启叠加后显示「共同空闲」摘要（具体时段、段数与时长；对方课表过久未更新时提示可能不准）
- 时间模板：支持按日期区间切换作息（例如暑期前后不同作息，最多 2 条且区间不重叠），规则可随云同步
- 首页下拉快捷导入：外观设置可开启；在课表首页下拉后于后台执行教务快捷导入（需已保存导入路径）
- 首页下拉快捷导入：进行中可取消；需验证码等手动操作时提示前往教务导入页继续

### 优化

- 云同步：本机已有课表且尚未建立同步基线时，后台自动拉取不再静默用云端整表覆盖本地，需在云同步页手动处理冲突
- 云同步：校验远端 meta 与快照内容哈希一致，避免基线与文件不一致
- 云同步：地点时间匹配规则随课表快照一并同步
- 数据导入：单课表「覆盖导入」会清空旧日程条目，避免课表已换但日程残留
- 课程冲突：按实际上课周（含自定义周次）判断，教务仓导入后不再因默认 1-16 周包络漏检冲突
- 教务导入：课程周次、星期、节次规范化，学期周数抬升设上限；适配脚本优先拉取官方源，镜像仅作回退
- 教务导入 WebView：Bridge 回传 requestId 做安全校验与 JSON 编码，降低注入风险
- 情侣课表 WebDAV：上传与拉取改为双槽位文件，避免本机「上传后再拉取」把自己的课表当成对方课表
- 考试提醒：通知权限未授予时不再丢弃该次提醒计划，授权后仍可送达
- 考试编辑：结束时间不能早于开始时间
- 桌面小组件：周次计算与主界面、超级岛一致（按周一对齐），减少杀进程后错周显示
- 日视图：「回今天」仅在学期周范围内可跳转，学期结束后不再错误跳到不存在的周
- 首次使用引导：未勾选隐私同意前，欢迎页「导入 / 恢复」会引导至隐私页，不再绕过同意直接初始化统计
- 完整备份导入：若备份中无情侣课表档案，自动清理悬空的情侣绑定
- 外观与小组件设置：滑动调节后快速返回时也会保存最后一次草稿
- 周次表达式：整式括号奇偶不再错误污染多段周次
- 应用内更新日志：补全 v2.0.5.1 至 v2.0.5.4 条目
- 隐私说明：补充「局域网编辑」数据流说明
- 情侣共同空闲：按我的教学周与对方周偏移分别计算忙碌时段，优先使用课程真实起止时间，减少错周与假空闲
- 日视图课程卡：备注入口移至右上角，不再挤在地点信息下方
- 课程备注弹层：键盘弹出时自动抬升并滚到当前输入框，无需切换到另一套编辑布局
- 课表设置：地点匹配入口收拢到时间模板管理，避免设置页重复入口
- 地点时间匹配：应用到课表时说明「钟点未变化 / 节次超出模板」等原因，减少误以为没有生效
- 地点时间匹配：同一关键词不可被多个地点组重复占用，避免规则互相覆盖
- 地点时间匹配：教学楼识别支持「A综D101」等字母+中文楼名，避免误拆成教室号
- 地点时间匹配与时间模板管理：列表、入口与空状态对齐 HyperOS 设置风格
- 添加 / 编辑课程：自动模式下直接展示实际生效的时间模板与起止钟点
- 日期切表：到开始日一次性把所选模板套用为所有课表的默认作息并更新课程钟点；同一规则不会每日重套，便于保留手改
- 超级岛：按当日日期解析节次钟点，暑期等日期规则当天即可生效
- 地点时间匹配：教学楼聚类覆盖更多校名写法（逸夫楼 / 理工楼 / 教室标签 / 线上平台 / 英文 Building·Hall 等），自定义地点也更易生成可用关键词
- 地点时间匹配：一键应用按结果区分「已更新钟点 / 已对齐无需改写 / 节次超出模板 / 无匹配」，提示更准确
- 地点时间匹配：再覆盖「1号楼 / 12栋 / 教1 / 东12」等常见写法，操场、线上会议与带校名的地点也更易识别
- 情侣课表 WebDAV：连接时可选择本机槽位（1 或 2），双方须不同槽位才能互读课表
- 情侣课表 WebDAV：只认双槽位文件，不再回退旧版单文件路径，避免把本机课表误当成对方
- 课程冲突 / 共同空闲 / 一起上课：停课周不再计入实际冲突或忙碌
- 拆分周次时保留「本节课」备注与作业标记
- 覆盖导入课程：确认文案说明会一并清空当前课表上的独立日程
- 地点时间匹配：一键应用结果提示更稳，不必连点两次
- 关闭系统触感时，列表滑到顶 / 底也不再震动
- 深色模式下关闭毛玻璃时，提示条文字仍清晰可读
- 桌面小组件：假日当天仍会在次日零点刷新，离开假日模式更及时
- 云同步：后台因冲突取消的同步会留下可查看的原因提示
- 系统提示默认约 2 秒自动消失，带撤销等操作的提示也不再长时间挡屏
- 超级岛测试入口在正式版也可进入，便于自助验证提醒与显示
- 地点时间匹配：改为「重新匹配当前课表」——命中课程恢复自动匹配并同步钟点，此前手动指定的模板会被清除；未命中课程不变（操作前确认）
- 日期切表：保存后按情况提示「今天已更新全部课表默认作息」或「将在开始日生效」
- 设置列表开关：整行点击更稳定，减少误连点导致开关连切
- 考试列表：同一天内按开始时间排序；结束时间须晚于开始时间
- 考试提醒：通知权限恢复后，会补发近期未能弹出的提醒
- 课表档案切换与操作弹层更顺畅
- 官网首页并入适配学校列表，支持搜索与字母索引
- 日期切表：若今天应自动套用但模板节次不足等导致失败，会明确提示「已保存但自动套用失败」
- 云同步：首次自动拉取时，本机已有地点匹配、日期规则、自定义模板等用户数据也会保护，不静默被云端覆盖
- 云同步恢复：先恢复地点匹配与日期规则，再导入课表，地点自动钟点更准确
- 日期切表：删除规则不会自动还原已套用的作息，需自行调整；套用后钟点可继续手改
- 云同步：不再上传调试用的临时测试课程；日期规则「已套用」状态可随快照同步
- 桌面小组件：内容未变时减少重复刷新，更省电
- 云同步网络：弱网超时更快失败，避免界面长时间无响应
- 教务导入：该校首次网页登录导入时，会在后台静默记录操作路径；导入成功后可选择保存为「快捷导入」
- 教务快捷导入：录制时同输入框连续输入只保留最终内容，回放更稳、更少误触发页面监听
- 日期切表：自动套用失败时写入运行日志，便于对照模板节次是否足够
- 教务快捷导入：有脚本页地址时优先「登录后直达课表页」加速路径，失败再回退完整点击录制
- 课程备注：「整门课」改为「课程简介」，与同名课程共享；旧版整节课备注会迁移到简介
- 情侣课表：爱心叠加开关会记住上次开关状态
- 情侣共同空闲：按完整节次时间范围估算，不再额外裁到 8–22 点；摘要只显示段数，版式更简洁
- 日视图：关闭按钮与日期、课程数信息布局更清晰
- 周视图：时间列周次标签略向右对齐，与节次数字视觉中心更一致
- 外观设置：相关选项合并为更少分区，预览与列表对齐 HyperOS 设置风格

- 导入课程首页：导入方式改为设置导航行样式，副标题更短，并带彩色图标
- 教务快捷导入：回放成功时不再叠出脚本「成功导入 N 条」轻提示与完成弹层
- 快捷导入完成弹层：结果说明显示在关闭按钮上方，阅读顺序更自然
- 课程总览：排序改为标题栏旁弹出选择，不必再开整页底栏
- 添加课程弹层：去掉多余副标题，选项更紧凑
- HyperOS 滑块行：整行可按压高亮，避免标题条被裁成小胶囊
- 设置列表含输入框时：滚动不再卸载表单项，避免输入内容滚动后空白需再点一次
- 添加课程 / 地点匹配 / 超级岛测试等：卡片内开关与选择行改为通栏按压，边距不再叠双层
