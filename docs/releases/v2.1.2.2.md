# v2.1.2.2

- 新增 周视图长按空白格加课：长按周视图里没课的时间格，出现虚线框和加号，点一下直接打开已经预填好周次、星期、节次的加课表单；按着不放可以拖着换格，换格时有轻微震动，点空白处取消选择。开关在「课表页面设置」里，默认关闭，关着的时候空白格和以前完全一样。
- 新增 日历导出自选去处：导出按钮生成课表文件后弹窗二选一——直接分享给日历应用，或者保存到手机上你指定的目录（不需要存储权限）。
- 优化 设置说明文案：25 条设置项副标题收紧，去掉重复解释和口语化表述，关键提示（授权、密码、条数上限等）保留，六语言同步。
- 修复 已结课的课程不再以「非本周」灰课常驻后续周：开着「显示非本周课程」时，已经上完的课（停课周、单双周、自定义周次都算进去）不再在之后的每一周里灰着出现；还没开始的课程仍照常灰色预览。
