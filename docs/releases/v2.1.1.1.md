# v2.1.1.1

- 新增课程配色：预设色板从 9 色扩充至 104 色，选色改为快捷色行 + 全量调色盘，编辑页提供带实时预览的专用配置弹窗，确认后才生效。
- 新增随机配色：导入课程时可按组选择随机配色（马卡龙、活泼、深色系），并新增多巴胺、落日、海洋三套高颜值鲜艳配色组。
- 新增超级岛快捷操作：静音 / 免打扰按钮按当前真实状态一键切换，已开启时显示「取消」可直接关闭；上课前的快捷动作支持自动执行。
- 新增超级岛自检：无课可测时自动注入自检预设课且不写入真实课表，测试课改为开始 / 取消开关，可一键取消、自动结束自动回弹。
- 新增更新提醒：启动检测到新版本时首页自动弹出更新页，可在设置中通过「弹窗提醒」开关控制（默认开启）。
- 新增鸣谢名单：添加 L*n。
- 优化安装包体积：锁定 arm64 架构并剔除冗余 ABI，安装包减小约 10MB。
- 优化二维码传输：「发送全部数据」可正常使用，发送 / 导出失败时明确提示而不是无反应，分享弹窗样式更统一。
- 优化学期进度：改按天精确计算，开学前显示 0%，不再预支整个第一周。
- 优化壁纸：铺放范围与模糊开关默认全开。
- 优化玻璃坞底栏：切换与点击的震动反馈更准确，再点当前内嵌页不再多余震动。
- 优化周次选择：液态玻璃弹窗的格子改用半透明白井 + 描边 + 纯黑墨，文字清晰可读。
- 优化课程导入：教务门户记住密码不完整时保存与自动补录判断更可靠，网页导入退出页面后不再偶发闪退。
- 优化界面细节：日课表摘要卡课程计数胶囊统一墨色，星期栏考试红点不再挤压格子，文字颜色设置两页不再重复显示同一批颜色行，底栏按钮编辑器提示文案更中性。
