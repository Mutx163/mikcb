# v1.1.10.4

- 识图导入教程改成更直接的操作链路：先复制提示词，再去豆包专家模式发送截图和提示词，把返回的 JSON 复制回来导入，最后选择开学日期。
- 导入课程时新增并强化了开学日期、课表第 1 周对应校历周次的确认流程，尽量减少学校第一周没课导致的周次错位。
- 首页课表点击课程卡片后改为弹出快捷操作卡片，可直接编辑、调课、删除；删除支持“删整个课”和“只删这节课”。
- 临时加课 / 单节课现在可以直接沿用已有课程的共享信息，不必重新输入课程名、老师等内容；同时不再误带入教室、星期、节次这类非共享字段。
- 修正识图导入页长文案下拉框的横向溢出，进一步收紧导入页的说明文案和交互引导。
