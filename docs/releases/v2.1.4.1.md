# v2.1.4.1

> 本次重点：更新日志改成「本次重点 + 分类分组」、软件更新页重做、转场更顺

## 新增 · 2

- 更新日志有了「本次重点」与分类分组：每个版本顶部最多 3 条重点，条目按新增 / 优化 / 修复 / 移除分组并带条数；更新弹窗、软件更新页、历史版本页、官网都按同一份显示，一版几十条时先看重点、再看规模。
- 历史版本页改成「3 条重点 + 分类计数 + 分组展开」，翻旧版本不再先读一整段原文；121 个历史版本也补齐了各自的本次重点（只加摘要，功能条目一条没动）。

## 优化 · 8

- 软件更新页重做：一个状态只给一个动作（有更新才出现「立即下载」，已是最新换成「重新检查」），版本关系压成一行「旧 → 新」，更新说明默认展开，短版本不再给折叠入口。
- 软件更新页文案收紧：「暂时无法读取版本信息」→「检查更新失败，请稍后重试」，更新时间改「更新于 …」，去掉两条几十字的长提示；日文 / 韩文里一直是英文的两条状态标题补上了译文。
- 应用图标换成「发丝描边 + 同色系极轻投影」，关于页与软件更新页统一。
- 首页菜单改成「先收缩、再推页面」，点进新页面时不再出现收缩与推页同时进行。
- 转场更顺：进页面时把首页悬浮钮、回今日钮与顶栏玻璃带冻结成预糊位图，不再每帧重跑高斯模糊。
- 转场时栈顶页的淡出与压暗合成一层，不再糊一层全屏透明矩形。
- 小组件效果预览更跟手：渲染移出主线程、像素扫描改成逐行。
- 视差为 0 时不再多铺一屏宽的右侧补底。

## 修复 · 11

- 软件更新页三个真问题：「已是最新版本」下面挂着一个能点的「立即下载」；检查失败被画成「已是最新版本」；下载过程中按钮写着「正在取消下载……」。
- 「查看 Release」以前永远打开 GitCode 的某个版本页，切换下载渠道也不变；现在打开发布页列表，并按渠道选主机（GitHub 渠道 → GitHub，其余 → GitCode）。
- 网络被限流、走页面兜底时，更新说明会退回整段原文（没有重点与分组）；现在兜底抓到的正文会还原成 Markdown。
- 更新清单只走官方直连，第三方镜像不再参与版本号与更新说明的应答。
- 作息设置了空节次表时，作息管理页每次进入都崩溃、坏数据也删不掉。
- 并发下载同一张壁纸时，其中一次会被误报成「写入失败」。
- 备份恢复写盘没有走设置事务，中途被杀会留下「课表列表已更新、激活档还指旧档」的混合态；天气缓存写失败会吞掉随后的界面刷新。
- 备份 / 云同步 / 局域网传输包里个别字段类型不对时，整份备份会被拒收或整档静默消失；现在只跳过坏字段。
- 单条课程数据坏掉时，部分丢课既无备份也无日志；现在会隔离留档并在日志里留痕。
- 转场几处老问题：release 包里读调试属性抛异常、每次转场泄漏一个动画对象、冻结位图被过度模糊、返回后按钮停在模糊位图上。
- 外观编辑页偶发「build 期间 setState」报错。
