# v1.1.10.27

- 优化更新检查逻辑：现在会同时结合 GitHub Releases 接口和页面兜底解析，在代理 / VPN / 接口限流等情况下也更容易拿到新版本信息，并自动跳过没有 APK 资源的失败构建。
- 优化课程冲突弹窗：当前课程和冲突课程会分开显示，每张课程卡片都带独立快捷操作，编辑、调课、删除时不容易点错对象。
- 优化课表更新逻辑：更新课表时改为覆盖当前课程数据，同时保留本地维护的简称、颜色、备注、课程简介和课程级时间模板覆盖，避免因增量合并残留旧课而出现重复课程。
- 优化多语言覆盖范围：最近导入、课程导入、课程总览、反馈、课表复制以及课程卡片等页面继续接入本地化文案，切换语言时显示更完整。
