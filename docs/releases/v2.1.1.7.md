# v2.1.1.7

- 新增 日程安排列表页：课程、考试、自定义日程三类时间实体有了统一浏览管理面，不用再回课表格子里逐个翻找。
- 新增 GitCode 国内直连更新渠道并设为默认：检查更新同时向多个渠道并发查询择优，国内下载更快更稳；下载失败自动回退 GitHub 直链重试，关于页测速同步支持新渠道。
- 新增 统计页环形图对称空态：暂无数据时给出引导而非空白；深度分析入口与课表对比整合为一张入口卡，页面更聚焦。
- 优化 统计页课表对比：改为表格式布局（指标做列、课表做行），二级页直接平铺全部指标不再点行弹窗；名字列不再随内容漂移，表头不再截断。
- 优化 统计页深度分析二级页：改为独立整页模式，读数字号放大到正文刻度，消除整页小字加大片留白；组头改为卡内小节标签，层次更清晰。
- 优化 时间利用卡：改纵向键值对列表，去掉固定宽度留白，空读数有兜底。
- 优化 统计页排版：大数字统一字重，tooltip 与成就徽章亮暗对比度自适应，成就网格间距放宽。
- 优化 周视图：移除与主视图重复的概览卡，信息不再出现两遍。
- 优化 日程编辑页：开始/结束时间选择块统一为全 app 表单字段样式，启用日程开关独立成卡更好找；同日常规日程不再显示「结束须晚于开始」常识提示条（保存时仍有校验兜底），半宽字段去掉尾部箭头后「下午 12:00」类长值不再被截断；浅色模式下提示条、考试关联占位井被误渲染成黑块的问题一并修复。
- 优化 教务登录页：压缩顶部固定内容给网页让出可视高度；键盘弹出不再把网页挤变形，聚焦输入框时自动滚动；右上角菜单黑色面板、全局玻璃降级为实色防遮挡等显示问题修复，桌面/移动切换恢复生效。
- 修复 启动挂死：启动管线 6 秒无响应时看门狗强制换入首页，不再永远停在启动画面。
- 修复 应用内更新安全：拿不到官方 SHA-256 摘要的安装包一律拒绝在应用内安装并引导前往发布页；GitCode 渠道发行版未内嵌摘要时自动从其他渠道补齐，不再误拒正常安装。
- 修复 桌面小组件：2×2 卡片教室行末尾凭空省略号，2×4 统计卡标题/进度假截断，4×2 横宽卡表头重复与顶线错位，深色模式风格退化与芯片文字对比度。
- 修复 数据健壮性：本地数据空判定归一化，迁移引导不再因自动回填字段而永不弹出；自定义假期设置页区分「暂无假期」与「存储损坏」，损坏时明确提示；课表错误处理路径不再二次抛异常。
- 修复 底栏导航：内嵌页按系统返回先收回页面、日/周课表却直接退出的口径不一——现在任意底栏状态按返回统一退出应用。
- 移除 ghproxy.cn 镜像预设：该域名已被抢注为待售页，继续放行存在被恶意利用的风险；从镜像候选中整体移除，存量选择自动回退其他镜像。
