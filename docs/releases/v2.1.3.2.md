# v2.1.3.2

- 新增 首页顶栏玻璃带「跟随默认材质」：会随整机默认材质自动切换为实体卡片、高斯模糊或液态玻璃；该选项的出厂值仍为单独指定液态玻璃，不会擅自改动已有观感。
- 新增 顶栏翻页改成 MIUI 那种筛选胶囊：材质面板顶部（通用 / 课程卡片）换成独立圆角胶囊，选中那格填主题色、按下有反馈；与设置里那些「选值分段」在含义上分家（胶囊 = 哪类看，短线标签 = 翻页）。
- 新增 面板里的选值分段与全站统一：数据统计、任务列表、假期设置等页的分段按钮改成同一种样式；材质面板的分段改为通栏、撤掉标题字，切到哪一格标题就是哪一格。
- 新增 壁纸「最近使用」可移除：每张右上角有看得见的「×」角标（长按也行），点一下那张卡自己进确认态、按「删除」才真删，删完还能当场撤销；正在使用的那张不给删并会解释原因。
- 新增 弹窗顶部渐变模糊带：材质面板顶部的分段坐到模糊带上，课程弹窗加一条空带；滚上来的内容不再被面板上沿硬切一刀。
- 新增 局域网编辑页支持英文 / 日文 / 韩文：原先这些语言的 App 用户打开编辑页会看到满屏中文；登录页也补了一句如实说明（这条连接是 HTTP、传输不加密，请只在你信任的网络上使用），绿色徽章不再写「安全连接中」。
- 新增 教务导入支持按教学楼分流作息：强智等教务按校区与教学楼类型公布多套作息，导入时按教室名自动套用对应的时间模板，套不上的用兜底那套；你自己建的分组不会被抹掉。
- 新增 教务导入的学校列表不再让用户在「标准版 / 增强版」里二选一：同一所学校的专属增强（按教学楼分流作息等）直接并进那条标准适配器，列表里只看到一条；增强探测失败时自动退回原样。
- 新增 教务导入的「已登录」识别：进入教务登录页时后台问一次「会话还活着吗」（已配置的学校自动生效），还登录着就在导入按钮上方说明可以直接导入，也不再弹「要不要帮你填密码」。
- 优化 材质选择与入口：材质名称统一为「实体卡片 / 高斯模糊 / 液态玻璃」，默认材质面板补齐三档；课程卡片设置改为跳转到同一材质面板，避免两处设置各说各话；没有壁纸时也会如实显示实体卡片，不再标成玻璃材质。
- 优化 应用级设置改为设备全局：材质、主题、语言、首页导航与底栏形态等不再跟着课表切换；首次升级时以正在使用的课表设置作为初始值。
- 优化 恢复默认的范围提示：外观页会提前说明主题、字体与玻璃质感会被恢复，课表页会说明壁纸也会被清除；液态玻璃的「恢复默认」明确只重置当前调参，不会动到整体材质或其他设置。
- 优化 子页顶栏玻璃：统一使用更明显的渐进模糊，模糊下沿向下延伸约一个字，标题与正文之间不再出现生硬的切边；原先单独的模糊风格选择已取消。
- 优化 外观编辑页三处观感：从右上角菜单进入时先收菜单、收完再起首页缩小；预览那份首页继承真实首页的滚动位置，落定后不再突然跳回置顶；落点交接时的暗闪也没了。
- 优化 课表管理：切换课表更快、列表顶部补上间距、大字体下列表不再压住标题、弹层不再残留或出现重复标题。
- 优化 界面文案大修：182 处措辞与标点（半角冒号、省略号、破折号、直角引号、占位符与中文之间补空格等）、60 处排版断句，以及 39 条术语统一（时间模板、桌面小组件、超级岛、备份、版本更新等，App / 原生 / 官网此前同名不同叫）。
- 优化 繁体文案：台湾版 778 条、香港版 112 条人工转修并逐字复查，繁体文件里不再有简体残留；桌面小组件按当地惯用写「小工具」（台湾）/「小組件」（香港），widget 与 component 不再混用；上一轮把 120 条台湾版文案多包了一层引号的回归、香港版 2 处品牌名错字一并修好。
- 优化 倒计时的三个单位选项：英文 / 日文 / 韩文的「分秒 / 纯分钟 / 纯秒」补上「Chinese units」并给出真实示例，不再选了之后对不上小组件上显示的「5 分钟 19 秒」。
- 优化 统计口径两处：跨夏令时的那一周不再少算一周，桌面小组件的「今天几节课」在有夏令时的地区不再数错（原先按固定 24 小时算）；中文教室名（如「第一教学楼-101」）现在能正确识别楼栋，不再把不同教室并成一栋，「3 号楼-101」与「3-201」也不再折成同一个「3」。
- 优化 官网四处：更新日志不再被截断（此前每个版本只显示前 8 条，这次的 26 条只剩 8 条）；「已适配 N 所高校」改为自动取真实数字，各语言不再各说各的，拉取失败时也不会露出 `{schoolCountBucket}` 这样的花括号；首屏四个数字居中，移除「求个 star」文案。
- 优化 帮助文档与官网文字：玻璃档位、材质入口路径、部署命令与当前软件对齐，照旧文档操作会找不到入口。
- 修复 教务导入：宏回放把录制的「选项文字」还原成脚本要的序号（此前每个带单选弹窗的脚本在录制回放下都会在弹窗出现后立刻「导入已取消」）；「选项已变化」时回退到脚本默认值而不是取消。
- 修复 首页顶栏选「实体卡片」后星期栏直接透出壁纸：实心条现在照常上屏把星期栏底色补齐，状态栏图标极性与墨色也按实心条判定；深浅色壁纸下「对比度不足」的提醒不再误弹。
- 修复 弹窗顶部渐变模糊带两处：开窗后模糊不出现（引擎侧坏登记，开窗后自动重登记修好）；有内容滚到带下时圆角外露出满浓度填充（白纱自绘圆角、模糊矩形按面板圆角走弧，形状与面板严丝合缝）。
- 修复 天气行闪现：预报还没到达时先摆一块看不见的等高空位，数据到了只换内容、课卡不再当场长高一格把下方内容顶下去；确定不会来数据的日子不占位。
- 修复 弹窗与菜单操作：关掉一节课的详情后马上点下一节会立即响应；右上角菜单尚未完全显示时不再误触不可见条目，菜单收起过程中也能马上重新打开；弹窗关闭后不再把键盘焦点遗留给隐藏控件。
- 修复 首页下拉快捷导入：手势被系统打断、落下第二根手指或页面重建时都能正常收场，不再出现半截圆环一直停住。
- 修复 课表导入与传输：局部传输不再改动设备全局设置；完整备份或写入失败时会恢复旧数据，取消、多指操作和页面提前关闭也不再造成假取消、卡住或结果丢失。
- 修复 设置保存可靠性：连续修改会按顺序写入，保存失败时回滚界面与旧数据并在下次启动时尝试恢复；损坏的旧记录会自动重建，拒绝保存时显示正常提示文字，不再露出内部代码。
- 修复 设置读档与回滚的一批：坏事务日志不再每次启动都抛错、把用户逼到清除应用数据；事务日志删不掉时，本次会话之后每次保存设置都会失败；写盘失败后「应用级偏好是设备全局的」会当场失效（切课表又改掉主题、材质、导航），并把旧值当成新的全局真源写回去；课程卡片的独立颜色读档后不再被默认色回填。
- 修复 导入体积上限补齐三条路：表格导入、备份恢复、以及从别的应用「分享」进 App 的那条路（此前完全没设限）；超限与读取失败也分成两条提示。
- 修复 局域网编辑页一批问题：课程名叫 `__proto__` 之类的名字会让整页打不开；教师名、地点、课程 ID 拼进网页时没转义，导入一份他人做的课表表格再打开编辑页即可触发；图标原本从外网 CDN 拉，手机或电脑没网时全部消失（已改为内嵌本地，并补齐 2 个漏定义的图标）；同时打开的请求数上限此前是空壳；中文界面下自定义星期标签不再显示成「周某个名字」。
- 修复 局域网编辑服务的安全与稳定性：同一 Wi-Fi 上别的网页现在打不进本机接口（不再白白烧掉 PIN 尝试额度），跨站表单发来的请求会被拒；同时最多 16 个请求并行、单个请求读取超时 20 秒、闲置 60 秒收摊。
- 修复 教务与云备份两处：云恢复后教务凭据的域名绑定会丢，原本只绑定某校域名的账号恢复后会对任意网站通过校验，凭据可能被自动填到钓鱼站上；一条坏调试记录曾同时打死教务子页与整次云备份，现在只跳过坏的那一条。
- 修复 考试列表页畸形课程颜色必现崩溃：颜色来自导入数据，一旦是畸形值整页渲染失败，现改为兜底色。
- 修复 日历导入可被恶意规则耗尽内存：一个 `UNTIL=99991231` 的重复规则就能在导入途中造出 41 万个周次条目。
- 修复 界面提示文字一批：40 多个还没登记的错误码会以机器码形式摆到界面上（`holiday_name:mid_autumn` 一类），现改为一句人话；表格导入报错不再把中文表头当代码名（英文 / 日文界面曾显示「星期 must be an integer」），行级警告也不再丢掉字段名（原先恒显示「第 7 行： 必须是整数」）。
- 修复 顶栏玻璃带下沿外推：原先多个页面静止时第一行小标题只显示下半部分（如桌面小组件页的「快速添加到桌面」）；外推改为按版面空白封顶，正文回到原位，标题与第一行的间距不再被整体撑大，「不透明窗口」也不再被撑宽。
- 修复 顶栏与玻璃观感一批：顶部那截改用更轻的均匀模糊（原先强模糊会把空白糊成一块平板）；从首页菜单进入外观编辑再返回时，右上角玻璃球不再偶发「图标在右上、玻璃跑到左上」的错位；返回键显影时补上小而柔和的阴影，不再被顶部磨砂带切出方形直边；底栏玻璃坞的阴影不再染灰；「回今日」浮钮也补上了外圈阴影。
- 修复 弹窗观感一批：弹窗面板不再挂手指高光（原先长按滑动时有一团亮光跟着手指跑，面板并不是控件）；往上拖把手不再把面板抬离屏幕底沿、露出那条白缝；顶部模糊带不再盖过拖动把手、糊成一整块渐变，弹窗顶部也只保留一根把手；带顶那条发白的硬边也没了。
- 修复 转场出场：顶部胶囊与底部圆钮改为按时间匀速淡入，点底栏进外观编辑时按压亮光不再被快照定格成一下闪光。
- 修复 筛选胶囊与材质胶囊三处：中性主题下不再黑底黑字、圆角收成整圆（不再按卡片口径留 6px 直边）、文字上下居中。
- 修复 输入框占位提示不再压住输入内容：「新建课表」这类只带灰色提示的输入框，打字时提示不再叠在文字上（全 App 约 30 处一起修好）。
- 修复 壁纸文件丢失不再静悄悄：路径还在但文件没了（换机、清数据、云同步只带回设置）时，设置里会有一条可点的提示，动作就是正下方那颗「选择图片」；「调整位置」里悄悄清掉失效路径的动作也会先说一声。
- 修复 桌面小组件在节假日时显示 `holiday_name:mid_autumn` 等内部代码，现会显示对应语言的节日名称。
- 移除 柔光玻璃选项与「高级材质」独立页面：材质档位统一为实体卡片、高斯模糊和液态玻璃，旧的柔光设置会自动转为液态玻璃；常用调参仍保留在「外观编辑」主面板中，同时清理已经无法从界面进入的旧预设与无效设置。
