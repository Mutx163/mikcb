# v2.1.1.8

- 新增 首页「二级悬浮菜单」：右上角菜单「添加课程」升级为 HyperOS 相册「视图」式展开，添加课程、日程、考试从父行原位的悬浮玻璃卡中直接选中，主面板自动让位退后、收起自然，点暗区或按返回键即可收起。
- 新增 悬浮卡片液态玻璃质感：二级菜单卡片真正折射出背后的首页内容，与主菜单同一套液态玻璃材质，展开与收起过程的折射、取色与一级弹窗完全一致，不再闪现横条、白边或透明窗口。
- 新增 关于页「请喝咖啡」入口：「支持与更新」列表新增请喝咖啡入口，一键直达支持开发者页面。
- 新增 鸣谢名单：添加 lxc。
- 优化 教务数据更新：更新渠道选择 GitCode 后，教务数据同步直接从国内镜像拉取，速度更快；拉取失败会自动回退到其他渠道重试。
- 优化 鸣谢名单加载：下载渠道选 GitCode 时名单同样国内直连获取，更快更稳，失败自动回退其他渠道。
- 优化 教务课源搜索：搜索无结果时提供反馈入口，遇到缺失内容可以直接反馈。
- 优化 首次同步体验：新设备首次「立即同步」不再被冲突提示挡路，直接以云端数据为准；真正遇冲突时弹窗会讲明白保留本机或使用云端的后果，并给出一键「以本应用数据备份」的入口。
- 优化 超级岛与上课提醒：系统限制后台启动时自动重试，超级岛不再莫名消失；应用升级后岛面配置得以保留，提醒状态不再跨课节残留。
- 优化 诊断页：新增自启动状态检测，不再一律显示未知；进程状态分类更细，问题定位信息更全。
- 优化 课程详情展开动画：打开课程详情不再逐帧卡顿、像幻灯片一样跳动，转场动画顺滑跟手。
- 优化 下拉快捷导入：下拉手势没回到顶部就松手时不再误触发更新；导入结束返回首页后，玻璃材质立即恢复。
- 优化 日程与考试时间选择：跨天日程在列表里带首尾日期显示，编辑时提示一次说清楚；日期/时间滚轮关闭后不再误弹出键盘，考试时间选择框不会被键盘遮挡。
- 优化 输入框可读性：未激活输入框的占位文字与框体对比度提高，浅色背景下也能看清，全局输入框统一生效。
- 优化 更新弹窗排版：新旧版本号过渡压缩为一行（旧版弱化、新版强调），更新说明左对齐、行距更舒适；公告里的分隔线改为纤细发丝线，与卡内其他线条一致，不再出现突兀粗黑杠。
- 优化 壁纸稳定性：更换壁纸或切换日/周课表时不再偶发闪退。
