# v2.0.9

相对 v2.0.8 累计说明（本地草稿；发版前需对齐 pubspec / tag / latest.json）。

### 修复

- 存储：`timetable_profiles` 解析改为按档案 / 按课降级，单门坏课不再整库 wipe；读时自愈写回清洗结果
- 存储：新增 `updateProfiles` 锁内读改写串行；Partner 导入 / 解绑走 RMW，避免与本地写 lost-update
- Provider：课表内存写统一走 mutation gate；rename 前 merge active 课程，避免陈旧快照盖盘
- 云同步：自动上传前校验远程 meta 是否仍为本地基线；远程漂移时取消上传（不静默 PUT 盖云）
- LAN：写操作绑定 `profileId` / session；active 不一致返回 409；与云 apply 共享 mutation gate
- 局域网编辑页：支持浅色 / 深色主题切换，并按本机偏好持久化
- 文案：澄清 v2.0.8「课程写完整串行化」仅覆盖 legacy `courses`，生产真源为 profiles
- 超级岛 / 假日：假日数据变更走完整 live gate（含 `stopLiveUpdate`），不再只推 schedule snapshot 导致岛上仍显示课程
- 超级岛 / 假日：冷启动先加载假日再推小组件 / 启动岛 tick，避免空假日语义下先弹课
- 超级岛 / 假日：后台远程假日差分覆盖后回调 Provider 重载并重推表面，不再只写 prefs
- 超级岛 / 假日：选课逻辑入口识别假日，tick / stage 路径不会在假日继续选中课程
- 超级岛：原生 `syncSnapshot` 的 `reschedule` 默认 `stopStaleSessions=true`，假日快照会停掉陈旧会话
