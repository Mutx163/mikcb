# v2.0.9

相对 v2.0.8 累计说明（本地草稿；发版前需对齐 pubspec / tag / latest.json）。

### 新增

- 局域网编辑：支持「离开后保持开启」——返回设置页时可选择继续运行，不必每次重新开服务
- 局域网编辑：控制台支持浅色 / 深色主题切换，并按本机偏好记住

### 优化

- 局域网编辑：控制台整体改用统一白系 shadcn 风格，侧栏与主区同一色系
- 局域网编辑：课程库工具栏「新建课程」固定在右侧，避免被挤到第二行
- 局域网编辑：课程卡片标题、时段与操作区排版更清晰，必修改为淡蓝标签、删除按钮更轻量
- 存储：`timetable_profiles` 解析按档案 / 按课降级，单门坏课不再整库 wipe；读时自愈写回清洗结果
- 存储：档案更新锁内读改写串行；情侣课表导入 / 解绑更稳，减少本地写丢失
- 课表：内存写入更稳；重命名前合并当前课表，避免旧快照盖掉新数据
- 云同步：自动上传前校验云端基线，远程已变时不再静默覆盖
- 局域网编辑：写操作绑定当前课表会话，课表不一致时提示刷新
- 超级岛 / 假日：假日变更会正确收起超级岛，冷启动与远程假日更新后也会同步
- 超级岛：假日快照会停掉陈旧会话，避免岛上仍显示课程

### 测试

- 补充 profiles 坏课 / 坏档案降级与并发更新测试
- 补充 WebDAV 自动上传基线决策单元测试
- 补充假日变更停岛、远程假日变更回调单元测试
- 补充局域网编辑「离开后保持开启」偏好读写单元测试
