# v2.1.2.1

- 新增 柔光玻璃：玻璃模式新增第四档「柔光玻璃」——雾面细腻、比液态更省电。雾度可用「柔光玻璃预设」一键选（清透 / 轻盈 / 标准 / 浓雾），也能在「高级材质」里逐项微调。
- 新增 首页顶栏玻璃自由选：顶栏玻璃材质从「跟随全局」改为独立五档（渐进磨砂 / 高斯磨砂 / 柔光 / 液态 / 实体）；其中渐进磨砂的模糊强度自上而下连续衰减，预设档之外还能自定义。
- 新增 质感方案与「各表面当前材质」：一键套用整套材质搭配（玻璃模式、作用范围、顶栏风格、卡片表面等），套完仍可逐项调整；一页看清每块表面当前用的是哪种材质。
- 新增 全局字重与字号缩放：新增字重滑杆，课程卡片按角色平移字重，标题与详情的层级关系保持不变。
- 新增 首页壁纸「最近使用」：最近用过的 10 张壁纸留在设置页一键切回，并记住每张当时的显示位置；这条历史是全局的，切课表不再跟着变。
- 新增 超级岛展开详情自定义：展开态每一行（阶段 / 简称 / 进度 / 状态 / 时间 / 地点 / 老师 / 下节课 / 备注）都能单独显隐并按需排序，关掉的字段不会再被系统补回来，课前与课中各存一套；非小米设备也能自定义岛左侧的图标位。
- 新增 右上角菜单改用系统同款玻璃弹层：菜单从「更多」按钮原位长出来、行间带形变动效，二级面板同步重做（切行做标题，主面板让位退后）；收起动画期间也能立刻再点开。
- 新增 选择小弹窗改用系统同款锚定弹层：从触发那一行长出来，宽度按内容自适应。
- 新增 时间模板分享：时间模板页与备份页可直接把模板分享出去。
- 新增 日历导出可选跳过节假日课程：导出的日历不再混进节假日停课的课，也不再出现导出空日历的情况。
- 优化 玻璃性能与发热：玻璃采样只录背后那条窄带、静止时不再吃满一个核；转场期间页面不再逐帧重画，滑动更顺、长时间用更少发热。
- 优化 液态玻璃观感：顶栏玻璃第一次真正折射壁纸与课表，折射质量改到更省电的档位，修掉滑动时卡死。
- 优化 120Hz 高刷屏：应用自己申请峰值刷新率，修掉高刷屏上只跑 60 多帧。
- 优化 顶栏折叠衔接：大标题切小标题、内容顶到标题栏时不再顿挫，也不会露出糊掉的内容。
- 优化 底栏内嵌页：不再白白重画被完全挡住的首页，进设置页不再掉帧。
- 优化 超级岛：系统限制后台启动时自动重试，岛面不再莫名消失；应用升级后岛面配置保留。
- 修复 材质与墨色错配：实体卡片档下菜单不再白底白字；浅色主题配暗壁纸时底栏不再白底白字；日课表的日期卡不再「亮卡上写白字」；课程卡在没有壁纸或关闭模糊时不再渲染成透明卡片。
- 修复 首页右上角两颗玻璃球（更多 / 爱心）：关菜单、跳页面、跳转回来都不再闪一下，也不会只剩半套材质。
- 修复 桌面小组件「色条 + 文字」的配色：字与色块亮度差收紧，看起来是同一个颜色。
- 修复 页脚年份：多语言目录加载失败时不再露出 {year} 占位符。
