# v1.1.10.3

## 包名更换迁移公告

- 本次版本已将应用包名更换为 `com.mutx163.qingyu`。Android 会把旧版和新版识别成两个独立应用，所以桌面上暂时出现两个图标是正常现象。
- 新版首次打开如果看到迁移提示，或者界面是空的，并不代表数据丢失。旧数据仍然保留在旧版应用里，不会自动出现在新版。
- 请不要先卸载旧版。旧版一旦卸载，旧包名对应的应用私有数据会被系统删除，之后无法再自动找回。

## 迁移教程

1. 打开旧版应用，进入 `设置 -> 数据备份与迁移`。
2. 在旧版里点击 `导出全部数据`，不要点 `导出当前课表`。
3. 旧版导出后会弹出系统分享面板。优先选择 `保存到文件`，建议保存到 `下载 / Download` 文件夹。
4. 如果你的系统没有 `保存到文件`，可以先分享到微信任意一个聊天，在微信里点开该备份文件并保存。保存后通常会出现在 `Download / WeiXin` 文件夹。
5. 回到新版后，在迁移引导页点击 `我已完成备份，去导入`，或者进入 `设置 -> 数据备份与迁移`。
6. 通过系统文件选择器选中刚才导出的 `.mikcb` 备份文件进行导入。
7. 确认新版课表、组件、提醒等功能都正常后，再卸载旧版应用。

## 本次补充修正

- 迁移页底部次级按钮文案改为 `以全新应用开始，不迁移`，避免误解成稍后还会继续迁移。
