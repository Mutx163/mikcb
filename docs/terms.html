合规信息

用户协议

轻屿课表面向 Android 用户提供课表管理、导入、提醒、小组件与版本更新等能力。下载安装并使用本应用，即表示你同意遵守以下基本规则。

1. 使用范围

  • 应用主要用于个人学习与课表管理场景
  • 你应确保导入的课表、教务信息或日历数据来源合法
  • 不得利用本应用或适配脚本从事破坏性、批量化或未经授权的数据抓取

2. 下载与安装

  • 官网当前提供的安装包以 Android arm64-v8a 为主
  • 安装前请自行确认设备系统版本、架构和来源可信度
  • 预发布版本主要用于体验新功能和验证更新，稳定性可能低于正式版

3. 数据与风险

课表提醒、超级岛、通知、小组件等表现会受到系统版本、厂商策略、权限、电池策略等外部因素影响，官网和应用无法保证所有设备表现完全一致。

4. 开源与分发

项目以开源方式维护，代码、版本与安装包通过 GitHub 与官网持续分发。你在遵守开源协议的前提下，可查看源码、反馈问题或参与贡献。

5. 反馈与改进

使用过程中发现问题、兼容性异常或学校导入需求，建议通过 GitHub Issue 或应用内反馈入口提交，帮助项目持续改进。
