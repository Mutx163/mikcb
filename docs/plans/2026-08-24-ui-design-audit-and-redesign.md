## 0. 总评（TL;DR）

| 评估维度 | 得分 | 一句话结论 |
|---|:---:|---|
| ① 界面排列是否合理 | **7 / 10** | 首屏骨架符合 HyperOS 规范；扣分在底栏承载低频「设置」、「回本周」三重入口、38 项功能全部压在 ⋮ 一层之后 |
| ② 功能是否杂乱 | **5 / 10** | 核心链路（看课→提醒）清晰，但外观个性化呈"参数面板化"：导航形态 2 × dock 布局 2 × 菜单形态 2 × 卡面 2 × 玻璃模式 4 × 背景 scope 4 开关，用户面对的是工程参数而非设计选择 |
| ③ 描述是否简洁明了 | **7 / 10** | 菜单标题普遍 2–5 字很克制；但 subtitle 有路线图泄漏、内部术语、复述标题等约 10 处硬伤 |

**核心病灶只有一个：能力增长快于信息架构收敛。** 每加一个功能都给了入口和开关，但没有同步做减法。以下方案围绕"做减法"展开。

## 一、三问逐答（现状评估）

### 1.1 整个界面的排列是否合理？——骨架好，关节错位

**做得对的：**

- 三层令牌架构（`MiuixSpec → Tokens → HyperosColors`）健全，395 处引用，亮暗双色板完整转录自 Miuix/HyperOS（`hyperos_miuix_spec.dart`）；主色 `#3482FF`/`#277AF7`，背景 `#FFFFFF`/`#242424`，与系统观感一致。
- 首屏纵向节奏正确：状态栏 → 标题(=课表切换器) → 星期栏(40dp) → 课表格；玻璃 chrome 带连续不分层（`home_page_region_blur.dart:129`）。
- 设置首页六大分组「课表 / 课表显示 / 提醒与桌面 / 应用 / 数据与共享 / 关于」符合用户心智模型（`timetable_settings_screen.dart:390-640`）。
- 课程卡对比度有 WCAG 巡检（min 3.0 / critical 2.0，`course_color_palette.dart:102-107`）。

**排列问题（按严重度）：**

1. **底栏黄金位给了低频操作。** glassDock 的「设置」Tab 常驻底栏（`timetable_screen.dart:154` `_GlassDockEntry{day,week,settings}`），而设置是典型的低频入口；日/周切换已有横滑 + 星期栏 scrubber 两条路径。
2. **「回本周」三重入口。** 星期栏下 8px 小字（L2180）＋磨砂浮钮（L7094）＋dock 圆钮可配置为 backToWeek（L6511）同时表达同一状态；当前周时小字仍占位。
3. **38 项功能压在 ⋮ 之后一层。** `kHomeMenuCatalog` 38 个入口（`home_menu_catalog.dart:49`），无二级归类，找「局域网编辑」和找「添加课程」要扫同一个平面。
4. **更新打扰首屏。** 顶栏红点（L729–747）之外，检测到新版本时启动即自动弹出更新 sheet（L8276–8294），首次印象被升级营销抢占。
5. **工程债反噬布局迭代。** `timetable_screen.dart` 8876 行单文件，近期 git log 近 20 条中 10+ 条是 glass-dock 材质返工——改一处动全身，布局微调成本已经显性化。

### 1.2 所有功能是否杂乱？——功能不乱，入口和开关乱

**入口冗余清单：**

| 功能 | 入口数 | 明细 |
|---|:---:|---|
| 加课程 | 3 | ⋮ 菜单 / dock 圆钮 / 添加 sheet 内表单 |
| 回本周 | 3 | 小字 / 浮钮 / dock 圆钮配置 |
| 时间模板 | 2 | 设置 hub `:441` ＝ 课表页面 `settings_timetable_page.dart:116-135` 同一路由 |
| 自检 | 2 | 超级岛页 `settings_live.dart:138-158` ＋ 诊断页 |
| 内存状态 | 2 | 开发者组 hub`:646` ＋ 诊断页 |
| 日视图 | 2 | 点日格 / dock Tab |
| 设置 | 2 | ⋮ 菜单 / dock Tab |

**外观配置矩阵（杂乱感的主要来源）：**

```
HomeNavigationForm(classic|glassDock)          ← 结构性选择，藏在「外观与配色」
├─ GlassDockLayout(overlay|inset)
│  └─ insetClearance 数值滑杆
├─ 显示 日Tab? 周Tab? 设置Tab? 加号钮? （4 开关，约束"至少留一个"）
│  └─ 圆钮功能 = 目录 38 项任选
HomeMenuStyle(list|grid)                        ← 双形态并存
HomeTitleStyle(classic|brand)                   ← 双形态并存
CourseCardSurfaceStyle(solid|gaussian)          ← 曾有 5 种，靠迁移函数收编（timetable_settings.dart:556-569）
FrostedGlassMode(frosted|liquidGlass|gaussian|translucent)  ← 4 种玻璃肉眼差异有限
背景 scope：状态栏/头部/星期栏/课表 4 开关 + 头部模糊 + 星期栏模糊 + 跟随周滑动
磨砂 sheet：blurSigma + tintAlpha + barrierAlpha 三个裸数值滑杆
```

理论组合上万种，其中大量组合未被视觉验证过——这正是 glass-dock 反复返工的根源。**给用户"参数"不如给用户"预设"。**

**设置页条目超标（建议红线 ≤9）：**

| 页面 | 条目数 | 状态 |
|---|:---:|---|
| 课表页面 | ≈22 | 超标 2.4 倍 |
| 课程卡片 | ≈18 | 超标 |
| 桌面小组件 | 14 | 超标 |
| 外观与配色 | 9–19（glassDock 展开时） | 边界模糊 |
| 通用 / 超级岛 / 诊断 | 4–5 | 健康 ✓ |

**归类错位：** 玻璃坞形态、八宫格编辑器、首页标题样式都是**结构性**设置，却住在「外观与配色」（`settings_appearance.dart:163-383`）。节假日高级页标题借用了云同步的键 `cloudSyncAdvancedTitle`（`settings_holiday.dart:396,623`）。「恢复默认」只有 4 页有，通用/节假日/超级岛没有，作用域规则不一致（`settings_reset.dart:8-20`）。

## 二、重设计方案

### 设计北极星

> **"打开即答案，个性不设防。"**
> 首屏零学习成本呈现今天/本周安排；个性化能力全部保留，但从"参数面板"重组为"场景预设"。

三条设计原则：

1. **一个动作一个门**（One Action, One Door）——每个高频动作只保留一个主动入口，其余入口降级为快捷方式或删除。
2. **预设优先于参数**（Presets over Parameters）——面向用户的永远是命名预设；裸数值滑杆收进"高级"。
3. **玻璃是点缀不是地板**（Glass as Accent）——同屏玻璃面 ≤2 层，其余表面降级纯色/tint。

### A. 信息架构重构

**A1. 底栏减负（dock 只做切换）**

```
现状：[ 日 | 周 | 设置 ]  (圆钮)
建议：[ 日 | 周 ]         (＋)     ← 移除设置 Tab；设置走 ⋮ 或标题长按
                                      ＋ 固定为加课程（去 ⋮ 菜单重复项）
```
- 「回本周」收敛为浮钮**单一**入口：仅非当前周淡入，当前周彻底隐藏；星期栏小字与 dock 圆钮配置项删除。
- overlay/inset 双布局合并为一种（内容滚动避让自动计算），`glassDockInsetClearance` 从一级设置下沉到"高级"。

**A2. 菜单从 38 项平铺改为三层漏斗**

```
⋮ 菜单
├─ 八宫格（默认 8 项，用户可换）：课程总览·统计·导入·考试·任务·传输·云同步·设置
├─ 「全部功能」列表（二级）：按 功能/数据/设备 三段分组
└─ 低频项（诊断、内存状态）只在开发者模式出现
```
- 删除 list/grid 双形态，八宫格唯一化（少一套配置矩阵，少一类 bug）；预置 3 套布局模板：**学习 / 考试季 / 极简**。
- 课表切换（点标题无暗示）补 chevron 缀饰或改为头像式徽标，可发现性问题一并解决。

**A3. 设置重组**

```
新增「首页与导航」组（从外观迁出）：玻璃坞形态·八宫格编辑器·首页标题·回本周行为
「外观与配色」瘦身为主题五件事：主题模式·种子色·字体·图标·玻璃质感（预设四选一）
时间模板只留在「课表页面」，hub 入口删除
自检统一入「诊断」；超级岛页删除重复项
所有设置页标配「恢复默认」，作用域 = 本页全部开关
红线：任何一页 >9 条目必须用「高级选项」折叠（先改 课表页面22/课程卡片18/小组件14）
```

**A4. 打扰治理**
- 启动不再自动弹更新 sheet；保留顶栏红点 + ⋮ 菜单置顶项即可。重大安全版本才允许一次弹窗。
- 下拉快捷导课手势补首次引导气泡（当前零提示，`timetable_screen.dart:2680`）。

### B. 视觉系统

**B1. 配色（保持骨架，清欠账）**

骨架健康（三层 token、395 处引用），欠账集中在四类：

- **高频复用色未入 token**（收进 `HyperosColors` 语义槽位）：

  | 复用色 | 出现位置 | 归宿 |
  |---|---|---|
  | 危险红 `#E05D44` ×4 | timetable_screen:5115/5733/5777、course_card:481 | `HyperosColors.destructive` |
  | fallback 蓝 `#2563EB` ×3 | live_settings_subpages:1207、timetable_settings_screen:1265、course_card:510 | 与 primary `#3482FF` 二选一统一 |
  | 旧 Material 蓝 `#2196F3` ×5 | add_course:178、add_schedule_item:854、course_card:86 等 | 同上或色板派生 |
  | 整套 Tailwind 色 ×9 | support_creator_screen:197–267 | 就地常量类封装即可 |
  | `Colors.redAccent/greenAccent/orangeAccent/shade700` ~24 处 | 强调/进度/徽章散点 | 语义 token 或 IconColors 扩展 |

- **圆角五档收敛**：全库 202 处 `BorderRadius.circular` 中 127 处字面量、18 种值——12(×27)、8(×15)、16(×14)、10(×11)、28(×9)、999 胶囊 hack(**×17**)…收敛为 `card=24 / control=16 / chip=12 / small=8 / pill(StadiumShape)` 五档，提供 StadiumShape 替代所有 `circular(999)`。
- **课程色板双轨合一**：以 `kPresetCourseColorPairs`（粉彩底+深墨字，9 对）为唯一真源，picker 色与随机导课色均从 pairs 派生；**修复橙对 `#FFCC80/#E65100` 实测对比度仅 2.56 < 自家 3.0 标准**（会被自家 unreadable 判警）：已实测候选墨色——`#C44E00`=3.20（最小视觉偏移）或 `#B34700`=3.72（推荐，留足余量且保持焦橙色调）；其余 8 对全部 ≥3.05 达标（红对 3.05 贴线，可顺手加深至 `#A31515` 一档）。
- **玻璃参数失配修复**：默认折射率 1.59 超出自家滑杆上限 1.5（liquid_glass_tuning.dart:127 vs :145），fromJson 经 clamp 后持久化值漂移到 1.5、与内存默认不一致——二选一对齐；合并三份逐字段相同的 LiquidGlassSettings 常量；删除 `_kStockDockGlass` 实验开关。
- **CI 门禁**：自定义 lint 禁止 lib/screens、lib/widgets 新增 `Color(0x…` 与 `Colors.<hue>`（miuix_showcase 演示目录白名单豁免）。

**B2. 玻璃预算制**
- 同屏玻璃面 ≤2：chrome 带 + 一个焦点面（dock 或浮钮）。其余表面用纯色/tint 降级。
- FrostedGlassMode 四选一保留但以**命名预设**呈现：「标准磨砂 / 液态玻璃 / 清透 / 薄雾」，blurSigma/tintAlpha/barrierAlpha 三个裸滑杆收进各预设的"高级调校"。
- 背景 scope 四开关合并为一张示意图上的点击热区（所见即所得），替代四个抽象开关行。

**B3. 字阶与排版**
- 字号齐全（32/24/20/18/17/16/14/13/11）；固化使用规则：页面标题 title3(20)、分组标签 footnote1(13) 灰、正文 main(17)、副题 body2(14)。禁止新字号入册。
- **补字重层级（当前最大短板）**：全站几乎纯 w400——标题、正文、按钮同一字重，层级只靠字号单维支撑，扫读时"标题不像标题"。建议：页面/卡片标题 w600、组标签 w500、正文与副题保持 w400、按钮文字 w500。改动集中在 `HyperosTypography` 一处，全局生效。
- 行高已规范（main 1.25 / listDetail 1.4），维持现状。
