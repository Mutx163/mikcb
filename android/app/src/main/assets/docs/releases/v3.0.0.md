# v3.0.0

> 本次重点：全站界面换成 Compose 重写版、首页多了月视图、云备份恢复前先看差异

这是 3.0 的第一个测试版，也是重构版的大版本：整个 App 的界面框架换成了 Compose 重写，页面、动效和玻璃材质全部重做，滑动和切页更跟手。老用户可以直接覆盖安装，课表、日程、壁纸和设置都会保留，不需要迁移；只有教务导入的登录状态需要重新登录一次。本版要求 Android 13（minSdk 33）及以上，Android 13 以下不再更新。

## 新增 · 20

- 全站界面换成 Compose 重写版：页面、弹层、玻璃材质和转场统一到 miuix 组件，滚动与切页更跟手，不再依赖 Flutter 运行时。
- 首页多了月视图：周 / 日 / 月三个同级视图，停在哪个视图会记住，冷启动回到原视图。
- 首页底栏换成可左右滑的玻璃底栏：切页有跟手转场，圆钮只给当前页亮。
- 首页「更多功能」汇总页：没有固定入口的页面集中收齐，按分类分区块、八宫格磁贴。
- 首页课表下拉就能重跑上次录好的教务导入：原地显示进度和结果，成功后自动回首页，不用再跳去导入页。
- 课表周视图：考试卡、日程卡按钟点落进网格；星期栏给有日程的日期加一个小圆点（跟着星期强调色）。
- 日视图：作业 / DDL 接进当日议程，顶部一条待办带。
- 课表导出与分享：导出干净课表图，顶栏菜单直接分享；截屏后也会提示分享。
- 课表自动更新：打开时 / 每隔 N 小时 / 每天定时三种时机，静默跑，有变化或失败才提示。
- 云备份恢复前先看差异：恢复拆成「预览差异 → 确认」两步，恢复后还能撤销。
- 局域网整份恢复与撤销：网页端可整份恢复课表，恢复后还能撤销。
- 教务导入补齐：网页登录接真 WebView、Cookie 提取与登录态判定，适配仓按教学楼分流作息，支持宏录制 / 回放；从旧版升级后需要重新登录一次教务。
- 二维码传输：真相机扫码、发送页真渲染二维码，扫码结果直接落成接收会话。
- 桌面小组件：设置页接真宿主，10 项设置真读真写，课表改完自动刷新桌面卡片。
- 通知点击落回对应页面：冷启动和已运行两路都解析，点通知不再只打开首页。
- 单节课闹钟：课程弹层可给这一节单独设提醒，考试改完会重排闹钟。
- 超级岛试弹：设置里可直接试弹实况通知，合成窗口、退后台和会话恢复走真管线。
- 外观编辑：整屏缩成卡片的入场 / 出场，改完即时预览。
- 课程卡片设置里多了日视图配色开关：关掉后日视图课程卡改用统一卡底色，课名更好读。
- 壁纸：取景页改成悬浮玻璃按钮，按钮跟着壁纸明暗翻色；拖动取景、历史记录 / 自动换 / 删除撤销，首页壁纸高斯模糊。

## 优化 · 12

- 底栏玻璃更省：切页时不再每帧重算整屏模糊，滑起来更跟手。
- 月视图拖动更顺：拖动时不再每帧重建整页。
- 周↔日切换的第一帧更稳，不再先卡一下才出来。
- 切回日视图更顺：不再把整页重新搭一遍。
- 顶栏玻璃统一成官方做法，各页面自动跟着生效。
- 引导页版式重做：圆点并进翻页按钮、页名提到大标题、权限进度条只表完成度。
- 滑杆更跟手：课表页四根滑杆改成松手后 0.25 秒才保存，拖动不再一卡一卡；选色弹窗换成官方组件。
- 考试弹层适配矮屏和大字号：选日期补具体日期行与周数徽章，列表限高，给底部按钮留位置。
- 更新页 / 关于页 / 赞助页收口：更新说明改淡色胶囊、版本号右对齐，关于页头部重排、免责声明移到页尾，赞助名单说明句精简。
- 列表样式统一：卡片里不再画多余横线，标题和滚动跟官方示例一致。
- 宽屏适配：页面骨架、列表和底栏 Rail 按同一套判据收口。
- 六种语言文案补齐：新界面补上译文，清掉过长的中文和没人用的文案。

## 修复 · 20

- 月视图：设了壁纸就进不去、矮屏面板被挤成 0、切入时文字闪黑闪白。
- 壁纸：删除档案会误删别的课表在用的图；自动换、历史切回 / 删除 / 撤销真正接到宿主。
- 备份 / 云同步 / 整份传输：个别字段类型不对导致整份备份被拒或整档静默消失；整份传输后设置与地点分组不再丢；空快照不再覆盖云端。
- 局域网：HTTP 线程与 UI 线程并发写互撞；表格覆盖导入任一行非法不再丢旧课表。
- 设置：坏一个字段不再把整份设置重置为默认；弹层关闭时官方退场动画不再丢失。
- 考试：选日期弹层底部按钮被挤出、未选星期时「确认」可点却无反应。
- 天气：坐标取整把「同一城市」判定打穿，升级用户永远丢缓存、日视图反复请求。
- 导入：单元格 Infinity 让 round() 抛异常，整表导入崩溃。
- 统计：拿不到的读数和没接的落点不再假装有。
- 通知：点击按变体找启动页，Compose 壳补一次通知权限申请。
- 更新：系统下载器改取官方直连 URL，不再被镜像信任根拒绝。
- 首页：切出内嵌页时整棵首页被重建，悬浮球闪一下。
- 首页八宫格：从旧版升级后某些格子会被旧配置占住、编辑后少一个入口；文字颜色和最后一行对齐也修了。
- 小组件刷新更省：只在课表有变化的时候才重新推快照，不再反复重画。
- 课表：日 / 周切换时星期栏选中态即时跟手，选中蓝条平滑滑动。
- 课表重新配色：点进去只显示「不可用」，现在能正常选配色。
- 壁纸：新页面第一帧不再闪一下没模糊的壁纸；玻璃表面也跟着壁纸一起糊。
- 启动：先显示上次的内容再刷新，不再先闪一下白屏或没壁纸的底色。
- 语言：把界面语言换成别的以后，界面还是旧语言；现在立刻跟着变。
- 全站按钮底色统一：修掉一百多处按钮和背景同色、看不出能点的问题。
